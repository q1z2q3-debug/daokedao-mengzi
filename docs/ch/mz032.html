第三十二章　伯夷隘

一　本章导读

公孙丑上最后一章，孟子给两种”极端”画像。

伯夷：非其君不事，非其友不友。不站在恶人的朝廷上，不与恶人说话——他觉得那像穿着朝服朝冠坐在泥灰里。把这份厌恶推到乡人：乡人帽子没戴正，他望一眼就走，像要沾污似的。所以诸侯中虽有把话说得极好来请他的，他也不接受——是亦不屑就已。

柳下惠：不羞污君，不卑小官。进用不隐自己的贤，一定按自己的道走。被弃不用不怨，困穷不忧。他说：尔为尔，我为我，虽袒裼裸裎于我侧，尔焉能浼我哉？ 所以他从容地与人相处而不失自己；拉住他留下，他就留下——是亦不屑去已。

孟子只判八个字：伯夷隘，柳下惠不恭。隘与不恭，君子不由也。

隘是太窄，不恭是太简慢。两种都不是坏，都”造乎至极”，都有弊。

此章驳谁：驳”极致就是正道”。立什么：立”两端皆有偏，君子不由”——不是取中，是不取偏。留给后人什么：一面镜子：我的洁，是不是窄；我的宽，是不是没了边。

二　经文

【经】孟子曰：“伯夷，非其君不事，非其友不友。不立于恶人之朝，不与恶人言。立于恶人之朝，与恶人言，如以朝衣朝冠坐于涂炭。”

【经】“推恶恶之心，思与乡人立，其冠不正，望望然去之，若将浼焉。是故诸侯虽有善其辞命而至者，不受也。不受也者，是亦不屑就已。”

【经】“柳下惠，不羞污君，不卑小官。进不隐贤，必以其道。遗佚而不怨，阨穷而不悯。故曰：’尔为尔，我为我，虽袒裼裸裎于我侧，尔焉能浼我哉？’故由由然与之偕而不自失焉，援而止之而止。援而止之而止者，是亦不屑去已。”

【经】孟子曰：“伯夷隘，柳下惠不恭。隘与不恭，君子不由也。”

三　字义与句读

涂炭　朱熹：“涂，泥也。”泥与灰。朝衣坐泥，喻自污。

望望然　朱熹：“望望，去而不顾之貌。”

浼　朱熹：“浼，污也。”

不屑就　朱熹引赵氏：“屑，洁也。……不屑就，言不以就之为洁，而切切于是也。”即不以”去”为高。

不隐贤　朱熹：“不隐贤，不枉道也。”

遗佚　朱熹：“遗佚，放弃也。阨，困也。悯，忧也。”

袒裼裸裎　朱熹：“袒裼，露臂也。裸裎，露身也。”

由由然　朱熹：“由由，自得之貌。”

不屑去　与”不屑就”对：不以”留”为污。

隘、不恭　朱熹：“隘，狭窄也。不恭，简慢也。”

句读一处：“伯夷隘，柳下惠不恭”——两句各判一字，是全章最省的判词；后面”君子不由”四字，才是孟子的立场。

四　今译

孟子说：“伯夷，不是他认可的君就不事，不是他认可的朋友就不交。不站在恶人的朝廷上，不与恶人说话。他觉得站在恶人的朝廷、与恶人说话，就像穿着朝服朝冠坐在泥灰里。”

“把这份厌恶推下去，跟乡人站在一起，人家帽子没戴正，他就看一眼走开，像要被沾污。所以诸侯中虽有把话说得极好来请他的，他也不接受。不接受，就是不以”去”为高。”

“柳下惠，不以事污君为羞，不以做小官为卑。被进用不藏自己的贤，一定按自己的道走。被弃不用不怨，困穷不忧。所以他说：’你是你，我是我，就算你在我旁边露臂露身，你怎能污我？’所以他从容与人相处而不失自己；拉住他留下，他就留下。留下，就是不以”留”为污。”

孟子说：“伯夷太窄，柳下惠太简慢。太窄与太简慢，君子都不走。”

五　章旨

洁到进不去，是隘；宽到没了边，是不恭；两种都是”至极”，也都带弊。

五条支撑：

  1. 两人都写得极细：伯夷的”望望然”、柳下惠的”由由然”，是两个身体姿态。
  2. 两人的立场都用一句话钉住：伯夷”不屑就”，柳下惠”不屑去”——各自把对方的动作当成污。
  3. “隘”不是骂他小气，是说他把自己关得太紧：连乡人帽子不正都要走。
  4. “不恭”不是骂他轻慢，是说他把自己放得太松：污君小官一概不拒。
  5. “君子不由”四字，孟子不取中道调和，只说两条路都不走——立的不是”中间”，是”不偏”。

六　注家

【朱熹曰】“朝，音潮。恶恶，上去声，下如字。浼，莫罪反。涂，泥也。乡人，乡里之常人也。望望，去而不顾之貌。浼，污也。”（《孟子集注·公孙丑上》）

【朱熹引赵氏曰】“屑，洁也。《说文》曰：’动作切切也。’不屑就，言不以就之为洁，而切切于是也。”（同上）

【朱熹曰】“柳下惠，鲁大夫展禽，居柳下而谥惠也。不隐贤，不枉道也。遗佚，放弃也。阨，困也。悯，忧也。”（同上）

【朱熹曰】“袒裼，露臂也。裸裎，露身也。由由，自得之貌。偕，并处也。不自失，不失其止也。援而止之而止者，言欲去而可留也。”（同上）

【朱熹曰】“隘，狭窄也。不恭，简慢也。夷、惠之行，固皆造乎至极之地。然既有所偏，则不能无弊，故不可由也。”（同上）

对照：赵岐注以”伯夷清、柳下惠和”为说，各有其美；朱熹补一句”固皆造乎至极之地，然既有所偏，则不能无弊”——先认其至极，再指其偏。赵说二人之德，朱说德之边界。

七　分寸与边界

  1. 不可把”隘”读成”清高可敬”。孟子明说”君子不由”。
  2. 不可把”不恭”读成”豁达可亲”。同一条判词：也不由。
  3. 不能把”君子不由”当作”取中间值”。孟子没有给折中方案，他只拒绝两偏。
  4. 不可把伯夷、柳下惠贬低。朱熹说”皆造乎至极”——他们的偏，是从极高处偏出去的。

八　义理

这一章是孟子给”道德姿态”做的一次边界测绘。

伯夷的问题不在”洁”，在”洁到不能与人共处”：连乡人帽子没戴正都要走。这种洁有一个代价——你只能跟已经正了的人在一起，而世上多半是还没正的人。 于是”洁”变成”断”：断人、断事、断世。朱熹叫它”隘”，窄。

柳下惠的问题不在”宽”，在”宽到没有边界”：污君可事，小官可做，人拉住就留。他的底气是一句极强的话：“尔为尔，我为我”——你能污我什么？这句话很硬，但它有一个漏洞：它只管自己不被污，不管世事被污。 你可以在泥里站得干净，但泥还是泥。朱熹叫它”不恭”，简慢。

孟子把两人并置，是要说明一件事：德性走到极端，会各自长出弊病；而弊病不在德性本身，在”只此一端”。 所以他不用”中”字，用”不由”——不是叫你取中间，是叫你别把任何一端当成全部。

这一章读到最后，问题落回自己：我的”洁”，是否已经窄到进不去人？我的”宽”，是否已经松到守不住事？

九　时代之问

  • 我的原则，是让我更能与人共事，还是更难？ 若越守越孤，可能是隘。
  • 我的包容，是让事更清楚，还是更模糊？ 若越宽越乱，可能是不恭。
  • 我”不屑”的那个动作，是不是也在替我关一扇门？
  • 我能不能在泥里站干净，同时不把泥当常态？ 这是柳下惠留下的真问题。

十　跨典

  • 《论语·微子》：“不降其志，不辱其身，伯夷、叔齐与！”——夷之清。
  • 《论语·微子》：“柳下惠、少连，降志辱身矣，言中伦，行中虑。”——惠之和。
  • 《孟子·万章下》：“伯夷，圣之清者也；柳下惠，圣之和者也。”——同此二人，另有一评。
  • 《老子》第四十五章：“大成若缺。”——至极处必有缺。
  • 《中庸》：“致中和。”——孟子虽不言”中”，其”不由”实近之。

十一　存疑

  1. “不屑就”与”不屑去”之”屑”。 赵氏训”洁”，朱熹从之；一说”屑”即”屑屑”，琐细之意。
  2. “推恶恶之心”。 上”恶”去声（厌恶），下”恶”如字（恶人）；朱熹标音如此。
  3. “乡人”之解。 朱熹谓”乡里之常人”；一说谓同乡之人，不必常人。
  4. 此章与《万章下》之评。 彼处称”圣之清”“圣之和”，此处称”隘”“不恭”——一褒一贬，注家多谓所指不同：彼论其至，此论其弊。
