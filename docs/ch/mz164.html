第一百六十四章　亲过大小

一　本章导读

公孙丑问：“高子说《小弁》是小人之诗。为什么？”

曰：“怨。”

孟子说：“固哉，高叟之为诗也！”——高叟解诗，真是固执。

“有人于此，越人关弓而射之，则己谈笑而道之；无他，疏之也。”——越人张弓射他，他谈笑自若地说；没别的，因为疏远。

“其兄关弓而射之，则己垂涕泣而道之；无他，戚之也。”——他哥哥张弓射他，他哭着说；没别的，因为亲近。

“小弁之怨，亲亲也。亲亲，仁也。”

——《小弁》的怨，是亲其所亲。亲其所亲，就是仁。

又追问：“《凯风》为什么不怨？”

孟子说：“《凯风》，亲之过小者也；《小弁》，亲之过大者也。”

“亲之过大而不怨，是愈疏也；亲之过小而怨，是不可矶也。”

——父母之过大而不怨，是越发疏远了；父母之过小而怨，是一激就怒，如石不可矶。

“愈疏，不孝也；不可矶，亦不孝也。”

——一头一尾，两个不孝。

“孔子曰：舜其至孝矣，五十而慕。”

此章驳谁：驳”诗不可有怨”。立什么：立”怨之有无，视亲之过大小”。留给后人什么：一片写着”小弁”的简，一片写着”凯风”的简。

二　经文

【经】公孙丑问曰：“高子曰：’《小弁》，小人之诗也。’孟子曰：”何以言之？“曰：”怨。“曰：”固哉，高叟之为诗也！有人于此，越人关弓而射之，则己谈笑而道之；无他，疏之也。其兄关弓而射之，则己垂涕泣而道之；无他，戚之也。《小弁》之怨，亲亲也。亲亲，仁也。固矣夫，高叟之为诗也！“曰：”《凯风》何以不怨？“曰：”《凯风》，亲之过小者也；《小弁》，亲之过大者也。亲之过大而不怨，是愈疏也；亲之过小而怨，是不可矶也。愈疏，不孝也；不可矶，亦不孝也。孔子曰：‘舜其至孝矣，五十而慕。’”

三　字义与句读

高子　朱熹曰”高子，齐人也”。

小弁　朱熹曰”小雅篇名”，“宜臼之傅为作此诗，以叙其哀痛迫切之情”。

关弓　引满弓。

戚　亲、近。

固　朱熹曰”固，谓执滞不通也”。

凯风　朱熹曰”凯风，邶风篇名”，“卫有七子之母，不能安其室，七子作此诗以自责”。

矶　朱熹曰”矶，水激石也”。

慕　思慕。

句读一处：“亲之过大而不怨，是愈疏也”——“愈疏”不是”更疏远父母”，是”自己越来越退开”。

四　今译

公孙丑问：“高子说《小弁》是小人之诗。为什么？”孟子说：“怎么说？”“因为怨。”孟子说：“高叟解诗，真固执！有人在此，越人张弓射他，他谈笑自若地说，没别的，因为疏远；他哥哥张弓射他，他哭着说，没别的，因为亲近。《小弁》的怨，是亲其所亲。亲其所亲，是仁。高叟真固执！”“《凯风》为什么不怨？”孟子说：“《凯风》是父母之过小的；《小弁》是父母之过大的。父母之过大而不怨，是越发疏远；父母之过小而怨，是一激就怒。愈疏是不孝，不可矶也是不孝。孔子说：‘舜真是至孝，五十岁还思慕父母。’”

五　章旨

怨非不孝；当怨而怨，正是亲亲。

五条支撑：

  1. “固哉”两字，先定高叟之病：执一。
  2. 越人射我谈笑，兄射我垂涕。 亲疏之别，在一”戚”字。
  3. “亲亲，仁也”，把怨归到仁上。
  4. 两诗对看：过小不怨，过大必怨。 怨之有无有准。
  5. 舜五十而慕，是把”怨”化成”慕”。

六　注家

【朱熹曰】“固，谓执滞不通也。为，犹治也。”（《孟子集注·告子下》）

【朱熹曰】“小弁，小雅篇名。周幽王娶申后，生太子宜臼；又得褒姒，生伯服，而黜申后，废宜臼。于是宜臼之傅为作此诗。”（同上）

【朱熹曰】“亲亲之心，仁之发也。”（同上）

【朱熹曰】“凯风，邶风篇名。卫有七子之母，不能安其室，七子作此诗以自责。”（同上）

【朱熹曰】“亲之过大而不怨，是愈疏也；亲之过小而怨，是不可矶也。矶，水激石也。不可矶，言微激之而遽怒也。”（同上）

【赵岐注】小弁之怨，未足为愆。（按：此为赵注大意，非原文。）

对照：赵岐宽其怨，朱熹析其度。赵恕之，朱准之。

七　分寸与边界

  1. 不可把本章读成”可以怨父母”。** 怨的是”亲之过大”，不是父母本身。
  2. 不可把”不可矶”读成”不能生气”。** 是”微激遽怒”。
  3. 不可把”愈疏”读成”父母疏我”。** 是我自退。
  4. 不可把《凯风》读成”无怨即孝”。** 七子自责，正是孝。
  5. 不可把本章读成诗评。** 它是孝道之度。

八　义理

这一章辩的是一个极难的分寸：孝，能不能有怨？

高子的答案是不能：诗里有怨，便是小人。

孟子的答案是看怨什么、怨多大。

他先给一个日常之比：越人射我，我谈笑；兄射我，我哭。

——同一件事，反应不同，不是因为事情大小，是因为关系亲疏。

“疏之也”与”戚之也”——这两个字是全章的枢。

《小弁》的作者，是被废的太子。 父亲听信谗言，废了他母亲，废了他。他怨。 高子说这是小人。

孟子说：“小弁之怨，亲亲也。亲亲，仁也。”

——他怨，是因为他还亲。 若他早已疏了，他会谈笑自若。

这就是”亲之过大而不怨，是愈疏也”。 父母有大过而你不怨，不是你宽厚，是你已经退开了。

反过来，“亲之过小而怨，是不可矶也”。 父母小过，你一激就炸，像水冲石就溅——这不是孝，是暴。

所以怨有两头：该怨不怨，是疏；不该怨而怨，是暴。 孟子把这两头都叫”不孝”。

最后一句最重：“舜其至孝矣，五十而慕。”

——舜的父母那样待他，他五十岁还思慕。这是把”怨”炼成了”慕”。

怨是对过，慕是对亲。 孟子不取消怨，他把怨收到慕里。

一片简写”小弁”，一片简写”凯风”。 两片简，一重一轻，中间是一个人的分寸。

九　时代之问

  • 我对亲近的人，还有”怨”的能力吗？
  • 我的怨，是”亲亲”还是”不可矶”？
  • 我是否已经”愈疏”而不自知？
  • 我能不能把怨，炼成慕？
  • 我评别人的”怨”，是否也”固”？

十　跨典

  • 《诗经·小雅·小弁》“我心忧伤”——怨之正。
  • 《诗经·邶风·凯风》“母氏圣善”——自责。
  • 《论语·里仁》“事父母几谏”——谏而不怨。
  • 《孟子·离娄上》“不得乎亲，不可以为人”——亲亲。
  • 《礼记·内则》“柔声以谏”——谏之度。
  • 《孝经》“父有争子”——争与怨之别。

十一　存疑

  1. 《小弁》作者。 朱熹曰”宜臼之傅”，一说宜臼自作。
  2. 高子其人。 朱熹曰齐人，与《孟子》他处高子或非一人。
  3. 《凯风》七子之母。 朱熹曰”不能安其室”。
  4. “矶”之训。 朱熹曰”水激石”。
  5. 舜”五十而慕”之出。 朱熹以为孔子语，今《论语》无。
