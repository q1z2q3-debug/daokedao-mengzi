第三十三章　天时地利人和

一　本章导读

公孙丑下开篇，孟子不谈人，先谈三样东西的排序。

天时：日子、干支、孤虚、王相——挑好的时辰。 地利：高城、深池、坚甲、利兵、多粮。 人和：得民心之和。

孟子的判法很奇怪：他不比较三者谁”更好”，他用“试一次”的办法——把前两样都占满，再看结果。

三里之城、七里之郭，四面围住打，打不下来。孟子说：能长期围，必是挑到了好时辰；可还是打不下来，可见天时不如地利。 城墙够高、护城河够深、甲兵够坚利、粮够多，结果守的人弃城跑了。可见地利不如人和。

于是三句否定式收束：域民不以封疆之界，固国不以山溪之险，威天下不以兵革之利。

此章驳谁：驳”把边界、险要、兵甲当作国力”。立什么：立”三样都能买，唯有一样买不到——人愿意跟你守”。留给后人什么：一句可倒过来用的自检——我的”固”，是固在墙上，还是固在人心里。

二　经文

【经】孟子曰：“天时不如地利，地利不如人和。”

【经】“三里之城，七里之郭，环而攻之而不胜。夫环而攻之，必有得天时者矣；然而不胜者，是天时不如地利也。”

【经】“城非不高也，池非不深也，兵革非不坚利也，米粟非不多也；委而去之，是地利不如人和也。”

【经】“故曰：域民不以封疆之界，固国不以山溪之险，威天下不以兵革之利。得道者多助，失道者寡助。寡助之至，亲戚畔之；多助之至，天下顺之。以天下之所顺，攻亲戚之所畔；故君子有不战，战必胜矣。”

三　字义与句读

天时　朱熹：“谓时日支干、孤虚、王相之属也。”不是天气，是择日择向的术数。

地利　朱熹：“险阻、城池之固也。”

人和　朱熹：“得民心之和也。”一”和”字，是全章的落点。

三里之城，七里之郭　朱熹：“三里七里，城郭之小者。郭，外城。”城小而围，是最容易攻的样本——正因为它容易，才说明问题。

环　朱熹：“围也。言四面攻围，旷日持久，必有值天时之善者。”

兵革　朱熹：“革，甲也。”兵是兵器，革是皮甲。

委　朱熹：“委，弃也。言不得民心，民不为守也。”“委”字最重：不是打不过，是不打了，把城丢下走。

域民　朱熹：“域，界限也。”以封疆划界把人圈住。

句读一处：“得道者多助，失道者寡助”——两句对举，第三个字”多／寡”才是孟子真正的度量衡：不量地，量助。

四　今译

孟子说：天时不如地利，地利不如人和。

三里的小城、七里的外郭，四面围起来打却打不下来。能长期围，一定是赶上了好时辰；可还是打不下来，这就是天时不如地利。

城墙不是不高，护城河不是不深，甲兵不是不坚利，粮不是不多——可守的人把城丢下跑了，这就是地利不如人和。

所以说：圈住百姓不靠边界，稳固国家不靠险要，威服天下不靠兵甲。得道的助多，失道的助少。少到极处，连亲戚都反他；多到极处，天下都顺他。用天下所顺，去打亲戚所叛——所以君子要么不打，打就必胜。

五　章旨

三样都能置办，只有”人愿意替你守”置办不来。

五条支撑：

  1. 孟子的方法不是比较，是排除。 他先把天时、地利给足，再让它们失败一次。剩下那个，才是答案。
  2. “环而攻之”是极端测试。 围城是最占天时的打法；打不下来，就不能再拿天时当借口。
  3. “委而去之”是本章的针眼。 城没破，人先走。地利是被”人”废掉的，不是被敌人攻破的。
  4. 三句”不以”，是把”国力”的定义撤掉重写。 边界、险要、兵甲都不是”固”，它们是”固”的替代品。
  5. “多助／寡助”是唯一的量化指标。 孟子不给城池数，给的是”有多少人愿意站你这边”。

六　注家

【朱熹曰】“天时，谓时日支干、孤虚、王相之属也。地利，险阻、城池之固也。人和，得民心之和也。”（《孟子集注·公孙丑下》）

【朱熹曰】“三里七里，城郭之小者。郭，外城。环，围也。言四面攻围，旷日持久，必有值天时之善者。”（同上）

【朱熹曰】“革，甲也。粟，谷也。委，弃也。言不得民心，民不为守也。”（同上）

【朱熹引尹氏曰】“言得天下者，凡以得民心而已。”（同上）

对照：赵岐注以”天时”为”时日干支五行王相孤虚”，与朱同；而赵于”人和”只解作”民心所和”，朱熹补出”民不为守”四字，把”和”落到”守”这个动作上——赵说其名，朱说其效。

七　分寸与边界

  1. 不可读成”天时地利不重要”。孟子用它们做前提，只是说它们不够。
  2. 不可把”人和”当成”民风好”。它是”愿意替你守”这一具体行为。
  3. 不能用此章反推”不必修城”。孟子不撤城防，他撤的是”以城防为国”。
  4. 不可把”得道多助”当成功学公式。孟子说的是长期结果，不是每次都能赢。

八　义理

这一章最容易被读成鸡汤，其实它是一份工程验收单。

孟子把国家拆成四层：时辰、地势、器械、粮秣，全是可置办项；再加上第五层——人。他的判法是：前四层全给满，再抽掉第五层，看系统是否崩溃。结论是：崩溃。 “委而去之”四个字，就是压力测试的失败报告。

这里有一层更狠的意思：地利是需要人来兑现的。 城墙高、池深、兵利、粮多——这些”利”全都是待兑现的期权，兑现的人才是在城墙上站着的那个人。人不站，期权归零。所以”地利不如人和”不是说人和比地利”价值更高”，而是说地利必须经过人才能变成地利。

再往下一层：为什么人会走？孟子没在这里答，但”域民不以封疆之界”已经指了方向——靠边界圈住的人，边界一破就走；靠险要吓住的人，险要一失就散。 只有一样东西不随城墙倒：他认为你值得他留下。

于是”得道多助”不是道德奖赏，是结构描述：你的位置，由多少人愿意与你共担风险来定义。

九　时代之问

  • 我的”护城河”，是护住了人，还是护住了我自己？
  • 如果把我的资源全给满、只抽掉”人愿意跟我”，这套系统还转吗？
  • 我数的是”我有什么”，还是”谁愿意替我守”？
  • 我圈住的人，是圈住的，还是留住的？

十　跨典

  • 《孙子·计篇》：“天者，阴阳、寒暑、时制也；地者，远近、险易、广狭、死生也。”——兵家也讲天地，但列在”五事”之首的是”道”。
  • 《荀子·王霸》：“用国者，义立而王，信立而霸。”——同一条思路：先立人，后立国。
  • 《论语·颜渊》：“民无信不立。”——“信”即”人和”的另一种说法。
  • 《老子》第六十四章：“民之从事，常于几成而败之。”——“委而去之”，常在将成之时。
  • 《管子·牧民》：“政之所兴，在顺民心。”——顺，即”和”。

十一　存疑

  1. “天时”是否指节气。 朱熹明列为”时日支干、孤虚、王相”，是术数；今人或解为气候，与朱注不合。
  2. “三里之城，七里之郭”的比值。 一般解为城三里、郭七里；一说”三里之城”指周长，注家无定。
  3. “君子有不战”之”有”。 朱熹：“言不战则已，战则必胜。”读”有”为”或”，语气词。
  4. 此章是否孟子亲历。 孟子未尝主兵，注家多以为设喻立论，非记实事。
