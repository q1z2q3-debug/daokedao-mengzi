第六十七章　不得罪巨室

一　本章导读

孟子说：为政不难，不得罪于巨室。 ——办政事不难，难的是别得罪那些世家大族。

下半句一转，把”不得罪”说清了：巨室之所慕，一国慕之；一国之所慕，天下慕之；故沛然德教溢乎四海。 ——巨室向着谁，一国就向着谁；一国向着谁，天下就向着谁；于是德教像水一样满出来，漫过四海。

此章驳谁：驳”为政难在权谋、难在压服强者”。立什么：立”不得罪＝身正而不取怨”，以及”服其心，而非胜其力”。留给后人什么：一个”沛然”——德教是满出来的，不是推出去的。

二　经文

【经】孟子曰：“为政不难，不得罪于巨室。巨室之所慕，一国慕之；一国之所慕，天下慕之；故沛然德教溢乎四海。”

三　字义与句读

巨室　朱熹：“巨室，世臣大家也。”——不是”有钱人”，是世代为卿大夫的家族，有根、有众、有声望。

得罪　朱熹：“得罪，谓身不正而取怨怒也。”——这一条是全章最容易读漏的地方：“得罪”不是”招惹”，是”自己身不正，招来的怨怒”。

慕　朱熹：“慕，向也，心悦诚服之谓也。”——“慕”是”向着”，不是”羡慕”。

沛然　朱熹：“沛然，盛大流行之貌。”

溢　朱熹：“溢，充满也。”

承上章　朱熹：“此亦承上章而言，盖君子不患人心之不服，而患吾身之不修。”

句读一处：“巨室之所慕，一国慕之”——两个”慕”，前者是”所向”，后者是”跟着向”。孟子用的是”水往哪里流，下面的水就跟着往哪里流”这种句法。

四　今译

孟子说：“办政事不难，只要不得罪那些世家大族。巨室所向着的，一国就跟着向；一国所向着的，天下就跟着向；所以德教盛大流行，漫满四海。”

五　章旨

“不得罪”不是讨好，是把身立正到不招怨；真正要服的，是心，不是力。

五条支撑：

  1. “为政不难”是一句吊胃口的话。 孟子先说”不难”，是为了把”难”从一个地方挪到另一个地方：不难在权术，难在身正。
  2. 朱熹把”得罪”训成”身不正而取怨怒”。 这一训，把”得罪”从”冒犯”改成了”自取”。于是”不得罪于巨室”不是”别惹他们”，是”别让自己站不正”。
  3. “慕”是向着，不是羡慕。 巨室的心往哪边倾，一国的心就跟着倾。这是”风向”的力学，不是”讨好”的技术。
  4. 力量用错了对象。 林氏说得直：“不修其本而遽欲胜之，则未必能胜而适以取祸。”——想压服巨室的人，多半先被巨室压住。
  5. “沛然”是这幅图的重量。 朱熹训”盛大流行之貌”。水不是被推出去的，是满出来的。 德教到这个地步，不需要”推”，它自己会漫过去。

六　注家

【朱熹曰】“巨室，世臣大家也。”（《孟子集注·离娄上》）

【朱熹曰】“得罪，谓身不正而取怨怒也。”（同上）

【朱熹曰】“慕，向也，心悦诚服之谓也。”（同上）

【朱熹曰】“盖巨室之心，难以力服，而国人素所取信；今既悦服，则国人皆服，而吾德教之所施，可以无远而不至矣。”（同上）

【朱熹引林氏曰】“战国之世，诸侯失德，巨室擅权，为患甚矣。然或者不修其本而遽欲胜之，则未必能胜而适以取祸。”（同上）

对照：赵岐注此章，以”巨室”为”世臣大家”，以”得罪”为”失其欢心”，重在说”不可失大族之欢”；朱熹则把”得罪”改训为”身不正而取怨怒”，并引林氏”遽欲胜之适以取祸”一语，把它读成”修本”而非”结欢”。赵主其欢，朱正其本。

七　分寸与边界

  1. 不可把此章读成”怕豪门”。朱熹的落点是”吾身之不修”，不是”巨室之难惹”。
  2. 不可把”不得罪”读成”讨好”。讨好是向外用力，此章是向内用力。
  3. 不可把”巨室之所慕”读成”必须争取豪族支持”。它说的是风向的传导，不是政治的站队。
  4. 不可把”沛然”读成”一蹴而就”。“沛然”是满出来的状态，前面有一段”身修”的慢工。
  5. 不可把此章当作”不得罪任何人”的处世术。孟子说的是”巨室”这一种有根有众的对象，不是叫人处处退让。

八　义理

这一章在《孟子》里常被读成一句”政治手腕”，其实它是一个力学问题。

先说”巨室”是什么。 朱熹：“世臣大家也。”——世代为卿大夫的家族。 这种家族的特点，不是钱多，是有根、有众、有信。国人对他们的信任，是几十年积下来的。所以他们的心往哪边倾，不是一家的事，是一国的事。

再说”得罪”是什么。 通常读成”冒犯”，朱熹偏要训成”身不正而取怨怒”。这一改，整章的重心就从”对方”移到了”自己”。 你不是因为说错了话才得罪巨室，你是因为站不正才招来怨怒。这就把”为政不难”接上了：难的不是应付他们，是立正自己。

然后说”慕”是什么。 “向也，心悦诚服之谓也。”——不是羡慕，是朝向。 巨室的心是一个坡，国人的心顺着这个坡流。孟子在这里用的不是道德劝说，是地形学。

最后说”沛然”。 这是全章最漂亮的一个词。朱熹训”盛大流行之貌”。水满了才会漫，漫了才”溢乎四海”。 反过来看：需要”推”的德教，说明还没满；需要”争”的政令，说明还没立。

林氏那一句是这一章的注脚： “不修其本而遽欲胜之，则未必能胜而适以取祸。”——想赢巨室的人，先输在自己的本上。 裴度服韩弘、承宗的那段史事，说的也是这个：不是朝廷的力能制其死命，是处置得宜，服其心。

所以这一章不是”别得罪人”，是”别让自己站歪”。 站正了，最难服的那一批先服；他们一服，剩下的顺着坡就下来了。

九　时代之问

  • 我这一行里的”巨室”是谁？我是在服其心，还是在胜其力？
  • 我最近招来的怨怒，是我做错了事，还是我站歪了？
  • 我想推的那件事，是满出来的，还是推出去的？
  • 我有没有把”不得罪”当成”讨好”来用？
  • 我的本，修到哪里了？

十　跨典

  • 《论语·颜渊》：“政者，正也。子帅以正，孰敢不正。”——“身正”与”不得罪”的同一条线。
  • 《论语·季氏》：“既得之，患失之。”——豪族之心难服的另一面。
  • 《孟子·公孙丑上》：“以力服人者，非心服也。”——“服其心”三字的直接来源。
  • 《孟子·离娄上》上一章：“家之本在身。”——本章所承。
  • 《大学》：“有诸己而后求诸人。”——先正己，后求人服。
  • 《史记·裴度传》：“处置得宜，能服其心。”——朱熹所引史事。

十一　存疑

  1. “巨室”的具体所指。 朱熹谓”世臣大家”，一说兼指”国人所信之大族”，两说大致相通。
  2. “得罪”的训释。 赵岐训”失欢心”，朱熹训”身不正而取怨怒”，二者侧重不同。
  3. “沛然”是否为水喻。 朱熹训”盛大流行”，后世多读作水貌，然未见明言。
  4. 林氏其人。 朱熹所引林氏，注家考为林之奇一系，未有定论。
  5. 麦丘邑人祝辞的来源。 见《新序》，朱熹引之以证”不得罪”之古义。

图位　图一｜巨室之门

读图三处：

  1. 那扇没有锁的门——门不需要锁。“不得罪”不是把门关上，是不让人来撞门。
  2. 门里那一个人——坐得很正。他一个人坐着，门外的人却在看他的方向。
  3. 那道漫出来的水纹——从门内向外，越过门槛。这就是”沛然”：不是推出去的，是满出来的。

图说一句：身正了，最难服的那一批先服。
