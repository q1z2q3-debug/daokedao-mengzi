第一百一十五章　禹稷颜回

一　本章导读

一章两幅画，两个人，两条路。

禹、稷当平世，三过其门而不入，孔子贤之。颜子当乱世，居于陋巷，一箪食，一瓢饮，人不堪其忧，颜子不改其乐，孔子贤之。

一个治水，三次路过自家门口不进去；一个居陋巷，一竹篮饭，一瓢水，别人受不了那份苦，他不变其乐。孔子都称贤。

孟子说：“禹、稷、颜回同道。”

同什么道？“禹思天下有溺者，由己溺之也；稷思天下有饥者，由己饥之也，是以如是其急也。”——禹想到天下有人被淹，像自己被淹；稷想到天下有人挨饿，像自己挨饿；所以他们才这样急。

“禹、稷、颜子易地则皆然。”——换了位置，三个人都一样。

最后一段是比喻：“今有同室之人斗者，救之，虽被发缨冠而救之，可也。乡邻有斗者，被发缨冠而往救之，则惑也，虽闭户可也。”

同屋的人打架，来不及束发正冠就去救，可以；邻居打架，披头散发跑去救，就是糊涂——关上门也可以。

此章驳谁：驳”出处异则道异”（做官与隐居是两条道）。立什么：立”心一而事异”，立”急有分”。留给后人什么：一扇门，一条陋巷。

二　经文

【经】禹、稷当平世，三过其门而不入，孔子贤之。颜子当乱世，居于陋巷，一箪食，一瓢饮，人不堪其忧，颜子不改其乐，孔子贤之。孟子曰：“禹、稷、颜回同道。禹思天下有溺者，由己溺之也；稷思天下有饥者，由己饥之也，是以如是其急也。禹、稷、颜子易地则皆然。今有同室之人斗者，救之，虽被发缨冠而救之，可也。乡邻有斗者，被发缨冠而往救之，则惑也，虽闭户可也。”

三　字义与句读

平世／乱世　治世／乱世。**这是全章的坐标：不是人不同，是世不同。

三过其门而不入　治水在外，三次经过自家门而不入。

箪食瓢饮　一竹器饭，一瓢水。**极简的食具，极简的生活。

同道　同一个道。**不是”同样的事”，是”同样的心”。

由己　“由”同”犹”，如同。

易地　交换位置。

被发缨冠　来不及束发，只把冠带系上。**形容急到什么程度。

闭户　关门。

句读一处：“禹、稷、颜子易地则皆然”——“易地”是假设：换一个位置，三个人都会做对方做的事。 不是说三人已经换过。

四　今译

禹和稷在治世，三次经过自家门口都不进去，孔子称赞他们。颜子在乱世，住在陋巷，一竹篮饭，一瓢水，别人受不了那种苦，颜子不改他的快乐，孔子称赞他。孟子说：“禹、稷、颜回是同一个道。禹想到天下有人被水淹，就像自己被淹；稷想到天下有人挨饿，就像自己挨饿，所以他们才这样急。禹、稷、颜子如果换了位置，都会这样。假如同屋的人打架，去救他，即使来不及束发、只系上冠带就去，也是可以的。假如邻居打架，披头散发跑去救，那就是糊涂，关上门也是可以的。”

五　章旨

心一而事异：进则救民，退则修己；急有其分，救有其界。

五条支撑：

  1. 两个”孔子贤之”并列。 一仕一隐，同得贤名——这是全章的判。
  2. “同道”是心同，不是事同。 朱熹说”其心一而已矣”。
  3. “由己溺、由己饥”是急的来处。 急不是因为责任，是因为”像自己的事”。
  4. “易地则皆然”是推想，也是判语。 三人可互换，说明道不分仕隐。
  5. “同室／乡邻”是界的比喻。 急到什么程度，看距离有多近。

六　注家

【朱熹曰】“圣贤之道，进则救民，退则修己，其心一而已矣。”（《孟子集注·离娄下》）

【朱熹曰】“圣贤之心无所偏倚，随感而应，各尽其道。”（同上）

【朱熹曰】“尹氏曰：‘当其可之谓时。’”（同上，引尹焞说）

【赵岐注】禹、稷急于救民，颜子安于修己，其道一也；同室之斗当救，乡邻之斗可闭户，言急有远近。（按：此为赵注大意，非原文。）

对照：赵岐以”急有远近”解末段；朱熹以”进则救民，退则修己，其心一”解全章，又引尹氏”当其可之谓时”，把”分”落在”时”上。赵明其急，朱定其时。

七　分寸与边界

  1. 不可读成”隐者亦圣、仕者亦圣”的相对主义。**孟子说的是”同道”，不是”同道者皆圣”。
  2. 不可读成”做官高于隐居”。**两个”贤之”是并列的。
  3. 不可把”易地”读成事实。**这是假设语。
  4. 不可把”闭户”读成冷漠。**闭户是”不该越的界”。
  5. 不可把”被发缨冠”读成失礼。**这是”急”，急到礼也来不及。

八　义理

这一章在处理一个古老的对立：做事的人与不做事的（或做别的事的）人，谁更高？

孟子的答法极干净：先摆两个”孔子贤之”。 治水三过门不入，贤；陋巷箪食瓢饮，也贤。两个都是贤，谁也没压过谁。 判语是孔子给的，孟子只是把它摆出来——这一摆，就把”谁更高”的问题取消了。

然后是”同道”。 同的是什么？朱熹一句”其心一而已矣”。心一是”天下有人被淹，像自己被淹”；事异是”一个去治水，一个守着陋巷”。 心同而事异，这才是”同道”的真正意思。不是做同样的事，是拿同一颗心去做不同的事。

“由己溺之”“由己饥之”，是全章最重的一句。 这不是”责任感”，责任还隔一层。“由己”是”如同自己”：别人的淹，就是我的淹。 有这一层，才有”如是其急”。

末段的比喻，替这一章装了刹车。 同屋的人打架，你连头发都来不及束就冲过去，对；邻居打架，你披头散发冲过去，就糊涂。差别不在”该不该救”，在”该救到什么程度”。 孟子在这里说的不是”冷漠”，是“急要有分寸”——同屋的斗会烧到你的房子，邻居的斗不会。

这一章给出的，是一把尺：心要一，事要分。 心不一，则事事都是别人的事；事不分，则处处都要扑上去。前者冷，后者乱。孟子两个都不要。

九　时代之问

  • 我做的这份事，是”进则救民”，还是”退则修己”？我知道了没有？
  • 我心里有没有”由己溺之”的那一层？还是只有”这事归我管”？
  • 我的急，是对同屋的，还是对邻居的？
  • 我是不是把”不救”说成”有分寸”，把”分寸”说成”不救”？
  • 我这一生，能不能换一个位置也做得成？

十　跨典

  • 《论语·泰伯》“禹，吾无间然矣”——禹之贤。
  • 《论语·雍也》“一箪食，一瓢饮，在陋巷”——颜子之乐。
  • 《孟子·尽心上》“穷则独善其身，达则兼善天下”——同一结构。
  • 《孟子·滕文公下》“三过其门而不入”——禹之实。
  • 《礼记·大学》“修身齐家治国平天下”——次第。
  • 《庄子·让王》“颜回不改其乐”——颜子之乐的另一记。

十一　存疑

  1. “平世”与”乱世”的分界。 禹稷之世未必尽平，此为相对言。
  2. “三过其门”的数目。 一说”三”为虚数。
  3. 颜子所乐何指。 朱熹他处曰”乐道”，此处不说。
  4. “易地则皆然”是否孟子自设之辞。 文气上是判语。
  5. “同室”“乡邻”是否实指。 此为设喻。

图位　图二十六｜门·陋巷

读图三处：

  1. 门半开，足迹不停。 “三过而不入”，过而不入才是过。
  2. 巷是窄的，窄到只容一人。 陋巷之”陋”，在宽度上。
  3. 一箪一瓢在巷中。 极简的两件食器，撑起”不改其乐”。

图说一句：一个是过门不入，一个是守在巷里——同一条心，两种走法。
