第二百二十二章　亲亲仁民

一　本章导读

“君子之于物也，爱之而弗仁。”

——君子对于草木禽兽，爱惜它，但不用”仁”去待它。

“于民也，仁之而弗亲。”

——对于百姓，用”仁”去待他，但不亲他。

“亲亲而仁民，仁民而爱物。”

——亲自己的亲人，才扩展到仁百姓；仁百姓，才扩展到爱万物。

三句，两个”弗”，一条次序。这一章是全篇最讲”层次”的一章。

程子说： “仁，推己及人，如老吾老以及人之老。于民则可，于物则不可。统而言之则皆仁，分而言之则有序。”

杨氏说： “其分不同，故所施不能无差等，所谓理一而分殊者也。”

此章驳谁：驳”一视同仁”——把”同”当成”等”。立什么：立”理一而分殊”。留给后人什么：三个同心圆。

二　经文

【经】孟子曰：“君子之于物也，爱之而弗仁；于民也，仁之而弗亲。亲亲而仁民，仁民而爱物。”

三　字义与句读

物　朱熹曰”物，谓禽兽草木”。

爱　朱熹曰”爱，谓取之有时，用之有节”。

弗仁　不用”仁”这一层。

亲　亲爱，血亲之情。

亲亲　第一个”亲”是动词，第二个指亲人。

句读一处：“爱之而弗仁”“仁之而弗亲”两句，都是”先肯定一层，再拦住一层”。 合为”对他有爱，但不升到仁；对他有仁，但不升到亲”。 若把”弗仁”“弗亲”读成”不仁”“不亲”，就把”已有一层”读成了”一层都没有”，正好反了。

四　今译

孟子说：“君子对于草木禽兽，爱惜而不以仁相待；对于百姓，以仁相待而不以亲相亲。亲爱亲人，才推及仁百姓；仁百姓，才推及爱万物。”

五　章旨

爱、仁、亲三层，各有所止；止不是缺，是次序。

五条支撑：

  1. “弗仁”“弗亲”是”止于此”，不是”无此”。
  2. “爱”取”有时有节”——物之爱，是用法不是感情。
  3. “仁”是推己及人，只对人说。
  4. “亲”是本于血亲，只对亲人说。
  5. “亲亲而仁民，仁民而爱物”，三个”而”是次第，不是并列。

六　注家

【朱熹曰】“物，谓禽兽草木。爱，谓取之有时，用之有节。”（《孟子集注·尽心上》）

【程子曰】“仁，推己及人，如老吾老以及人之老，于民则可，于物则不可。统而言之则皆仁，分而言之则有序。”（朱熹引）

【杨氏曰】“其分不同，故所施不能无差等，所谓理一而分殊者也。”（朱熹引）

【尹氏曰】“何以有是差等？一本故也，无伪也。”（朱熹引）

【赵岐注】物可以爱而不可仁，民可以仁而不可亲；亲亲然后仁民，仁民然后爱物。（按：此为赵注大意，非原文。）

对照：赵岐只列层次，程子分出”统／分”两观，杨氏标出”理一分殊”四字，尹氏补一个”一本”。赵列其层，程分其观，杨立其名，尹溯其本。

七　分寸与边界

  1. 不可把”弗仁”读成”不仁”。** 有爱，只是不到”仁”这一层。
  2. 不可把”弗亲”读成”不亲”。** 有仁，只是不到”亲”这一层。
  3. 不可把”爱物”读成”爱惜动物”。** 朱熹说”取之有时，用之有节”。
  4. 不可把”差等”读成”歧视”。** 差等是次序，歧视是无故。
  5. 不可把”理一”读成”都一样”。** 理一是同源，分殊是分层。

八　义理

这一章讲的是”爱的容量”问题。

一个人爱的总量是有限的。 这话孟子不说，但整章都在这上面。

“君子之于物也，爱之而弗仁。”

对草木禽兽，可以有爱，但不给”仁”。 为什么？朱熹注”爱，谓取之有时，用之有节”。

——对物的”爱”，不是抱它，是用它有分寸。 该砍的时候砍，该猎的时候猎，只是不滥。

这其实是最难的一种”爱”。 因为它不含感情，只含节制。

“于民也，仁之而弗亲。”

对百姓，可以仁，但不给”亲”。

“仁”是什么？程子说”推己及人，如老吾老以及人之老”。 是把自己的一份推出去。

推出去的，和原来那份，是不同的。 老吾老，是亲；以及人之老，是仁。

注意程子加的一句： “于民则可，于物则不可。”

——推己及人，只能推到人。 推到禽兽身上，就成了”以人之情加于物”，那不是仁，是滥。

最后一句是次序： “亲亲而仁民，仁民而爱物。”

三个”而”，是”先……然后……“。 先亲亲，才谈仁民；先仁民，才谈爱物。

杨氏说： “其分不同，故所施不能无差等，所谓理一而分殊者也。”

——“理一”是同源，“分殊”是分层。 同一个源头，不同的施法。

尹氏又追了一层： “何以有是差等？一本故也，无伪也。”

——“一本”，是说这些层次不是人为划的，是从一个根上长出来的。 “无伪”，是说它不假。

这两句合起来，把”差等”从”等级”里救出来了。 等级是外面加的，差等是里面长的。

图上三个同心圆，同一个圆心。

内圆一个”亲”字，中环一个”民”字，外环一个”物”字。

上方”理一而分殊”，其下一行”统而言之则皆仁，分而言之则有序”。

下方一行”亲亲 → 仁民 → 爱物”。

——三个圈共一个心，这是”理一”；三个圈半径不同，这是”分殊”。

一个字：同心，不等于同圈。

九　时代之问

  • 我对”物”的爱，是有节制的用法，还是滥情？
  • 我对”民”的仁，是从自己推出去的，还是从概念出发的？
  • 我把”一视同仁”当成了”一样对待”吗？
  • 我的”亲”，有没有先给最该给的人？
  • 我的同心圆，圆心还在吗？

十　跨典

  • 《孟子·梁惠王上》“老吾老以及人之老”——推之序。
  • 《孟子·滕文公上》“爱无差等，施由亲始”——夷子之说，孟子所驳。
  • 《礼记·祭义》“仁者，仁此者也”——一本。
  • 《中庸》“亲亲之杀，尊贤之等”——差等之礼。
  • 《荀子·礼论》“贵贱有等”——另一路的等。
  • 《墨子·兼爱》“爱无差等”——孟子所对。

十一　存疑

  1. “物”是否包括人以外的一切。 朱熹曰”禽兽草木”。
  2. “爱”是否为”节用”。 朱熹曰”取之有时，用之有节”。
  3. “弗仁”是否即”不仁”。 朱熹以”爱之而弗仁”为”爱而不能仁”，是有层次的。
  4. “理一分殊”是否朱子学专用。 杨氏已言之，朱熹承之。
  5. 本章与《滕文公上》夷子之辩。 彼言”爱无差等”，此章正面立差等。
