第二百五十八章　养心莫善于寡欲

一　本章导读

“养心莫善于寡欲。”

——养心，没有比少欲更好的。

“其为人也寡欲，虽有不存焉者，寡矣；其为人也多欲，虽有存焉者，寡矣。”

——一个人欲少，纵然有存不住的，也少；一个人欲多，纵然有存得住的，也少。

二十八字，一副药方，两个”寡”字。 一个说”欲寡”，一个说”存者寡”.

朱熹说： “欲，如口鼻耳目四支之欲，虽人之所不能无，然多而不节，未有不失其本心者，学者所当深戒也。”

程子曰： “所欲不必沈溺，只有所向便是欲。”

此章驳谁：驳”多欲亦可以存心”。立什么：立”寡欲”为养心第一方。留给后人什么：一个心（圆），左边三两点细流，右边一片密点；心在左则圆，在右则缺。

二　经文

【经】孟子曰：“养心莫善于寡欲。其为人也寡欲，虽有不存焉者，寡矣；其为人也多欲，虽有存焉者，寡矣。”

三　字义与句读

养心　存养本心。

寡欲　少其所欲。

不存　本心存不住。

存　本心存得住。

句读一处：两个”寡”字不是同一个”寡”. 前一个”寡欲”的”寡”是”少”，后一个”不存焉者寡矣”“存焉者寡矣”的”寡”是”少有幸免”. 若两处读成一义，后半句就成了同语反复；孟子恰恰用同一个字，说两件相反的事。

四　今译

孟子说：“养心没有比少欲更好的。一个人欲少，纵然有存不住的时候，也少；一个人欲多，纵然有存得住的时候，也少。”

五　章旨

一句断语，两句反证；字少而缝密。

五条支撑：

  1. “莫善于”是最高级，不留余地。
  2. “寡欲”不是”无欲”——朱熹明言”不能无”.
  3. 前句留了”虽有不存”的余地，故不绝对。
  4. 后句留了”虽有存”的余地，故不刻薄。
  5. 两个”寡”字把概率说成结果：多欲者，存是偶然。

六　注家

【朱熹曰】“欲，如口鼻耳目四支之欲，虽人之所不能无，然多而不节，未有不失其本心者，学者所当深戒也。”（《孟子集注·尽心下》）

【程子曰】“所欲不必沈溺，只有所向便是欲。”（朱熹引）

【赵岐注】养心之道，莫过寡欲；寡欲则心存者多，多欲则心失者多。（按：此为赵注大意，非原文。）

对照：赵岐只说”多寡之效”，朱熹先定”欲不能无”再定”多而不节必失”，程子更把”欲”的门槛压到”所向”。赵言其效，朱定其界，程压其门。

七　分寸与边界

  1. 不可把”寡欲”读成”无欲”.** 朱熹曰”人之所不能无”.
  2. 不可把”欲”只读成”贪财好色”.** 朱熹曰”口鼻耳目四支之欲”.
  3. 不可把”不存”读成”心不在”.** 是”本心存不住”.
  4. 不可把”多欲”读成”欲多”.** 是”多而不节”.
  5. 不可把本章读成”禁欲”.** 是”节”，不是”绝”.

八　义理

这一章只有二十八个字，却是全书最像药方的一段。

“养心莫善于寡欲。”

——养心，没有比少欲更好的。

“莫善于”是最高级。 孟子不给第二个方子。

但要紧的是”寡”，不是”无”. 朱熹先把门框定住：“虽人之所不能无。”

——欲是人不能没有的。 口要食，目要色，身要安——这些不是罪，是身。

问题不在”有”，在”多而不节”。

“其为人也寡欲，虽有不存焉者，寡矣。”

——欲少的人，也有存不住的时候，但少。

注意孟子没有说”必存”。 他说”虽有不存焉者，寡矣”。

这一句极诚实。 寡欲的人也会失守，只是失守的时候少。

“其为人也多欲，虽有存焉者，寡矣。”

——欲多的人，也有存得住的时候，但少。

这一句更狠。 不是”必失”，是”存是偶然”。

两句合看，才见孟子的分寸： 他不给保证，只给概率；不说”一定”，只说”多”与”少”。

而概率累积起来，就是一生。

程子一句，把”欲”的门槛压到最低：

“所欲不必沈溺，只有所向便是欲。”

——不必沉溺才算欲，心一向那边去，就是欲。

这一句把”寡欲”从”戒大事”改成了”管方向”. 不是等它长成大欲才管，是它刚一偏就收。

图上：一个圆（心）在中央。

左侧三条细流（少）注入，圆心完整。

右侧十余条细流（多）注入，圆心被挤出一个缺口。

左注”寡欲·存者多”，右注”多欲·存者少”。

底部：“寡，非无也；节而已。”

——同是一颗心，左边细流，右边密流。

九　时代之问

  • 我的”欲”，有几条在流？
  • 我节的是大的，还是小的？
  • 我心一向那边去的时候，我知道吗？
  • 我”存”的时候，是常还是偶？
  • 我把”寡”读成”无”了吗？

十　跨典

  • 《孟子·尽心下》“尧舜性者也”——上章，“性”与”欲”相对。
  • 《孟子·告子上》“从其大体为大人”——大体小体之辨。
  • 《孟子·离娄下》“养心”（他处之语）。
  • 《论语·颜渊》“克己复礼”——节之正路。
  • 《老子》第四十八章”为道日损”——寡之另一说法。
  • 《荀子·劝学》“其数则始乎诵经”——养之次第。

十一　存疑

  1. “欲”的范围。 朱熹限于”口鼻耳目四支”，程子扩至”所向”.
  2. “不存”是否指”心亡”. 注家作”本心不存”.
  3. 本章是否专为学者说。 朱熹曰”学者所当深戒”.
  4. “寡”是否可作”少而精”. 注家只作”少”.
  5. 孟子是否另有”节欲”之方。 本书取”寡”字，不外添。

十二　双卡与图

俗见 正解
寡欲即无欲 朱熹曰”人之所不能无”
欲只是贪财好色 朱熹曰”口鼻耳目四支之欲”
不存即心不在 是”本心存不住”
多欲即欲多 是”多而不节”
本章是禁欲 是”节”，不是”绝”

图位　图二百五十八｜一心在中·左三细流·右十余密流·圆心左全右缺

读图三处：

  1. 流的数目不同，流的方向相同。 欲不能无，只在多少。
  2. 缺口在右。 失守不是一下子，是被挤出来的。
  3. 心只有一个。 左边满了，右边就缺。

图说一句：寡，非无也；节而已。
