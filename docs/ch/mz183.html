第一百八十三章　无耻之耻

一　本章导读

“人不可以无耻。”

——人不可以没有羞耻。

“无耻之耻，无耻矣。”

——以”无耻”为耻，就没有耻辱了。

九个字，一个转。

赵岐说： “人能耻己之无所耻，是能改行从善之人，终身无复有耻辱之累矣。”

——人若能以”自己没有可耻之事”为耻，就是能改行从善的人，终身不再受耻辱之累。

此章驳谁：驳”无耻而不自知”。立什么：立”耻其无耻”。留给后人什么：两张脸，一张平，一张有痕。

二　经文

【经】孟子曰：“人不可以无耻。无耻之耻，无耻矣。”

三　字义与句读

无耻　无羞恶之心。

无耻之耻　以”无耻”为耻。

无耻矣　不再有耻辱。

句读一处：“无耻之耻，无耻矣”——上”无耻”是名词（无耻这件事），下”无耻”是动词性（没有耻辱）。同字两用，是全章的机关。

四　今译

孟子说：“人不可以没有羞耻。以’无耻’为耻，就没有耻辱了。”

五　章旨

耻的可贵，不在有耻，在”耻其无耻”；一耻转，则终身无累。

五条支撑：

  1. “人不可以无耻”是一句通令，不是一句描写。
  2. “无耻之耻”把耻的对象翻了一层。
  3. “无耻矣”是翻转后的果：无累。
  4. 赵岐”改行从善”四字，说出这一耻的用处。
  5. 全章九字，重心在第二个”耻”。

六　注家

【赵氏曰】“人能耻己之无所耻，是能改行从善之人，终身无复有耻辱之累矣。”（朱熹《集注》引）

【朱熹曰】“此言人不可无耻，而耻之尤莫大于无耻。”（《孟子集注·尽心上》大意）

【按】此章与下章”耻之于人大矣”相承：此章言”耻无耻”，下章言”耻之大”。

对照：赵岐重”改行从善”，朱熹重”耻莫大于无耻”。赵言其效，朱定其重。

七　分寸与边界

  1. 不可把”人不可以无耻”读成”人不可有羞耻”。** 断句为”不可以／无耻”。
  2. 不可把”无耻之耻”读成”不知羞耻”。** 是”以无耻为耻”。
  3. 不可把”无耻矣”读成”从此不要脸”。** 是”无复耻辱之累”。
  4. 不可把本章读成”自责”。** 是”自耻”，自责者外，自耻者内。
  5. 不可把九字看作格言。** 它是一次翻转。

八　义理

九字一章，是《孟子》里最精的几处之一。

“人不可以无耻。”——先立一个底线：人不能没有羞耻。

可问题在于： 有一种人，他恰恰”没有羞耻”，而且不自知。

他对自己的无耻，不以为耻。 这是最深的一层病。

孟子说： “无耻之耻，无耻矣。”

——把”无耻”这件事本身当作耻辱，那就没有耻辱了。

为什么？ 赵岐说透了：“能耻己之无所耻，是能改行从善之人。”

——一个人开始”为自己没有羞耻而羞耻”，他就已经站到”能改”的位置上了。

这一转，比任何自责都深。

自责是对”做过的事”悔；自耻是对”没有的感觉”痛。

悔可以过去；痛，才开始。

“终身无复有耻辱之累矣”——为什么？ 因为从此他有耻了。 有耻的人，不必再受”无耻”之累。

两个”无耻”，字同义反： 前一个是病，后一个是愈。

两张脸。 左边一张平的：眼平、嘴平，什么都不缺，缺的是”耻”。

右边一张有痕的：三道赭色的斜纹，落在颊上。

从平到有痕，就是”无耻之耻”。

孟子没有骂那个人，他只说了一句：你可以耻。

九　时代之问

  • 我有没有”不以为耻”的事？
  • 我会为”自己没有感觉”而痛吗？
  • 我的自责，停在”事”，还是到”心”？
  • 我的脸上，有那三道痕吗？
  • 我”改行从善”过吗？

十　跨典

  • 《论语·里仁》“君子耻其言而过其行”——耻之言。
  • 《孟子·公孙丑上》“无羞恶之心，非人也”——耻之根。
  • 《孟子·尽心上》“耻之于人大矣”——下章承此。
  • 《礼记·中庸》“知耻近乎勇”——耻之力。
  • 《荀子·劝学》“无廉耻”之戒。
  • 《管子·牧民》“礼义廉耻”——四维。

十一　存疑

  1. 本章之次第。 紧接”习而不察”，皆言”心之失”。
  2. “无耻之耻”之读。 一说”无耻，是可耻的”，文义略异。
  3. 朱熹此章之解。 《集注》文字简，诸本略有出入。
  4. “终身无复有耻辱之累”是否赵注原文。 朱熹引作”赵氏曰”，今赵注本略同。
  5. 九字是否完章。 诸本皆独立。
