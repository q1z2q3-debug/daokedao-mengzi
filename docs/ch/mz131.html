第一百三十一章　观其所主

一　本章导读

万章问：“或谓孔子于卫主痈疽，于齐主侍人瘠环，有诸乎？”——有人说孔子在卫国住在痈疽家，在齐国住在宦官瘠环家，有这回事吗？

孟子答：“否，不然也。好事者为之也。”——没有。这是好事的人编的。

“于卫主颜雠由。弥子之妻与子路之妻，兄弟也。弥子谓子路曰：‘孔子主我，卫卿可得也。’子路以告。孔子曰：’有命。’”

——孔子在卫，住在颜雠由家。弥子的妻子与子路的妻子是姐妹。弥子对子路说：孔子若住我家，卫国的卿位可以得到。 子路告孔子。孔子说：“有命。”

然后孟子讲了一套极清楚的判人法：

“孔子进以礼，退以义，得之不得曰’有命’。而主痈疽与侍人瘠环，是无义无命也。”

后面两段反证：孔子不悦于鲁、卫，遭宋桓司马将要而杀之，微服而过宋。 那时孔子在宋，主司城贞子，为陈侯周臣。若真是住在痈疽、瘠环家，那孔子就”无义无命”了。

最后一句是全章的名言：

“观近臣，以其所为主；观远臣，以其所主。”

——看朝廷的近臣，看他接待什么人；看外来的远臣，看他住在谁家。

此章驳谁：驳”孔子主痈疽、瘠环”。立什么：立”进以礼，退以义”、“观其所主”。留给后人什么：一扇门，门外一人，门内一人，一条双向的虚线。

二　经文

【经】万章问曰：“或谓孔子于卫主痈疽，于齐主侍人瘠环，有诸乎？”孟子曰：“否，不然也。好事者为之也。于卫主颜雠由。弥子之妻与子路之妻，兄弟也。弥子谓子路曰：‘孔子主我，卫卿可得也。’子路以告。孔子曰：’有命。’孔子进以礼，退以义，得之不得曰’有命’，而主痈疽与侍人瘠环，是无义无命也。孔子不悦于鲁、卫，遭宋桓司马将要而杀之，微服而过宋。是时孔子当厄，主司城贞子，为陈侯周臣。吾闻观近臣，以其所为主；观远臣，以其所主。若孔子主痈疽与侍人瘠环，何以为孔子？”

三　字义与句读

主　朱熹曰”主，谓舍于其家，以之为主人也”。**住在他家，以他为东道。

痈疽　朱熹曰”疡医也”。**此处为人名，是卫灵公的宠臣。

侍人　朱熹曰”奄人也”。**宦官。

瘠环　宦官之名。

颜雠由　卫国贤大夫。

弥子　弥子瑕，卫灵公宠臣。

兄弟　此处指”姐妹”。

有命　朱熹曰”命，谓天命”。**得与不得，由命。

进以礼，退以义　进而以礼，退而以义。

要而杀之　朱熹曰”要，遮也”。**中途拦截要杀他。

微服　穿便服。

司城贞子　宋国贤大夫。

陈侯周　陈国君主，名周。

近臣／远臣　在朝的臣／外来的臣。

句读一处：“进以礼，退以义，得之不得曰’有命’”——三句并列：进、退、得不得。 前两条是他怎么做，第三条是他怎么接受结果。

四　今译

万章问：“有人说孔子在卫住在痈疽家，在齐住在宦官瘠环家，有这回事吗？”孟子说：“不，不是。这是好事的人编的。孔子在卫住在颜雠由家。弥子的妻子与子路的妻子，是姐妹。弥子对子路说：‘孔子若住我家，卫卿之位可以得到。’子路告诉了。孔子说：’有命。’孔子进而以礼，退而以义，得与不得都说’有命’——若住在痈疽和宦官瘠环家，那就是无义无命了。孔子在鲁、卫不得意，遇上宋国桓司马要在途中拦杀他，就换了便服过宋。那时孔子正在困厄，住在司城贞子家，做了陈侯周的臣。我听说：看近臣，看他接待什么人；看远臣，看他住在谁家。若孔子真住在痈疽和宦官瘠环家，那还凭什么称孔子？”

五　章旨

进以礼，退以义，得不得曰有命；观人者，观其所主。

五条支撑：

  1. “好事者为之”是全章的断。 一句话判它是编的。
  2. “主颜雠由”是事实。 贤大夫，不是宠臣。
  3. “卫卿可得”是诱。 弥子把位置摆在门口。
  4. “有命”两字是拒。 不说不去，说”有命”。
  5. “观其所主”是留给后人的法。 近臣看客，远臣看主。

六　注家

【朱熹曰】“主，谓舍于其家，以之为主人也。痈疽，疡医也。侍人，奄人也。……好事，谓喜造言生事之人也。”（《孟子集注·万章上》）

【朱熹曰】“进以礼，退以义，得之不得曰有命。”（同上）朱熹曰：“言其进退有据，而不苟也。”

【朱熹曰】“要，遮也。……微服，常服也。……司城贞子，宋之贤大夫也。”（同上）

【朱熹曰】“观近臣以其所为主，观远臣以其所主。”（同上）朱熹曰：“主，犹依也。……言近臣之贤否，视其所宾主；远臣之贤否，视其所依托。”

【赵岐注】孔子主颜雠由、司城贞子，皆贤者；主痈疽、瘠环之说，好事者为之。（按：此为赵注大意，非原文。）

对照：赵岐断其为诬；朱熹以”进以礼，退以义”六字立孔子之守，又以”观其所主”立后人之法。赵辨其事，朱立其法。

七　分寸与边界

  1. 不可把”有命”读成”无所谓”。**它是”不因可得而失守”。
  2. 不可把”主”读成”投靠”。**是寄宿，非依附。
  3. 不可把”观其所主”读成”看门第”。**看的是”谁”，不是”何等”。
  4. 不可忽略”当厄”这个处境。**困厄之时，仍择主而居。
  5. 不可把”何以为孔子”读成意气语。**它是全章的推论句：若如此，则非孔子。

八　义理

这一章是辨诬，但真正的收获是一把尺。

先看诬辞的形状。 “孔子于卫主痈疽，于齐主侍人瘠环”——痈疽是疡医，瘠环是宦官。 两个都是君王身边最贴身的人。这条诬辞的用意很清楚：说孔子也走内线。

孟子的驳法，是给出事实：主颜雠由，主司城贞子。 两个都是贤大夫。再加上一段：弥子拿”卫卿可得”来诱他，他答”有命”。 ——这是最有力的反证：位置摆在面前，他不要。

然后他给出判人的原则： “进以礼，退以义，得之不得曰有命。”三条：进有据，退有据，结果不论。 一个这样的人，不可能住在宠臣家求位——“是无义无命也”。

最后那句是留给两千年的： “观近臣，以其所为主；观远臣，以其所主。”在朝的，看他家里来什么人；外来的，看他住在谁家。 这一句极实用：人是被他所交往的人定义的。

孟子收得也狠： “若孔子主痈疽与侍人瘠环，何以为孔子？”——若真是这样，那就不是孔子了。 这不是骂人，是逻辑：一个人的行为与他的名，必须相称。

九　时代之问

  • 我进的时候，有据吗？退的时候，有据吗？
  • 一个位置摆在面前，我说的是”我要”，还是”有命”？
  • 我住在谁家？我接待什么人？
  • 我被人编排过吗？我用事实驳，还是用情绪驳？
  • 我的”名”，还配我的”行”吗？

十　跨典

  • 《论语·里仁》“不义而富且贵，于我如浮云”——不进以非礼。
  • 《论语·述而》“富而可求也，虽执鞭之士，吾亦为之”——有命之辨。
  • 《孟子·滕文公下》“孔子微服而过宋”——同事异记。
  • 《史记·孔子世家》“孔子适卫，主于子路妻兄颜浊邹”——名之异写。
  • 《礼记·表记》“君子不以色亲人”——择主。
  • 《荀子·劝学》“居必择乡，游必就士”——所主之重。

十一　存疑

  1. “痈疽”是人名还是病名。 朱熹以为疡医，此处当是人名。
  2. “颜雠由”与《史记》“颜浊邹”。 一人异写。
  3. “侍人瘠环”之事。 诸书无考。
  4. “为陈侯周臣”一句。 旧解有异，一说”为陈侯周之臣”是”陈侯周”为人名。
  5. “观其所主”的适用范围。 朱熹就”臣”言，后世广用于择友。
