第八十章　事亲守身

一　本章导读

这一章把”孝”从一件感情的事，讲成一件有本末的事：

事孰为大？事亲为大；守孰为大？守身为大。

——侍奉谁最大？侍奉父母最大；守住什么最大？守住自身最大。

然后给出两句判语：不失其身而能事其亲者，吾闻之矣；失其身而能事其亲者，吾未之闻也。

接着是本末的定位：孰不为事？事亲，事之本也；孰不为守？守身，守之本也。

全章的后半，是曾家父子两代的一段实录，差别只在一个动作上：

曾子养曾皙，必有酒肉。将彻，必请所与；问有余，必曰”有”。

曾皙死，曾元养曾子，必有酒肉。将彻，不请所与；问有余，曰”亡矣”——将以复进也。

孟子据此下断：此所谓养口体者也。若曾子，则可谓养志也。事亲若曾子者，可也。

此章驳谁：驳”孝就是供养”“给得越多越孝”。立什么：立”守身为本”，立”养志”与”养口体”的分界。留给后人什么：一张撤席的食案，一双把余食往外递的手，和一个”可也”的止字。

二　经文

【经】孟子曰：“事孰为大？事亲为大；守孰为大？守身为大。不失其身而能事其亲者，吾闻之矣；失其身而能事其亲者，吾未之闻也。孰不为事？事亲，事之本也；孰不为守？守身，守之本也。

【经】“曾子养曾皙，必有酒肉。将彻，必请所与；问有余，必曰’有’。曾皙死，曾元养曾子，必有酒肉。将彻，不请所与；问有余，曰’亡矣’。将以复进也。此所谓养口体者也。若曾子，则可谓养志也。事亲若曾子者，可也。”

三　字义与句读

守身　朱熹：“守身，持守其身，使不陷于不义也。”——不是”保命”，是”不陷于不义”。

亏体辱亲　朱熹：“一失其身，则亏体辱亲，虽日用三牲之养，亦不足以为孝矣。”——“辱亲”二字最重：身一失，孝就断了根。

彻　撤去食器。“将彻”是饭刚吃完、还没收走的那一瞬。

所与　朱熹：“必请于父曰：‘此余者与谁？’”——问的是”剩下的给谁”，不是”还剩多少”。

亡　朱熹：“虽有言无。”读如”无”。曾元说”没有了”，其实还有——留给父亲下顿再吃。

复进　朱熹：“其意将以复进于亲，不欲其与人也。”——“复进”是再端上来，不是再做一份。

口体／志　朱熹：“此但能养父母之口体而已。曾子则能承顺父母之志，而不忍伤之也。”

句读一处：“将彻，必请所与；问有余，必曰’有’。”——两个动作的主语都是曾子：先问”给谁”，再答”有”。 若把”问有余”读成”父亲问还有没有”，则答”有”的是曾子；两读皆通，但只有前者能显出”他愿意把余下的给出去”这一层。

四　今译

孟子说：“侍奉谁最大？侍奉父母最大；守什么最大？守住自身最大。不失自身而能侍奉父母的，我听说过；失了自身而能侍奉父母的，我没听说过。谁没有要侍奉的人？侍奉父母，是侍奉的根本；谁没有要守的？守身，是守的根本。

“曾子奉养曾皙，每餐必有酒肉。撤席时，一定问剩下的给谁；父亲问还有没有，一定说’有’。曾皙死后，曾元奉养曾子，每餐必有酒肉。撤席时不问给谁；问还有没有，就说’没有了’——是想留着再端上来。这叫作养口体。像曾子那样，才叫养志。侍奉父母能像曾子这样，也就可以了。”

五　章旨

孝有两层：一层是让父母吃好，一层是不让父母为你蒙羞；而”守身”是这两层的地基。

五条支撑：

  1. “事亲为大”不是排他，是定位。 孟子说”事亲，事之本也”——本是根，不是全部；根一断，枝叶都枯。
  2. “守身为大”把孝从”给”翻成”守”。 世人以为孝是往外拿，孟子说孝是先守住自己：身一失，拿什么都是脏的。
  3. “吾未之闻也”是一句硬话。 不是”很少见”，是”没有”。失身而能事亲，在孟子这里不成立。
  4. 曾子与曾元的差别，只在一个动作。 一个”必请所与”，一个”不请”；一个”必曰有”，一个”曰亡”。同样的酒肉，两种心。
  5. “可也”是全章的止字。 程子说”事亲若曾子可谓至矣，而孟子止曰可也”——孟子不给”至”，只给”可”：孝没有满分。

六　注家

【朱熹曰】“守身，持守其身，使不陷于不义也。一失其身，则亏体辱亲，虽日用三牲之养，亦不足以为孝矣。”（《孟子集注·离娄上》）

【朱熹曰】“事亲孝，则忠可移于君，顺可移于长。身正，则家齐、国治、而天下平。”（同上）

【朱熹曰】“曾子养其父，每食必有酒肉。食毕将彻去，必请于父曰：‘此余者与谁？’或父问此物尚有余否？必曰’有’。恐亲意更欲与人也。曾元不请所与，虽有言无。其意将以复进于亲，不欲其与人也。”（同上）

【朱熹引程子曰】“子之身所能为者，皆所当为，无过分之事也。故事亲若曾子可谓至矣，而孟子止曰可也，岂以曾子之孝为有余哉？”（同上）

对照：赵岐注此章，重解”守身”与曾、元二事，把”请所与”讲作”承顺亲意”；朱熹则先立”亏体辱亲”四字，把守身与孝接成一条根，再以程子”止曰可也”收住分寸。赵明其事，朱立其本。

七　分寸与边界

  1. 不可把”守身”读成自保、惜命。朱熹训”不陷于不义”；守的是义，不是命。
  2. 不可把”养志”读成满足父母一切要求。志是心意所向，不是欲求清单；顺其志与顺其欲，是两件事。
  3. 不可把曾元读成不孝。他也”必有酒肉”，也想着”复进”；他差的是那一问。
  4. 不可把”三牲之养”当孝的标准。朱熹说得很清楚：失身者，“虽日用三牲之养，亦不足以为孝”。
  5. 不可把”可也”读成孟子的吝啬。“可”是界限：做到了，可以了；再往上，不是加分，是另一件事。

八　义理

这一章把”孝”从情感题材，改造成一份本末表。

先看那个”本”字。 孟子说”事亲，事之本也；守身，守之本也”。他连用两个”本”，是要把两件容易并列的事排出先后：事亲是事之本，守身是守之本。 两者的关系不是并列，是嵌套：守身是根，事亲是干。根不牢，干再高也站不住。

“失其身而能事其亲者，吾未之闻也”，这句为什么说得这么绝？ 因为孟子看见了一件世人常忽略的事：你给父母的东西，是从你这个”人”里拿出来的。 人若不正，拿出来的东西就带着不正；父母吃下去，吃的是儿子的不义。 所以”亏体辱亲”四个字，比”不养”更重：不养只是缺，辱亲是污。

曾子与曾元那一段，是全章的眼睛。 两人都做到了”必有酒肉”，差别只在撤席时的一问。这一问问的是什么？问的是”这剩下的，还能给谁”。 曾子的心是向外的：家里的余食，可以给更需要的人；曾元的心是向内的：余食要留着，明天再端给父亲。一个把父亲放在”人”里，一个把父亲放在”口”里。 孟子用”养口体”与”养志”四个字，把这两种心分开了。

最后那个”可也”。 程子替曾子不平：这样的孝，怎么只说”可”？孟子偏不说”至”。因为孝的标准不在”做了多少”，在”还在不在做”。 一说”至”，人就停了；一说”可”，人还站着。孟子给的不是奖状，是一个可以继续的位置。

九　时代之问

  • 我给父母的，是口体，还是志？
  • 我这一身，有没有让父母蒙羞的地方？
  • 撤席时那一问，我问了吗？
  • 我把”给得多”当成”孝得深”了吗？
  • 我这一格，够得上一个”可”字吗？

十　跨典

  • 《论语·为政》：“今之孝者，是谓能养。至于犬马，皆能有养；不敬，何以别乎？”——“养口体”的孔子版。
  • 《论语·学而》：“身体发肤，受之父母，不敢毁伤。”（《孝经》文，同旨）——“守身”的古训。
  • 《礼记·祭义》：“养可能也，敬为难。”——养与敬的分界。
  • 《大戴礼记·曾子事父母》：“曾子养曾皙”——同一段故事的另一记载。
  • 《孟子·尽心下》“孝子之至，莫大乎尊亲”——孝的顶点在”尊”，不在”养”。
  • 《史记·仲尼弟子列传》：“曾参……孔子以为能通孝道。”——曾子之为孝的样本。

十一　存疑

  1. “守身”的范围。 一说指不苟取、不妄为，一说兼指保身；朱熹以”不陷于不义”为说。
  2. “必请所与”的主语。 一说曾子问父，一说曾子自问；朱熹取前者，亦不排除后者。
  3. “问有余”是父问还是子问。 两读皆通，朱熹并存。
  4. 曾元”曰亡矣”的动机。 朱熹谓”将以复进”，是孝而非吝；今人或读为吝，恐非其本。
  5. “事亲若曾子者可也”是否含批评。 程子以为”止曰可”有分寸，一说只是许之。

图位　图一｜撤席的一问

读图三处：

  1. 那只向外递的手——手是伸出去的，不是收回来的。“请所与”的画法，是手的方向。
  2. 案下的那双鞋，鞋尖朝外——鞋尖的方向，说明这屋里的人是要出门的。余食的去处，在门外。
  3. 门外那道淡淡的人影——它没有脸，只是一个”谁”。曾子问的”谁”，就是这个人。

图说一句：同样的酒肉，一问一不问，养的是两种人。
