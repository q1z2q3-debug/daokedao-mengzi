第一百一十七章　易地皆然

一　本章导读

同一场祸，两个人，两种走法。

曾子在武城，越国来犯。有人劝他：“寇至，盍去诸？”——敌人来了，何不走？曾子走前留下话：“无寓人于我室，毁伤其薪木。”——别让外人住我的屋，别伤我的树。敌人退了，他说：“修我墙屋，我将反。”

子思在卫，齐国来犯。有人劝他走，他说：“如伋去，君谁与守？”——我若走了，谁跟国君守？

孟子判：“曾子、子思同道。曾子，师也，父兄也；子思，臣也，微也。曾子、子思易地则皆然。”

此章驳谁：驳”去者怯、守者忠”的二分。立什么：立”所处之地不同，其心一”；立”身份定义务”。留给后人什么：两扇门，一出一守。

二　经文

【经】曾子居武城，有越寇。或曰：“寇至，盍去诸？”曰：“无寓人于我室，毁伤其薪木。”寇退，则曰：“修我墙屋，我将反。”寇退，曾子反。左右曰：“待先生如此其忠且敬也，寇至则先去以为民望，寇退则反，殆于不可。”沈犹行曰：“是非汝所知也。昔沈犹有负刍之祸，从先生者七十人，未有与焉。”子思居于卫，有齐寇。或曰：“寇至，盍去诸？”子思曰：“如伋去，君谁与守？”孟子曰：“曾子、子思同道。曾子，师也，父兄也；子思，臣也，微也。曾子、子思易地则皆然。”

三　字义与句读

武城　鲁邑，曾子居之。

越寇　越国来犯。

无寓人于我室　别让外人寄住我的屋子。

为民望　朱熹曰”为民望，言使民望而效之”。**“望”，是榜样。

沈犹行　曾子弟子。

负刍之祸　负刍，人名，作乱者。

伋　子思之名，孔伋。

微　朱熹曰”微，犹贱也”。**位卑。

句读一处：“曾子，师也，父兄也；子思，臣也，微也。”——两个身份并置：一个是”师”（如父兄），一个是”臣”（位卑）。 身份不同，义务就不同。

四　今译

曾子住在武城，越国来犯。有人说：“敌人来了，何不走？”曾子说：“别让外人住我的屋，别伤我的树。”敌人退了，他说：“修我的墙屋，我要回去了。”敌人退后，曾子回来了。左右的人说：“这里的人待先生这样忠敬，敌人一来先生就先走，做了百姓的榜样；敌人退了又回来，恐怕不可以。”沈犹行说：“这不是你们能懂的。从前沈犹氏有负刍之乱，跟先生的有七十人，没有一个参与。”子思住在卫，齐国来犯。有人说：“敌人来了，何不走？”子思说：“如果我走了，谁跟国君守？”孟子说：“曾子、子思同道。曾子是师，如父兄；子思是臣，位卑。曾子、子思若换了地方，都会那样做。”

五　章旨

位不同则事不同，心一则道同；“去”与”守”各有其地。

五条支撑：

  1. 曾子走，留两句话。 一句护屋树，一句要回来——**走不是弃。
  2. “为民望”是旁人的责难。 他们认为师当与城共存亡。
  3. 沈犹行一句解释。 曾子之去，是不使门下卷入祸乱。
  4. 子思守，一句”君谁与守”。 守不是忠君，是”我在此位”。
  5. “师／臣”二字是全章的秤。 身份不同，义务就不同。

六　注家

【朱熹曰】“武城，鲁邑。越寇，越兵也。”（《孟子集注·离娄下》）

【朱熹曰】“为民望，言使民望而效之。”（同上）

【朱熹曰】“言师宾不与臣同。”（同上，释曾子之所以可去）

【朱熹曰】“微，犹贱也。言子思为臣，位卑，当与国共存亡。”（同上）

【尹氏曰】“或远害，或死难，其事不同者，所处之地不同也。”（同上，引尹焞说）

【孔氏曰】“若权衡之称物，低昂屡变，而不害其为同也。”（同上，引孔氏说）

【赵岐注】曾子为师，可以去；子思为臣，当守。易地则皆然。（按：此为赵注大意，非原文。）

对照：赵岐以”师可去、臣当守”解；朱熹以”师宾不与臣同”立界，又引尹氏”所处之地不同”、孔氏”权衡称物”，把”同”说成了一个可变的秤。赵分其位，朱明其衡。

七　分寸与边界

  1. 不可读成”逃跑有理”。**曾子之去，有”无寓人”“修墙屋”两句作凭。
  2. 不可读成”守死为高”。**子思之守，因其为臣。
  3. 不可把”民望”读成”榜样即须死”。**此是旁人责难之辞，非孟子之断。
  4. 不可忽略”微”字。**位卑，才当守；位尊，方可去。
  5. 不可把”易地皆然”读成”两人都会做对方的事”。**这是推想说心同。

八　义理

这一章最容易被读成”各有各的道理”，其实不然。

孟子给的不是相对主义，是”位定义务”。 “曾子，师也，父兄也；子思，臣也，微也。”——同一件祸事，一个人的身份决定他该走还是该守。 这不是”看情况”，这是“看你站在哪个位置”。

曾子的”去”，带两句嘱咐。 “无寓人于我室，毁伤其薪木”——走，但护着这一处的物；“修我墙屋，我将反”——走，但明说要回来。 这两句把”走”与”弃”分开了：弃是不回头，走是还要回来。

子思的”守”，只有一句。 “如伋去，君谁与守？”——这不是表忠，这是算账：我走了，这个位子空了。 位子空了，事就断了。所以他不能走。

“为民望”那一段，是旁人的不理解。 他们说：人家待你这样忠敬，你却先走，还做了百姓的榜样——这恐怕不可以。这话听起来很正，其实是把”师”当成了”守将”。 沈犹行的回答不在道德上，在事实上：从前有乱，跟先生的七十人一个都没卷进去。 ——曾子的走，护住的是七十个人。

尹氏”或远害，或死难”，孔氏”权衡称物，低昂屡变而不害其为同”——这两句把本章说透了。 秤在称东西的时候，秤杆一直在动；动的是秤杆，不动的是那颗”称准”的心。 曾子去、子思守，就是秤杆的两次倾斜。

所以”易地则皆然”不是”两人一样”，是”两人若换了位，也都会这么办”。 这一句把”同”从”行为”挪到了”判断”上：同的不是做法，是同一种”该怎么做就怎么做”的心。

九　时代之问

  • 我站在什么位置？这个位置要求我走，还是守？
  • 我的”离开”，有没有留下两句该留的话？
  • 我的”坚守”，是因为位子空了，还是因为我怕人说我？
  • 别人用”民望”责我的时候，我是在守位，还是在守面子？
  • 我能不能换一个位置，也把同一颗心带过去？

十　跨典

  • 《论语·泰伯》“危邦不入，乱邦不居”——去之义。
  • 《论语·宪问》“见危授命”——守之义。
  • 《孟子·尽心上》“穷则独善其身”——去之据。
  • 《孟子·公孙丑下》“君子不以其所以养人者害人”——去之慎。
  • 《礼记·曲礼》“临难毋苟免”——守之节。
  • 《荀子·臣道》“谏争辅拂之人”——臣之位。

十一　存疑

  1. 曾子所居武城。 鲁有武城，一说在费。
  2. “负刍之祸”其人。 沈犹氏之乱，史无详载。
  3. “为民望”是否为曾子弟子语。 文作”左右曰”。
  4. “微”的训释。 朱熹”犹贱也”，指位卑。
  5. 子思是否确曾居卫。 史传有”子思居卫”之说。
