第二百五十章　用其一缓其二

一　本章导读

“有布缕之征，粟米之征，力役之征。”

——有布缕的征，有粟米的征，有力役的征。

“君子用其一，缓其二。”

——君子只用一样，缓其余两样。

“用其二而民有殍，用其三而父子离。”

——用两样，百姓就有饿死的；用三样，父子就离散。

二十七个字，是一张税则，也是一条人命线。 三个”征”,三个数：一、二、三，对应”活、饿、散”。

朱熹说： “征赋之法，岁有常数，然布缕取之于夏，粟米取之于秋，力役取之于冬，当各以其时；若并取之，则民力有所不堪矣。”

尹氏曰： “言民为邦本，取之无度，则其国危矣。”

此章驳谁：驳”三征并取为常法”——把榨尽当制度。立什么：立”用一缓二，取之有节”。留给后人什么：三只并排的征物，其中一只被取走，另两只上各压一道横线。

二　经文

【经】孟子曰：“有布缕之征，粟米之征，力役之征。君子用其一，缓其二。用其二而民有殍，用其三而父子离。”

三　字义与句读

布缕　布与线缕，指织物之征。

粟米　粮食之征。

力役　徭役。

用其一　三样之中取一样。

缓其二　另两样缓征。

殍　饿死。

父子离　父子离散。

句读一处：“用其一，缓其二” 与“用其二”“用其三” 是一组数。一、二、三是实指的层数，不是虚数。 若把”用其一缓其二”读成”随便取一样”，那”用二有殍、用三父子离”的递增就无处落；孟子给的是一把刻度，不是一句劝。

四　今译

孟子说：“有布缕的征，有粟米的征，有力役的征。君子只用一样，缓其余两样。用两样，百姓就有饿死的；用三样，父子就离散。”

五　章旨

三个”征”是三种取法，一、二、三是三条命线。

五条支撑：

  1. 三征并举，是当时实况，不是设喻。
  2. “用其一”是上限，不是理想。
  3. “缓其二”的”缓”是推迟，不是免除。
  4. “民有殍”是第二步的果。
  5. “父子离”是第三步的果：人不死而家散。

六　注家

【朱熹曰】“征赋之法，岁有常数，然布缕取之于夏，粟米取之于秋，力役取之于冬，当各以其时；若并取之，则民力有所不堪矣。”（《孟子集注·尽心下》）

【朱熹曰】“今两税三限之法，亦此意也。”（同上）

【尹氏曰】“言民为邦本，取之无度，则其国危矣。”（朱熹引）

【赵岐注】三征并举，则民不堪；君子取其一，缓其二，所以纾民力。（按：此为赵注大意，非原文。）

对照：赵岐只说”纾民力”，朱熹补出”各以其时”一层，把”缓”解成”错开季节”。赵言其纾，朱言其时。

七　分寸与边界

  1. 不可把”用其一”读成”只征一种”.** 是当年只取一样。
  2. 不可把”缓其二”读成”免其二”.** 缓是推迟。
  3. 不可把”殍”读成”贫”.** 是饿死。
  4. 不可把”父子离”读成”家庭不和”.** 是离散。
  5. 不可把本章读成”轻赋论”.** 说的是”取之有节”，不是”不取”。

八　义理

这一章短，但它有刻度。

“有布缕之征，粟米之征，力役之征。”

三样：要布，要粮，要人。

这三样正好是农家一年的全部： 织的、收的、力气。

“君子用其一，缓其二。”

——只取一样，另两样缓。

注意”缓”不是”免”. 孟子不说”只征一样，其余不征”，他说”缓”. 因为他知道免不了，只求错开。

朱熹把这层说得极实： “布缕取之于夏，粟米取之于秋，力役取之于冬，当各以其时。”

——夏取布，秋取粮，冬取力。

同一双手，一年只伸三次，每次只伸一样。 这样才活得下去。

“用其二而民有殍。”

——取两样，就有人饿死。

为什么？ 因为农家的收成，只够应付一样。两样同时来，就得卖了口粮去交布，或者卖了布去交粮。

“用其三而父子离。”

——三样齐取，父子就散。

这一层比”死”更冷。 死是一个人的事；散是一家人各自去逃荒。

三个数，三条线：

一，活；二，饿；三，散。

尹氏一句收得极重： “民为邦本，取之无度，则其国危矣。”

——取到无度，国就危。 不是民危，是国危。

图上一排三只征物：

左：一束布（几道竖线束起）。

中：一袋粟（一个鼓形袋，袋口扎起）。

右：一副担（一根横木两端各一筐，代表人役）。

左只上方一支手（赭色），把它取走。

中、右两只上方各一道横线压住（缓）。

下方三个数：一｜二｜三，各注”活”“殍”“离”。

——三只并排，只取一只；另两只压着，等明年。

九　时代之问

  • 我今年”取”了几样？
  • 我”缓”的那两样，缓到什么时候？
  • 我取的是”布”，还是他的”命”？
  • 我知道”二”的那条线在哪儿吗？
  • 我取到”三”的时候，谁散了？

十　跨典

  • 《孟子·梁惠王上》“什一而税”——取之有制。
  • 《孟子·公孙丑上》“市廛而不征”——商征之节。
  • 《孟子·尽心下》“诸侯之宝三”——下章，同一”三”.
  • 《论语·颜渊》“百姓足，君孰与不足”——取与之本。
  • 《荀子·富国》“轻田野之税”——节用之道。
  • 《老子》第七十五章”民之饥，以其上食税之多”——取之无度。

十一　存疑

  1. 三征是否同时并行。 朱熹曰”当各以其时”，本不同时。
  2. “布缕”是否即”调”. 汉制之”调”类此。
  3. “缓”是否可作”免”. 朱熹曰”缓”，非免。
  4. “父子离”是否指流亡。 是离散，注家无异。
  5. 本章是否专对某国而发。 无确指。
