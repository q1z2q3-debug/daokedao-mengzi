第一百六十七章　三子趋一

一　本章导读

淳于髡问：“先名实者，为人也；后名实者，自为也。”

——先顾名声事业的，是为别人；后顾名声事业的，是为自己。

“夫子在三卿之中，名实未加于上下而去之，仁者固如此乎？”

——先生位居三卿，上未正君、下未济民，就这样走了；仁者该是这样吗？

孟子说：“居下位，不以贤事不肖者，伯夷也；五就汤，五就桀者，伊尹也；不恶污君，不辞小官者，柳下惠也。”

——身处下位、不肯以贤事不肖的，是伯夷；五次就汤、五次就桀的，是伊尹；不嫌恶君、不辞小官的，是柳下惠。

“三子者不同道，其趋一也。一者何也？曰：仁也。”

——三个人走的路不同，所归的一处相同。这一处是什么？是仁。

“君子亦仁而已矣，何必同？”

淳于髡再攻：鲁缪公时公仪子为政、子柳子思为臣，“鲁之削也滋甚”——鲁国削得更厉害。贤者于国无益，竟到这样？

孟子答：“虞不用百里奚而亡，秦穆公用之而霸。不用贤则亡，削何可得与？”

——虞国不用百里奚就亡了，秦穆公用他就霸了。不用贤就亡，连”削”都轮不到。

淳于髡再举：王豹居淇而河西善讴，绵驹居高唐而齐右善歌，华周杞梁之妻善哭其夫而变国俗。“有诸内必形诸外。” 做事而无功的，我没见过。“是故无贤者也，有则髡必识之。”

——所以是没有贤者；若有，我一定认得。

孟子说：“孔子为鲁司寇，不用，从而祭，燔肉不至，不税冕而行。”

——孔子做鲁司寇，不见用。跟去祭祀，祭肉没送来，他连礼冠都不解就走了。

“不知者以为为肉也，其知者以为为无礼也。”

——不懂的以为他为一块肉；懂的知道他为”无礼”。

“乃孔子则欲以微罪行，不欲为苟去。”

——孔子是想借一个小罪名走，不愿白白地、苟且地走。

“君子之所为，众人固不识也。”

此章驳谁：驳”以功名验贤”。立什么：立”三子趋一，君子亦仁”。留给后人什么：三条路，一个圆。

二　经文

【经】淳于髡曰：“先名实者，为人也；后名实者，自为也。夫子在三卿之中，名实未加于上下而去之，仁者固如此乎？”孟子曰：“居下位，不以贤事不肖者，伯夷也；五就汤，五就桀者，伊尹也；不恶污君，不辞小官者，柳下惠也。三子者不同道，其趋一也。一者何也？曰：仁也。君子亦仁而已矣，何必同？”曰：“鲁缪公之时，公仪子为政，子柳、子思为臣，鲁之削也滋甚。若是乎贤者之无益于国也！”曰：“虞不用百里奚而亡，秦穆公用之而霸。不用贤则亡，削何可得与？”曰：“昔者王豹处于淇，而河西善讴；绵驹处于高唐，而齐右善歌；华周杞梁之妻善哭其夫，而变国俗。有诸内必形诸外。为其事而无其功者，髡未尝睹之也。是故无贤者也，有则髡必识之。”曰：“孔子为鲁司寇，不用，从而祭，燔肉不至，不税冕而行。不知者以为为肉也，其知者以为为无礼也。乃孔子则欲以微罪行，不欲为苟去。君子之所为，众人固不识也。”

三　字义与句读

淳于髡　齐人，以辩称。

名实　名声与事功。朱熹曰”名，声誉也。实，事功也”。

三卿　朱熹曰”三卿，谓孟子为齐卿”。

“名实未加于上下”　朱熹曰”言上未能正其君，下未能济其民”。

趋　归向。

公仪子　朱熹曰”公仪子，名休，为鲁相”。

燔肉　祭肉。

税冕　解冠。税，同”脱”。

微罪　小罪名。

句读一处：“君子亦仁而已矣，何必同？”——“同”字收在问句上，是全章的定盘星。

四　今译

淳于髡说：“先顾名实的，是为别人；后顾名实的，是为自己。先生位居三卿，上未正君、下未济民，就这样离开，仁者该这样吗？”孟子说：“处下位不肯以贤事不肖的，是伯夷；五就汤、五就桀的，是伊尹；不嫌恶君、不辞小官的，是柳下惠。三人路不同，所归则一。一是何？是仁。君子也就是仁罢了，何必相同？”“鲁缪公时，公仪子为政，子柳、子思为臣，鲁国削得更厉害。贤者于国无益，竟到这样！”孟子说：“虞不用百里奚而亡，秦穆公用之而霸。不用贤就亡，连削都轮不到。”“从前王豹居淇，河西都善讴；绵驹居高唐，齐右都善歌；华周杞梁之妻善哭其夫，而变了国俗。有诸内必形诸外。做事而无功的，我没见过。所以是没有贤者；若有，我一定认得。”孟子说：“孔子做鲁司寇，不见用，跟去祭祀，祭肉不至，他不解冠就走。不懂的以为他为肉，懂的知道他为无礼。孔子是想借个小罪名走，不愿苟且地走。君子所为，众人本来不识。”

五　章旨

贤之所以为贤，不在功名之验，在”趋一”——一者，仁也。

五条支撑：

  1. “先名实/后名实”，淳于髡先把人分两等，逼孟子择一。
  2. 孟子举三子，破”一等”。 伯夷、伊尹、柳下惠，三样活法。
  3. “其趋一也……仁也”，把三样收在一处。
  4. “鲁之削”一问，孟子以虞、秦对，明”不用贤则亡”。
  5. “孔子燔肉不至”，末以”众人固不识”收。

六　注家

【朱熹曰】“名实未加于上下，言上未能正其君，下未能济其民也。”（《孟子集注·告子下》）

【朱熹曰】“仁者，无私心而合天理之谓。”（同上）

【朱熹曰】“杨氏曰：伊尹之就汤，以三聘之勤也；其就桀也，汤进之也。岂圣人之心哉？”（同上）

【朱熹曰】“公仪子，名休，为鲁相。子柳，泄柳也。”（同上）

【朱熹曰】“王豹，卫人，善讴……华周、杞梁，二人皆齐臣，战死于莒，其妻哭之哀，国俗化之。”（同上）

【朱熹曰】“孔子为鲁司寇……燔肉不至，不税冕而行。”（同上）

【朱熹曰】“乃孔子则欲以微罪行，不欲为苟去。”（同上）

【朱熹曰】“尹氏曰：淳于髡未尝知仁，亦未尝识贤也。”（同上）

【赵岐注】三子异道而同归，贤不必一途。（按：此为赵注大意，非原文。）

对照：赵岐明”异道同归”，朱熹断”髡不知仁”。赵释其义，朱斥其识。

七　分寸与边界

  1. 不可把”三子不同道”读成”无原则”。** 趋一者是仁。
  2. 不可把”何必同”读成”各行其是”。** 是”同归于仁”。
  3. 不可把”鲁之削”读成贤者无用。** 削与亡，是两等。
  4. 不可把”燔肉不至”读成为一块肉。** 朱熹明辨”为无礼”。
  5. 不可把”众人固不识”读成看不起众人。** 是”君子所为”不在一事之验。

八　义理

这一章辩的是一个很现代的问题：怎么证明一个人是贤的？

淳于髡的办法是验功：“为其事而无其功者，髡未尝睹之也。”——做事没有成效的，我没见过。所以没有贤者；有，我一定认得。

这套论证看上去无懈可击：以结果论人。

孟子不否认”有诸内必形诸外”。他只指出一件事：你看的那个”外”，可能还没到。

他先举三个人。

伯夷：处下位，不肯以贤事不肖。他什么功也没有，因为他根本不就。 伊尹：五就汤，五就桀。他反复就，看上去毫无节操。 柳下惠：不恶污君，不辞小官。他什么位置都坐。

三个人的活法，互相都看不上。 可孟子说：“其趋一也。一者何也？曰：仁也。”

——他们归到同一处。

这就是”君子亦仁而已矣，何必同”的分量：证明贤，不看一条路，看那个”一”。

淳于髡第二击更狠：鲁国用了公仪子、子柳、子思，“鲁之削也滋甚”。

——贤者在朝，国反而削。 这几乎是铁证。

孟子的回答极干脆：“不用贤则亡，削何可得与？”——不用贤就亡国，你连”削”都保不住。 鲁国还能”削”，正因为它还有点贤。

第三击，淳于髡举了三个”化俗”的例子： 王豹在淇，河西善讴；绵驹在高唐，齐右善歌；杞梁之妻哭夫，变了国俗。一个人能改一方的风俗，这就是”形诸外”。

孟子的回答，落在孔子身上。

孔子做鲁司寇，不见用。跟去祭祀，祭肉没送来。他不解冠就走了。

“不知者以为为肉也，其知者以为为无礼也。”

——同一件事，两种读法。 一种读成”为一块肉”，一种读成”为无礼”。

孟子说：孔子其实是想”以微罪行”。——借一个小罪名走，不愿”苟去”。

这句话极深：他不是赌气，他是不肯白白地走。 他要给这件事一个名目，让别人有话说，让自己有名目走。

“君子之所为，众人固不识也。”

——这不是傲，是看清了：一件事的意义，常常不在它的成效里，也不在旁人的读法里。

三条路，一个圆。 路各不同，圆只有一个。

淳于髡认得所有的路，他不认得那个圆。

九　时代之问

  • 我用什么验人：功，还是趋？
  • 我的”路”，是否已经离了那个”一”？
  • 我判断别人”无益”，是否只看了”削”？
  • 我有没有”苟去”过？
  • 我读别人的事，是”为肉”还是”为无礼”？

十　跨典

  • 《论语·微子》“逸民：伯夷、叔齐、虞仲……”——三子之伦。
  • 《孟子·万章下》“伯夷隘，柳下惠不恭”——三子之偏。
  • 《孟子·公孙丑上》“非其君不事”——伯夷之守。
  • 《尚书·说命》“股肱惟人”——贤之重。
  • 《荀子·非十二子》“同”与”异”之辨。

十一　存疑

  1. 淳于髡所言之”三卿”。 孟子在齐是否居卿位，说者不一。
  2. “五就汤五就桀”之数。 朱熹引杨氏，以为汤进之。
  3. 王豹、绵驹、华周杞梁。 朱熹各注其人，年代不一。
  4. “以微罪行”之义。 一说借小事去，一说自认小罪。
  5. 本章与《万章下》“三子”之关系。 语近而旨别。
