第二十七章　尊贤使能

一　本章导读

这一章是孟子最像”政策清单”的一章：五处，五条，一处一句话。

一，尊贤使能，俊杰在位，则天下之士，都愿意站在他的朝廷上。 二，市，廛而不征，法而不廛，则天下的商人，都愿意把货存在他的市里。 三，关，讥而不征，则天下的旅人，都愿意走他的路。 四，耕者助而不税，则天下的农夫，都愿意种他的田。 五，廛，无夫里之布，则天下的民，都愿意做他的百姓。

五句话，五个”皆悦而愿”。孟子一个”劝”字都没用——他不说”你要让人愿意”，他说”这样做了，人就自己愿意”。

结句极重：信能行此五者，则邻国之民仰之若父母矣。率其子弟，攻其父母，自生民以来，未有能济者也。 让儿子去打父母，从来没人成功过。

无敌于天下者，天吏也。然而不王者，未之有也。

此章驳谁：驳”强国靠关卡税收得紧”。立什么：立”五个入口各让一步，人自己会来”；天吏不是封号，是奉行天命之实。留给后人什么：一张最短的清单——想让谁来，就在他进门的地方少收一点。

二　经文

【经】孟子曰：“尊贤使能，俊杰在位，则天下之士皆悦而愿立于其朝矣。”

【经】“市，廛而不征，法而不廛，则天下之商皆悦而愿藏于其市矣。关，讥而不征，则天下之旅皆悦而愿出于其路矣。”

【经】“耕者助而不税，则天下之农皆悦而愿耕于其野矣。廛，无夫里之布，则天下之民皆悦而愿为之氓矣。”

【经】“信能行此五者，则邻国之民仰之若父母矣。率其子弟，攻其父母，自生民以来，未有能济者也。如此，则无敌于天下。无敌于天下者，天吏也。然而不王者，未之有也。”

三　字义与句读

俊杰　朱熹：“俊杰，才德之异于众者。”

廛而不征　廛，市宅（铺面场地）；征，征货税。朱熹引张子：“或赋其市地之廛，而不征其货。”

法而不廛　朱熹引张子：“或治之以市官之法，而不赋其廛。盖逐末者多则廛以抑之，少则不必廛也。”两句是两种治法，择一而行。

讥而不征　讥，查察（防奸）；不征，不抽税。朱熹：“解见前篇。”

助而不税　朱熹：“但使出力以助耕公田，而不税其私田也。”

夫里之布　朱熹引《周礼》郑氏：“宅不种桑麻者，罚之使出一里二十五家之布；民无常业者，罚之使出一夫百亩之税，一家力役之征也。”本是罚，战国”一切取之”，变成常税。

氓　民。朱熹：“氓，民也。”

天吏　朱熹引吕氏：“奉行天命，谓之天吏。废兴存亡，惟天所命，不敢不从，若汤武是也。”

句读一处：“市，廛而不征，法而不廛”——中间是两条路，不是四件事：要么收地租不收货税，要么按市法管、不收地租。

四　今译

孟子说：“尊重贤人、任用能人，让才德出众的在位上，天下的士就都愿意站在他的朝廷上。”

“市场，收铺面租就不收货税，或者按市法管理就不收铺面租，天下的商人就都愿意把货存在他的市里。关卡，只查奸不抽税，天下的旅人就都愿意走他的路。”

“种田的，只出劳力助耕公田、不税私田，天下的农夫就都愿意种他的田。住宅，不收夫里之布，天下的民就都愿意做他的百姓。”

“真能行这五条，邻国的民就把他当父母看待。领着儿子去打父母，自有生民以来，没有能成的。这样，就无敌于天下。无敌于天下的，是天吏。做到这样还不成王的，从来没有过。”

五　章旨

王道不是一句口号，是五处具体的地方各让一步；人不是被说服来的，是被”进门便宜”吸引来的。

五条支撑：

  1. 五条全是”减”，没有一条是”加”：不征税、不抽关、不税私田、不收罚布。治国的动作，先做减法。
  2. 五条对应五类人：士、商、旅、农、民。几乎覆盖了所有会流动的人。
  3. 每句结尾都是”皆悦而愿”：愿是自愿，不是奉命。政策成不成，看有没有”愿”字。
  4. “仰之若父母”是五条的合力：不是一项恩惠，是一整套可预期的宽。
  5. “率其子弟，攻其父母”是全章最硬的论证：人心一旦归了，连兵都调不动。

六　注家

【朱熹曰】“俊杰，才德之异于众者。”（《孟子集注·公孙丑上》）

【朱熹引张子曰】“或赋其市地之廛，而不征其货；或治之以市官之法，而不赋其廛。盖逐末者多则廛以抑之，少则不必廛也。”（同上）

【朱熹曰】“但使出力以助耕公田，而不税其私田也。”（同上）

【朱熹引郑氏曰】“宅不种桑麻者，罚之使出一里二十五家之布；民无常业者，罚之使出一夫百亩之税，一家力役之征也。今战国时，一切取之。”（同上）

【朱熹引吕氏曰】“奉行天命，谓之天吏。废兴存亡，惟天所命，不敢不从，若汤武是也。”（同上）

【朱熹曰】“此章言能行王政，则寇戎为父子；不行王政，则赤子为仇雠。”（同上）

对照：赵岐注逐条释”廛”“征”“布”之制，重在复原古法；朱熹引张子、郑氏，把”古法”读成”两种可选的治法”，并指出战国”一切取之”才是病根。赵说制度，朱说取舍。

七　分寸与边界

  1. 不可把五条读成”免税就万能”。五条之前有一条”尊贤使能”——人不对，减税只是白送。
  2. 不可把”廛而不征”与”法而不廛”当成同时执行。朱熹明说是两种治法，择一。
  3. 不能把”无敌于天下”当作军事结论。它的前提是”邻国之民仰之若父母”。
  4. 不可把”天吏”当作自我加冕。吕氏的定义是”奉行天命”，天吏是被派的那个，不是自封的那个。

八　义理

这一章罕见地不谈德性，只谈”入口”。

孟子看得很清楚：人往哪里走，不看哪国口号好，看哪国进门便宜。所以他把王道拆成五道门——士进门看有没有位子，商进门看铺面贵不贵，旅进门看关卡抽不抽，农进门看私田税不税，民进门看住着要不要交罚布。五个门槛，五个痛点，五处各让一步。

这不是仁政的全部，但它是仁政的”可操作面”。仁心看不见，门槛看得见。一个人真想行仁政，第一步不是发誓，是去把自己的门槛量一遍。

而五条的合力，是一个极难被击败的东西：当邻国之民把你当父母，你的对手就失去了他的军队。 因为军队是从民里来的。这就是”率其子弟，攻其父母，未有能济者”的意思——不是道德感化，是组织学：你要打的那个人，是他的兵的爹娘。

最后”天吏”两字，把整章收住。天吏不是”替天行道”的自许，是”奉行天命”的实指：你做的事，正好是天要发生的事。判断自己是不是天吏，不看宣言，看有没有人真的往你这边走。

九　时代之问

  • 我的”门槛”在哪几处？ 别人进我这儿，要在哪五道门上各交一次钱、各等一次？
  • 我减的是哪一项？ 减在门槛上，人才来；减在口号上，人不动。
  • 我的用户，是”愿”来的，还是被”推”来的？ 愿来的会留下，推来的一推就散。
  • 我若被人打，我的”子弟”会站在哪边？ 这是全章最不留情的自测。

十　跨典

  • 《论语·子路》：“近者说，远者来。”——五条之效。
  • 《孟子·梁惠王上》：“王如施仁政于民，省刑罚，薄税敛。”——同一逻辑的简版。
  • 《管子·牧民》：“仓廪实而知礼节。”——先给实惠，再谈教化。
  • 《老子》第六十六章：“江海所以能为百谷王者，以其善下之。”——下之则归之。
  • 《荀子·王制》：“田野荒而仓廪实，百姓虚而府库满，夫是之谓国蹶。”——聚财而失民，正是反面。

十一　存疑

  1. “廛”之制。 朱熹谓市宅；一说谓市中的空地税。注家多从朱。
  2. “夫里之布”之数。 郑氏谓一里二十五家之布、一夫百亩之税，其制汉已不可详。
  3. “五者”之序。 士、商、旅、农、民，朱熹未言其次序之义；或以”由士而民”为自高而下。
  4. “天吏”是否为孟子自造。 吕氏以为本于天命之说，先秦他书少见，当是孟子用语。
