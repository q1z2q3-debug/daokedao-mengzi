第二百六十章　孔子在陈

一　本章导读

“不得中道而与之，必也狂獧乎！狂者进取，獧者有所不为也。”

——找不到行中道的人来教，那就找狂与獧吧：狂的人往前取，獧的人有所不为。

“如琴张、曾皙、牧皮者，孔子之所谓狂矣。”

——像琴张、曾皙、牧皮这样的人，就是孔子说的狂。

“非之无举也，刺之无刺也；同乎流俗，合乎污世；居之似忠信，行之似廉洁；众皆悦之，自以为是，而不可与入尧舜之道，故曰德之贼也。”

——要非议他，举不出事；要讥刺他，找不到刺。随波逐流，迎合浊世；住着像忠信，做着像廉洁；众人喜欢他，他自己也以为对，却不能同他入尧舜之道：所以叫德之贼。

这是全书最长的一章，也是全书最凶的一段骂。 骂的不是坏人，是”好人”.

朱熹说： “乡原不狂不獧，人皆以为善，有似乎中道而实非也，故恐其乱德。”

尹氏曰： “所恶于乡原，而欲痛绝之者，为其似是而非，惑人之深也。绝之之术无他焉，亦曰反经而已矣。”

此章驳谁：驳”众悦即德”——把众人的好评当作道的凭证。立什么：立”狂獧可教，乡原不可入；君子反经而已”。留给后人什么：三人一排：左狂（举手向古）、中乡原（四面逢迎）、右獧（抱臂自守）；乡原身上一个赭叉。

二　经文

【经】万章问曰：“孔子在陈曰：‘盍归乎来！吾党之士狂简，进取，不忘其初。’孔子在陈，何思鲁之狂士？“孟子曰：”孔子’不得中道而与之，必也狂獧乎！狂者进取，獧者有所不为也’。孔子岂不欲中道哉？不可必得，故思其次也。”“敢问何如斯可谓狂矣？”曰：“如琴张、曾皙、牧皮者，孔子之所谓狂矣。”“何以谓之狂也？”曰：“其志噀噀然，曰’古之人，古之人’。夷考其行而不掩焉者也。狂者又不可得，欲得不屑不洁之士而与之，是獧也，是又其次也。孔子曰：‘过我门而不入我室，我不憾焉者，其惟乡原乎！乡原，德之贼也。’”曰：“何如斯可谓之乡原矣？”曰：“’何以是噀噀也？言不顾行，行不顾言，则曰：古之人，古之人。行何为踽踽凉凉？生斯世也，为斯世也，善斯可矣。’阉然媚于世也者，是乡原也。”万子曰：“一乡皆称原人焉，无所往而不为原人，孔子以为德之贼，何哉？”曰：“非之无举也，刺之无刺也；同乎流俗，合乎污世；居之似忠信，行之似廉洁；众皆悦之，自以为是，而不可与入尧舜之道，故曰德之贼也。孔子曰：’恶似而非者：恶莠，恐其乱苗也；恶佞，恐其乱义也；恶利口，恐其乱信也；恶郑声，恐其乱乐也；恶紫，恐其乱朱也；恶乡原，恐其乱德也。’君子反经而已矣。经正，则庶民兴；庶民兴，斯无邪慝矣。”

三　字义与句读

狂简　朱熹曰”志大而略于事”。

獧　同”狷”，朱熹曰”有所不为者，知耻自好，不为不善之人也”。

噀噀　朱熹曰”志大言大也”。

夷考　朱熹曰”夷，平也”。

不掩　朱熹曰”掩，覆也。言平考其行，则不能覆其言也”。

踽踽凉凉　朱熹曰”踽踽，独行不进之貌；凉凉，薄也”。

阉然　朱熹曰”阉，如奄人之奄，闭藏之意也”。

乡原　朱熹曰”原，与愿同……谓谨愿之人也”。

反经　朱熹曰”反，复也；经，常也”。

句读一处：“狂者进取，獧者有所不为也” 十字之内是两个分句，中间不断。“进取”与”有所不为”是一对反动作，一放一收；若把十字连读成一句，就丢了孟子”两者皆是其次”的意思——不是”取进又不为”，是两种人。

四　今译

万章问：“孔子在陈国说：‘何不回去呢！我家乡的士人狂而疏略，勇于进取，不忘本初。’孔子在陈国，为什么想念鲁国的狂士？“孟子说：”孔子说过’找不到行中道的人来教，那就找狂与獧吧：狂的人往前取，獧的人有所不为’。孔子难道不想中道？是不能必得，所以想其次。”“请问怎样才算狂？”孟子说：“像琴张、曾皙、牧皮，就是孔子说的狂。”“为什么叫狂？”孟子说：“他们志气大、话说得大，开口就是’古之人，古之人’；可平实地考察他们的行为，却盖不住自己的话。狂者也不可得，就想找那种不屑于不洁之事的人来教，这是獧，是又次一等。孔子说：‘过我门而不进我屋，我不遗憾的，只有乡原吧！乡原是德之贼。’”万章问：“怎样才算乡原？”孟子说：“’何必这样志大言大？说话不顾行为，行为不顾说话，只会说古之人、古之人。何必这样孤孤零零、冷冷淡淡？生在这个世，就做这个世的人，让大家都说好就行了。’那样遮遮掩掩讨好世人的，就是乡原。”万章说：“一乡都说他是好人，到哪儿都是好人，孔子却以为德之贼，为什么？”孟子说：“要非议他，举不出事；要讥刺他，找不到刺。随波逐流，迎合浊世；住着像忠信，做着像廉洁；众人都喜欢他，他自己也以为对，却不能同他入尧舜之道：所以叫德之贼。孔子说：’厌恶那些似是而非的：厌恶莠草，怕它乱了禾苗；厌恶巧言，怕它乱了义；厌恶利口，怕它乱了信；厌恶郑声，怕它乱了正乐；厌恶紫色，怕它乱了朱红；厌恶乡原，怕它乱了德。’君子只是回到常道罢了。常道正了，百姓就兴起；百姓兴起，就没有邪慝了。”

五　章旨

四层：狂—獧—乡原—反经。一层比一层低，末一层是解法。

五条支撑：

  1. “不得中道”是实情，不是客气。
  2. 狂是”言过其行”，獧是”有所不为”，两者都有可取。
  3. 乡原的可怕在”无举无刺”——找不出错处。
  4. “众皆悦之”是乡原的凭证，也是他的罪证。
  5. “反经”是唯一的解法：不是骂他，是把常道立起来。

六　注家

【朱熹曰】“狂简，谓志大而略于事。进取，谓求望高远。不忘其初，谓不能改其旧也。”（《孟子集注·尽心下》）

【朱熹曰】“有所不为者，知耻自好，不为不善之人也。”（同上）

【朱熹曰】“噀噀，志大言大也。……言平考其行，则不能覆其言也。”（同上）

【朱熹曰】“乡原不狂不獧，人皆以为善，有似乎中道而实非也，故恐其乱德。”（同上）

【朱熹曰】“世衰道微，大经不正，故人人得为异说以济其私，而邪慝并起，不可胜正，君子于此，亦复其常道而已。”（同上）

【尹氏曰】“君子取夫狂獧者，盖以狂者志大而可与进道，獧者有所不为，而可与有为也。所恶于乡原，而欲痛绝之者，为其似是而非，惑人之深也。绝之之术无他焉，亦曰反经而已矣。”（朱熹引）

【赵岐注】乡原者，其行似善而非善，众人悦之，故为德之贼；君子复常道以正之。（按：此为赵注大意，非原文。）

对照：赵岐只断”似善而非善”，朱熹立”不狂不獧、似中道而实非”三层，尹氏把”反经”提为绝之之术。赵断其似，朱析其层，尹指其术。

七　分寸与边界

  1. 不可把”狂”读成”狂妄”.** 朱熹曰”志大而略于事”，是可爱之人。
  2. 不可把”獧”读成”狭隘”.** 是”知耻自好”.
  3. 不可把”乡原”读成”乡下的老实人”.** 是”阉然媚世”.
  4. 不可把”众皆悦之”读成”德之证”.** 正是他的罪证。
  5. 不可把”反经”读成”复古”.** 是”复其常道”.

八　义理

这是全书最长的一章，也是心里最冷的一章。

万章问的是一件小事： 孔子在陈国，为什么想家？

孟子答得极大： 因为孔子想找人来教，而中道之人找不到。

“不得中道而与之，必也狂獧乎！”

——找不到行中道的人，那就找狂与獧。

“狂者进取，獧者有所不为也。”

——狂的人往前取，獧的人有所不为。

两句话，两个人： 一个过，一个不及。都不到中道，但都可教。

狂是什么？

“其志噀噀然，曰’古之人，古之人’。夷考其行而不掩焉者也。”

——志气大、话说得大，开口就是”古之人”；可一考他的行为，盖不住自己的话。

这是极可爱的毛病： 说得比做得多。朱熹说它”可与进道”——因为他心里有个高的东西。

獧是什么？

“欲得不屑不洁之士而与之” ——找那种不屑做不洁之事的人。

“是又其次也。”

——再退一等。

狂是第一备选，獧是第二备选。

然后孟子把刀抽出来：

“过我门而不入我室，我不憾焉者，其惟乡原乎！乡原，德之贼也。”

——过我门不进我屋，我不遗憾的，只有乡原。

注意这句的分量。 别人不来，孔子遗憾；乡原不来，孔子不遗憾。

为什么？因为他来了也没用，甚至更有害。

万章问：一乡都说他是好人，为什么是贼？

孟子的回答，是全章最沉的二十余字：

“非之无举也，刺之无刺也。”

——要非议他，举不出事；要讥刺他，找不到刺。

“同乎流俗，合乎污世。” ——随波逐流，迎合浊世。

“居之似忠信，行之似廉洁。” ——住着像忠信，做着像廉洁。

“众皆悦之，自以为是，而不可与入尧舜之道。”

——众人喜欢他，他自己也以为对，却不能同他入尧舜之道。

四个”似”字，是全章的机关。 他不是坏，他是”像”.

而”像”比”坏”更难对付： 坏人有形迹，可以指；像的人没有形迹，指不出来。

孔子那六个”恶”，正是同一个道理：

恶莠，怕它乱苗； 恶佞，怕它乱义；恶利口，怕它乱信； 恶郑声，怕它乱乐；恶紫，怕它乱朱； 恶乡原，怕它乱德。

——六样都是”似而非”. 莠像苗，紫像朱，乡原像德。

最后一句是解法，不是骂法：

“君子反经而已矣。经正，则庶民兴；庶民兴，斯无邪慝矣。”

——君子只是回到常道。常道正了，百姓兴起；百姓兴起，邪慝就没了。

注意这个次序： 不是先打邪慝，是先立常道。

尹氏说得准： “绝之之术无他焉，亦曰反经而已矣。”

——要断绝他，没有别的办法，就是反经。

图上：三人一排。

左：狂——一人仰头举手，口边一个小圈内写”古之人”.

中：乡原——一人正面直立，双手向左右各伸，两边各两小人向他倾身。

右：獧——一人抱臂而立，身前一堵矮墙（有所不为）。

乡原头顶一个赭叉，旁注”德之贼”.

底部：“君子反经而已矣。”

——狂与獧都有形，乡原没有形；所以最难对付的是中间那个。

九　时代之问

  • 我是狂，是獧，还是乡原？
  • 我说话，盖得住我的行为吗？
  • 我有没有”找不出错处”的时候？
  • 我做的事，是为人，还是为众人说好？
  • 我的”常道”，立着吗？

十　跨典

  • 《论语·子路》“不得中行而与之，必也狂狷乎”——本章所本。
  • 《论语·阳货》“乡原，德之贼也”——孔子语。
  • 《孟子·尽心下》“曾皙嗜羊枣”——上章，曾皙亦在狂者之列。
  • 《孟子·滕文公下》“距杨墨”——距有形之邪。
  • 《中庸》“小人之中庸”——似而非之另一说法。
  • 《荀子·非十二子》“饰邪说，文奸言”——同病之诊。

十一　存疑

  1. “盍归乎来”与《论语》“盍归乎来”文字小异。 朱熹曰”此语与《论语》小异”.
  2. 琴张、牧皮其人。 朱熹曰”牧皮，未详”.
  3. “乡原”是否即”愿人”. 朱熹曰”原，与愿同”.
  4. 本章是否孟子自作解经之体。 前半引孔子，后半自解。
  5. “反经”是否即”复礼”. 注家多以为近而不同。
