第九十三章　三有礼

一　本章导读

齐宣王接着上一章问：礼规定臣要为旧君服丧，那么君要怎样待臣，臣才该为他服？

孟子的答复是三个动作：

谏行言听，膏泽下于民——一是他的话说得进去，恩泽落到百姓身上；

有故而去，则君使人导之出疆，又先于其所往——二是他要走，君派人引他出境，又先一步替他打招呼；

去三年不反，然后收其田里——三是三年之后才收回他的田宅。

此之谓三有礼焉。

反面也列了三件：谏不行、言不听；膏泽不下；要走就抓、就堵、当天就收田宅。此之谓寇雠。寇雠何服之有？

此章驳谁：驳”服丧是臣的单方面义务”。立什么：立”礼是对等的契约”：三件事给出路，服才有着落。 留给后人什么：一条放行的路，一面半开的门。

二　经文

【经】王曰：“礼，为旧君有服，何如斯可为服矣？”曰：“谏行言听，膏泽下于民；有故而去，则君使人导之出疆，又先于其所往；去三年不反，然后收其田里。此之谓三有礼焉。如此则为之服矣。今也为臣，谏则不行，言则不听；膏泽不下于民；有故而去，则君搏执之，又极之于其所往；去之日，遂收其田里。此之谓寇雠。寇雠何服之有？”

三　字义与句读

为旧君有服　《仪礼·丧服》“以道去君而未绝者，服齐衰三月”。“旧君”，是曾为其臣的君。

膏泽　恩泽。**“下于民”，落到百姓身上：不是给臣一人好处。

有故而去　“故”是正当的缘故。**不是逃，是”有故”。

导之出疆　朱熹曰”防剽掠也”。**送出边境，是护他不被劫。

先于其所往　朱熹曰”称道其贤，欲其收用之也”。**先一步到那边替他说话。

收其田里　田为禄田，里为居宅。**“三年而后收”，朱熹曰”前此犹望其归也”。

搏执　抓起来。

极　朱熹曰”穷也”。**“极之于其所往”，是让他在所去之处也走不通。

寇雠何服之有　“何服之有”是反问：有什么服可服？**反问即否定。

句读一处：“去三年不反，然后收其田里。”——“反”读为”返”。三年内不收，是留一条回来的路；三年到了才收，是”望其归”的期限。

四　今译

齐宣王说：“按礼，臣要为旧日的君主服丧，君要怎样待臣，臣才为他服呢？”孟子说：“臣的谏诤施行，言语听从，恩泽施及百姓；臣因故离去，君派人引他出境，又先一步在他要去的地方称道他；离开三年不回来，然后才收回他的田宅。这叫做三有礼。这样，臣就为他服了。如今做臣的：谏诤不施行，言语不听从；恩泽不下及百姓；因故离去，君就把他抓起来，又让他在所去之处走投无路；走的那天，就收回他的田宅。这叫做仇敌。仇敌有什么服可服？”

五　章旨

服不服，看君待臣之礼；礼不是单向的。

五条支撑：

  1. 三件事，都是”给出路”。 听话、送行、打招呼、留三年——**没有一件是”给好处”，全是”不堵路”。
  2. 第一件事在”言”上。 谏行言听，是让他的话能变成事。**臣的价值，先在他的话。
  3. 第二件事在”行”上。 送出境、先容——**人走了，关系不断。
  4. 第三件事在”财”上。 三年不反才收田里。**留三年的口粮与退路。
  5. 反面三件事，恰好把三条路一一堵死。 不听、不送、即收。**“此之谓寇雠”，是把人做成敌人。

六　注家

【朱熹曰】“导之出疆，防剽掠也。先于其所往，称道其贤，欲其收用之也。三年而后收其田禄里居，前此犹望其归也。”（《孟子集注·离娄下》）

【朱熹曰】“极，穷也。……今也为臣以下，正与上文相反。”（同上，按：文有节引）

【朱熹引杨氏曰】“君臣以义合者也。故君使臣以礼，则臣事君以忠；君使臣不以礼，则臣事君不以忠。”（同上）

【朱熹引潘兴嗣曰】“孟子告齐王之言，犹孔子对定公之意也。”（同上）

【赵岐注】引《礼》“以道去君”之制为说，谓君待臣有礼则臣为服。（按：此为赵注大意，非原文。）

对照：赵岐先把”礼”的条文摆出来，让”服”有制度上的根；朱熹一层一层剖开三个动作的用意（防剽掠、欲收用、望其归），再以杨氏一语点明”以义合”。赵陈其礼，朱权其去。

七　分寸与边界

  1. 不可读成”臣可以叛”。**全章讲的是”去”，不是”反”；“去”是有故而行。
  2. 不可把”三有礼”读成形容词。**它是三件可数、可验的事。
  3. 不可忽略”三年”的用意。**不是宽限，是”犹望其归”。
  4. 不可忽略”有故”二字。**无故而去，不在此列。
  5. 不可把末段当作孟子对齐王的当面讥刺就完事。**它是一面镜子：君可以照，臣也可以照。

八　义理

这一章最要紧的，是把”礼”从”应该”还原成”动作”。

“礼，为旧君有服”——宣王问的是条文。 孟子不答条文，答动作。三个动作，一件比一件轻，也一件比一件难。

第一件最重：谏行言听，膏泽下于民。 这是”你的话有用”。一个臣最难舍的，不是俸禄，是自己的话被当话。 君若做到这一条，臣已经得了大半。

第二件最细：导之出疆，先于其所往。 送出境，是护他不被劫；先容，是先一步替他铺路。这两件事，一件在身后，一件在前头。 一个人要走，君既护其身后，又谋其前头——**这时候的”君”，已经不是”上”，是”故人”。

第三件最缓：三年而后收其田里。 田宅是命根。留着三年，就是留着一条回来的路；三年到了才收，是”望”有了期限。 这一条最见分寸：不即刻收，是情；到时不收，是乱。

反面三件，是把这三条一一掐断。 不听其言，是不认他的话；不送不先容，是断他的路；当日即收田里，是断他的粮。三刀下去，人还在，关系已经没了。 孟子说”此之谓寇雠”——不是臣成了寇雠，是君把臣做成了寇雠。

“寇雠何服之有”这一反问，是全章的落点。 服丧之服，是为”曾被善待”而穿的。没有被善待过，穿什么？ 这不是狡辩，是把”服”还原成了”回应”。

图里是一道城门，门扇半开；一条路从门里出去，路上有人引，有人持节；再远处是三格田。 三样东西，正是三件事：出去的路（导之出疆）、前头的招呼（先于其所往）、留在原处的田（三年不收）。

九　时代之问

  • 我离开一个地方的时候，有没有人替我”先容”？
  • 我给要走的人，留了几年？
  • 我是不是把”服”当作义务，却从不问”待”？
  • 我的话，在我所在的地方，还算话吗？
  • 我有没有把某个人，一步一步做成了”寇雠”？

十　跨典

  • 《仪礼·丧服》“为旧君”之服——本章所问的条文。
  • 《论语·八佾》“君使臣以礼，臣事君以忠”——对等之正说。
  • 《礼记·曲礼》“大夫去国……”——去国之礼。
  • 《孟子·万章下》“再三谏而不听，则去”——去之节。
  • 《孟子·公孙丑下》“三宿而后出昼”——去而迟迟，望其归。
  • 《左传·僖公五年》“辅车相依，唇亡齿寒”——断路之祸。

十一　存疑

  1. “为旧君有服”的服制。 《仪礼》谓齐衰三月，“以道去君而未绝者”；孟子所答是否即此制，未可确指。
  2. “三有礼”是否礼书成文。 今存礼书未见”三有礼”之名，或为孟子立说。
  3. “极”字的训释。 朱熹训”穷”；一说”极”为”放逐于极远”。
  4. “搏执”的对象。 一说执其臣，一说执其家人，文义可两通。
  5. 此章是否即承上章而发。 上章告宣王”手足腹心”，此章宣王问”旧君有服”，文气紧接，然是否同一次问答，无确证。

图位　图四｜三有礼

读图三处：

  1. 半开的门——没有关死。**“有故而去”的人，是走出去的，不是被赶出去的。
  2. 路上的一引一持节——引者在前面带路，持节者在一旁作凭。**一件护他出境，一件替他说话。
  3. 路尽头那三格田——还在原地，没有收。**三年，是”望其归”的长度。

图说一句：礼不是要人服，是先给人路走。
