第一百二十一章　诗亡春秋

一　本章导读

这一章讲一种”接替”：诗停了，史起来了。

王者之迹熄而诗亡，诗亡然后春秋作。

王者的事迹熄了，诗就亡了；诗亡了，然后《春秋》作。

晋之乘，楚之梼杌，鲁之春秋，一也。

晋国的史叫《乘》，楚国的叫《梼杌》，鲁国的叫《春秋》——一样的东西。

其事则齐桓、晋文，其文则史。孔子曰：“其义则丘窃取之矣。”

记的事是齐桓、晋文之事，用的文是史官的文；至于那”义”，孔子说：我私下取过来了。

此章驳谁：驳”《春秋》只是一部史书”。立什么：立”其文则史，其义则窃取”——义在笔削之间。留给后人什么：一盏无焰的灯，一束竹简。

二　经文

【经】孟子曰：“王者之迹熄而诗亡，诗亡然后春秋作。晋之乘，楚之梼杌，鲁之春秋，一也。其事则齐桓、晋文，其文则史。孔子曰：‘其义则丘窃取之矣。’”

三　字义与句读

王者之迹　朱熹曰”谓平王东迁，而政教号令不及于天下也”。**“迹”，是王者巡守、采诗、号令所留下的踪。

诗亡　朱熹曰”谓黍离降为国风而雅亡也”。**不是诗没有了，是”雅”亡了。

乘／梼杌／春秋　三国史记之名。**同物异名。

一也　一样。**指其为”史记”这件事一样。

其事／其文　所记之事／所用之文。

义　裁断之旨。**“笔则笔，削则削”。

窃取　谦辞，非偷。**“私取之”——取的是那个”义”。

句读一处：“其文则史，其义则丘窃取之矣。”——上句说”文”是别人的，下句说”义”是我的。两句对读，“述而不作”的分寸才出来：事与文不创，义则自任。

四　今译

孟子说：“王者的事迹熄了，诗就亡了；诗亡了，然后《春秋》才作。晋国的史叫《乘》，楚国的叫《梼杌》，鲁国的叫《春秋》，是一样的。所记的事是齐桓、晋文之事，所用的文是史官的文。孔子说：‘那其中的义，我私下取过来了。’”

五　章旨

诗亡而春秋作；事与文因旧，义则自取。

五条支撑：

  1. “迹熄”是因，“诗亡”是果。 王者不再采诗，诗就失了根。
  2. “诗亡然后春秋作”是接替。 一亡一起，不是偶然，是位子空了有人填。
  3. 三国史记”一也”是去神秘。 《春秋》不因其名而特殊。
  4. “其事则……其文则……”是划界。 事与文都不是孔子的。
  5. “其义则窃取”是自任。 一字褒贬，责任在己。

六　注家

【朱熹曰】“王者之迹熄，谓平王东迁，而政教号令不及于天下也。诗亡，谓黍离降为国风而雅亡也。”（《孟子集注·离娄下》）

【朱熹曰】“春秋，鲁史记之名。孔子因而笔削之。始于鲁隐公之元年，实平王之四十九年也。”（同上）

【朱熹曰】“乘，去声。梼，音逃。杌，音兀。乘义未详。赵氏以为兴于田赋乘马之事。或曰：’取记载当时行事而名之也。’梼杌，恶兽名，古者因以为凶人之号，取记恶垂戒之义也。”（同上）

【朱熹曰】“窃取者，谦辞也。《公羊传》作’其辞则丘有罪焉尔’，意亦如此。盖言断之在己，所谓笔则笔、削则削，游夏不能赞一辞者也。”（同上）

【尹氏曰】“言孔子作春秋，亦以史之文载当时之事也，而其义则定天下之邪正，为百王之……”（同上，引尹焞说。原刻此处有阙。）

【赵岐注】平王东迁，王迹熄，诗亡，然后春秋作；三国史记异名而同实。（按：此为赵注大意，非原文。）

对照：赵岐以”王迹”与”史记异名”立说；朱熹补”黍离降为国风”、补”笔削”、补”游夏不能赞一辞”，把”义”落在可指的操作上。赵明其变，朱指其笔。

七　分寸与边界

  1. 不可把”诗亡”读成诗全没了。**朱熹明说”雅亡”。
  2. 不可把”窃取”读成偷窃。**这是谦辞，实为”自任”。
  3. 不可把《春秋》读成现代意义的史书。**其事其文皆旧，唯义新。
  4. 不可把”一也”读成三书同值。**同的是职守，不是裁断。
  5. 不可把”王者之迹”读成虚指。**它指采诗、号令这些具体的事。

八　义理

这一章讲的是“记录”与”裁断”的分家。

第一句是一段衰史。 王者之迹熄——采诗的人不来了，号令不出王畿了。 于是诗亡。诗不是被人烧掉的，是没人再采。 一种制度的死，常常不是被禁止，是没人再做。

第二句是接替。 诗亡然后春秋作——位子空了，就得有人坐。 孟子把这两件事连起来说，意思很清楚：《春秋》不是凭空来的，它是”诗”空出来的那个位置上的继承人。 诗温柔地规劝，春秋则一字一字地裁断。

第三句最妙，是”一也”。 晋叫乘，楚叫梼杌，鲁叫春秋——名字各异，东西一样。 这一句先把《春秋》从神坛上拿下来：它首先是一部史记，和别国的史记同类。

第四、五句才是全章的骨。 “其事则齐桓晋文，其文则史”——事是别人的事，文是史官的文。 孔子没有编事，也没有造文。“其义则丘窃取之矣”——只有那个”义”，是我取的。

这五个字，是”述而不作”最精确的注。 事不创，文不创，创的只是”义”：什么该写，什么该削，谁该褒，谁该贬。一个字的重轻，就是一部书的立场。

所以《春秋》的分量不在记事，在”取义”。 孟子说这句话时，是在替孔子认账：这部书的褒贬，是我担的。

九　时代之问

  • 我做的记录，是”其事其文”，还是也取了”义”？
  • 我所在的那个”位子”，是谁空出来的？
  • 一种东西死了，是被禁的，还是没人再做了？
  • 我敢不敢说”这个判断是我下的”？
  • 我的”一字褒贬”，担得起吗？

十　跨典

  • 《论语·述而》“述而不作，信而好古”——述作之分。
  • 《孟子·滕文公下》“孔子成春秋而乱臣贼子惧”——义之效。
  • 《左传·隐公元年》“春秋笔法”——笔削之实。
  • 《诗经·王风·黍离》——诗亡之征。
  • 《公羊传·哀公十四年》“其辞则丘有罪焉尔”——异文可参。
  • 《荀子·劝学》“春秋之敬”——经之教。

十一　存疑

  1. “乘”义。 赵岐以为田赋乘马之事；朱熹曰”未详”。
  2. “诗亡”的界限。 朱熹曰”黍离降为国风而雅亡”。
  3. 尹氏语之阙文。 原刻”为百王之”下有阙，今补”法”字亦属推测。
  4. 《春秋》起年。 朱熹曰鲁隐公元年，当平王四十九年。
  5. “窃取”是否孔子原语。 孟子引之，他书异文可参。
