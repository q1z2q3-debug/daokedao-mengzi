第一百二十八章　天与之

一　本章导读

万章问：“尧以天下与舜，有诸？”——尧把天下给了舜，有这回事吗？

孟子答：“天子不能以天下与人。”

万章追问：那就是舜从尧那里得的了？孟子说：“否。天子能荐人于天，不能使天与之天下。”

于是全章的主脉出来：

“昔者，尧荐舜于天，而天受之；暴之于民，而民受之。”

怎么知道天受了？“使之主祭，而百神享之，是天受之；使之主事，而事治，百姓安之，是民受之也。天与之，人与之。”

“天不言，以行与事示之而已矣。”

万章问：以行与事示之，怎么讲？孟子举两件事：舜相尧二十有八载，非人之所能为也，天也。 尧崩，三年之丧毕，舜避尧之子于南河之南，天下诸侯朝觐者不之尧之子而之舜，讼狱者不之尧之子而之舜，讴歌者不讴歌尧之子而讴歌舜。 所以说：天也。夫然后之中国，践天子位焉。

接着引《太誓》：“天视自我民视，天听自我民听。”——天怎么看？依百姓的眼；天怎么听？依百姓的耳。

此章驳谁：驳”天子可私相授受”。立什么：立”天与之，人与之”、“天不言，以行与事示之”。留给后人什么：一道天弧，一道虚线，三个并立的小人。

二　经文

【经】万章曰：“尧以天下与舜，有诸？”孟子曰：“否。天子不能以天下与人。”“然则舜有天下也，孰与之？”曰：“天与之。”“天与之者，谆谆然命之乎？”曰：“否。天不言，以行与事示之而已矣。”曰：“以行与事示之者，如之何？”曰：“天子能荐人于天，不能使天与之天下；诸侯能荐人于天子，不能使天子与之诸侯；大夫能荐人于诸侯，不能使诸侯与之大夫。昔者，尧荐舜于天，而天受之；暴之于民，而民受之。故曰：天不言，以行与事示之而已矣。”曰：“敢问荐之于天，而天受之；暴之于民，而民受之，如何？”曰：“使之主祭，而百神享之，是天受之；使之主事，而事治，百姓安之，是民受之也。天与之，人与之，故曰：天子不能以天下与人。舜相尧二十有八载，非人之所能为也，天也。尧崩，三年之丧毕，舜避尧之子于南河之南。天下诸侯朝觐者，不之尧之子而之舜；讼狱者，不之尧之子而之舜；讴歌者，不讴歌尧之子而讴歌舜，故曰天也。夫然后之中国，践天子位焉。而居尧之宫，逼尧之子，是篡也，非天与也。《太誓》曰：’天视自我民视，天听自我民听。’此之谓也。”

四　今译

万章说：“尧把天下给了舜，有这回事吗？”孟子说：“没有。天子不能把天下给人。”“那么舜有天下，是谁给的？”孟子说：“天给的。”“天给他，会一遍遍叮咛嘱咐吗？”孟子说：“不会。天不说话，只以行事示人。”万章说：“以行事示人，是怎么讲？”孟子说：“天子能向天荐人，不能让天把天下给他；诸侯能向天子荐人，不能让天子把诸侯之位给他；大夫能向诸侯荐人，不能让诸侯把大夫之位给他。从前尧荐舜于天，天受了；显扬于民，民受了。所以说：天不说话，只以行事示人。”万章说：“请问荐于天而天受、显于民而民受，是怎样的？”孟子说：“让他主祭，百神享其祭，是天受了；让他主事，事治而百姓安，是民受了。天给，人给，所以说天子不能把天下给人。舜辅佐尧二十八年，不是人力所能做到的，是天。尧崩，三年丧毕，舜避开尧的儿子，到南河之南。天下诸侯朝见的，不去尧的儿子那里而到舜那里；打官司的，不去尧的儿子那里而到舜那里；唱歌颂的，不歌颂尧的儿子而歌颂舜。所以说：天。然后才到国都，登天子位。若住进尧的宫室、逼迫尧的儿子，那是篡，不是天给。《太誓》说：’天视自我民视，天听自我民听。’说的就是这个。”

五　章旨

天子不能以天下与人：天与之，人与之，天以行与事示之。

五条支撑：

  1. “不能以天下与人”是全章的定。 天下不是私产。
  2. “荐”三步：天、天子、诸侯、大夫。 只能荐，不能与。
  3. “主祭／主事”是两验。 一验于神，一验于民。
  4. “避南河”是关键的谦。 舜先避开，再看天下归谁。
  5. “居尧之宫，逼尧之子，是篡”是反证。 同一个人，做法不同，名就不同。

六　注家

【朱熹曰】“天下者，天下之天下，非一人之私有故也。”（《孟子集注·万章上》）

【朱熹曰】“谆谆，详语之貌。……天无形，其视听皆从于民之视听。”（同上）

【朱熹曰】“暴，显也。……荐于天而天受之，谓使之主祭而百神享之也；暴于民而民受之，谓使之主事而事治、百姓安之也。”（同上）

【朱熹曰】“舜相尧二十八年，非人之所能为者，言其久也，非有大德不足以当之。”（同上，意引）

【朱熹曰】“《太誓》，周《书》也。……天视自我民视，天听自我民听，言天即民以视听也。”（同上）

【赵岐注】天下非天子所得私与，舜之得天下，天与民与也。（按：此为赵注大意，非原文。）

对照：赵岐重”非私与”；朱熹以”天下之天下”一句把所有权问题提到最前，又以”天即民以视听”解《太誓》。赵明其戒，朱立其义。

七　分寸与边界

  1. 不可把”天与之”读成”天有意志”。**朱熹明说”天无形”。
  2. 不可把”人与之”读成”民选”。**孟子说的是”归之”，不是”投票”。
  3. 不可把”天即民”读成”民意即天意”而不加分辨。**此处是”即民以视听”，不是”民即天”。
  4. 不可把”舜避南河”读成”作态”。**二十八年相尧，然后避。
  5. 不可把”篡”与”与”混。**同是做天子，做法不同，名分就不同。

八　义理

这一章讲的是权力从哪里来，而且讲得极硬。

万章的问法最直接：尧把天下给了舜，有这回事吗？ 这是把天下当成一件可以给的东西。孟子的第一句就把这个前提打掉：“天子不能以天下与人。”——你不是天下的主人，你只是替它办事的人。

朱熹在这里加了一句极重的话：“天下者，天下之天下，非一人之私有故也。” 一句把所有权归位。

那么舜的天下从哪来？ 孟子说： 荐举只能到”荐”为止。天子能荐人于天，不能使天与之；诸侯能荐人于天子，不能使天子与之。层层只能荐，层层不能与。——这一串排比，是在说：位置不是礼物，是托付。

然后他给出”天怎么说话”的答案：天不言，以行与事示之。 行，是他做的事；事，是事的结果。“使之主祭而百神享之”——一验于神；“使之主事而事治、百姓安之”——一验于民。

最精彩的是”舜避南河之南”这一段。 尧崩，三年丧毕，舜没有直接坐上去，他躲开了；然后看天下的脚往哪边走——朝觐的、讼狱的、讴歌的，都不去尧的儿子那里，而来舜这里。 于是才”之中国，践天子位”。

孟子还留了一道反证： “居尧之宫，逼尧之子，是篡也。”——同样坐上那个位子，若是住进尧的宫、逼走尧的儿子，那就叫篡。 所以名分不在位子上，在怎么上去的路上。

《太誓》那两句，是全章的收口： 天视自我民视，天听自我民听。天不说话，但它有眼睛和耳朵——就是百姓的眼睛和耳朵。

九　时代之问

  • 我手上的位置，是”我的”，还是”托付的”？
  • 我上一次得到什么，是谁”给”的，还是我自己”取”的？
  • 我做的事，经得起”百神享之”这一验吗？
  • 我做的事，经得起”百姓安之”这一验吗？
  • 如果可以坐上去，我会不会先躲开三年？

十　跨典

  • 《尚书·尧典》“正月上日，受终于文祖”——禅让之实。
  • 《尚书·太誓》“天视自我民视”——本章所引。
  • 《论语·尧曰》“咨尔舜，天之所数在尔躬”——天命之语。
  • 《孟子·万章上》后章”天与贤”——继此而问。
  • 《礼记·礼运》“天下为公”——天下之天下。
  • 《荀子·正论》“天子者，天下之利也”——位之公。

十一　存疑

  1. “天与之”的”天”是否人格神。 朱熹以”无形”解，近于”理”。
  2. “南河之南”地望。 旧说在今山西永济一带。
  3. “二十有八载”之数。 《尚书》“二十八载”同。
  4. 《太誓》真伪。 今文《太誓》已佚，此为引文。
  5. 禅让与篡夺之辨。 战国人已有异说，《竹书纪年》记”舜囚尧”。
