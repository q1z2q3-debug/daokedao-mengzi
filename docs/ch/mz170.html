第一百七十章　民贼

一　本章导读

孟子说：“今之事君者皆曰：‘我能为君辟土地，充府库。’”

——如今事君的人都说：我能替君主开疆土、充实府库。

“今之所谓良臣，古之所谓民贼也。”

——今天所谓的良臣，正是古人所谓的民贼。

“君不乡道，不志于仁，而求富之，是富桀也。”

——君不向道、不志于仁，你却求让他富，那是让桀富。

“我能为君约与国，战必克。”

——我能替君主结好盟国，战必得胜。

“今之所谓良臣，古之所谓民贼也。”

“君不乡道，不志于仁，而求为之强战，是辅桀也。”

——君不向道，你却求替他强战，那是辅桀。

“由今之道，无变今之俗，虽与之天下，不能一朝居也。”

——照今天这套做法，不改今天的风气，就算把天下给他，也一天坐不住。

此章驳谁：驳”富国强兵即良臣”。立什么：立”富桀辅桀即民贼”。留给后人什么：一片田、一座仓、一个背对”道”的君。

二　经文

【经】孟子曰：“今之事君者皆曰：’我能为君辟土地，充府库。’今之所谓良臣，古之所谓民贼也。君不乡道，不志于仁，而求富之，是富桀也。’我能为君约与国，战必克。’今之所谓良臣，古之所谓民贼也。君不乡道，不志于仁，而求为之强战，是辅桀也。由今之道，无变今之俗，虽与之天下，不能一朝居也。”

三　字义与句读

辟　朱熹曰”辟，开垦也”。

府库　藏货财之所。

乡　朱熹曰”乡，与向同”。

约　朱熹曰”约，要结也”。

与国　朱熹曰”与国，和好相与之国也”。

强战　勉力作战。

一朝居　一日安处。

句读一处：“今之所谓良臣，古之所谓民贼也”——一句两世，同一人。这是全章的刀口。

四　今译

孟子说：“如今事君的人都说：’我能替君开疆土、充府库。’今天所谓的良臣，正是古人所谓的民贼。君不向道、不志于仁，你却求让他富，那是让桀富。’我能替君结好盟国，战必得胜。’今天所谓的良臣，正是古人所谓的民贼。君不向道、不志于仁，你却求替他强战，那是辅桀。照今天这套做法，不改今天的风气，就算把天下给他，也一天坐不住。”

五　章旨

富强非功；君不向道而富之强之，是富桀辅桀，是民贼。

五条支撑：

  1. 两句”我能”，先立世俗良臣的标准：辟地、充库、约国、克战。
  2. 两句”今之所谓……古之所谓……“，把标准反过来。
  3. “是富桀也”“是辅桀也”，两个判断，一句比一句重。
  4. “不乡道、不志于仁”是前提。 前提一换，功即成罪。
  5. “虽与之天下，不能一朝居”，收在”不可久”上。

六　注家

【朱熹曰】“辟，开垦也。”（《孟子集注·告子下》）

【朱熹曰】“乡，与向同。”（同上）

【朱熹曰】“约，要结也。与国，和好相与之国也。”（同上）

【朱熹曰】“言必争夺而至于危亡也。”（同上）

【赵岐注】富国强者，若不以仁义为本，则适足以助其君之恶。（按：此为赵注大意，非原文。）

对照：赵岐言”助恶”，朱熹断”危亡”。赵责其心，朱见其果。

七　分寸与边界

  1. 不可把本章读成”反对富强”。** 是”君不向道”而富之。
  2. 不可把”良臣”读成”忠臣”。** 忠有定向，良有标准。
  3. 不可把”富桀辅桀”读成骂人。** 是一句判断：所助者谁。
  4. 不可把”不能一朝居”读成诅咒。** 是”不可久”之理。
  5. 不可把本章读成”事君无用”。** 它问的是”所事者何”。

八　义理

这一章只有七八句话，却把一整套”良臣”的标准翻了过来。

当时的良臣是什么样？ 两类：

一类是”辟土地，充府库”——经济学家式的能臣。 一类是”约与国，战必克”——外交家、军事家式的能臣。

这两类人，在哪个时代都受重用。 他们确实”能干”，确实”有功”。

孟子的判词是： “今之所谓良臣，古之所谓民贼也。”

——同一件事，两个名字。 名字为什么不同？因为衡量的尺不同。

今天的尺是”国强”，古人的尺是”君向道”。

“君不乡道，不志于仁，而求富之，是富桀也。”

——这一句最要紧：不是”富国”错了，是”富谁”错了。 若君是桀，你让他更富，就是让桀更有力作恶。

“而求为之强战，是辅桀也。”

——“富”是给他资源，“强战”是给他刀。 一层的罪，比一层重。

所以孟子不是反对做事，他先问一句：你事的是谁？他在向哪里走？

“由今之道，无变今之俗，虽与之天下，不能一朝居也。”

——这条路走下去，给他整个天下，他也坐不住一天。

为什么坐不住？ 朱熹说：“言必争夺而至于危亡也。”

——因为”辟地、充库、约国、克战”这套逻辑，本身就以争夺为根。 你越强，争得越凶；争到极处，就是危亡。

一片田，一座仓，一个背对”道”的君。 这就是”良臣”的全部成绩。

成绩是真的。名字是错的。

九　时代之问

  • 我做的事，是在”富”谁、“强”谁？
  • 我所事之人，向道吗？
  • 我的”能力”，是资源还是刀？
  • 我这一行，用”国强”还是”君向道”作尺？
  • “不能一朝居”，说的是不是我这条路？

十　跨典

  • 《孟子·梁惠王上》“何必曰利”——富谁之问。
  • 《论语·先进》“聚敛之臣”——良臣之辨。
  • 《大学》“不以其道得之，不处也”——道与富。
  • 《荀子·王制》“富国”——儒者之富。
  • 《管子·轻重》“富国”——法家之富。
  • 《史记·商君传》“强兵”——强之效与祸。

十一　存疑

  1. “今之事君者”所指。 泛指当时策士，非一人。
  2. “约与国”之”约”。 朱熹曰”要结”，一说盟约。
  3. “富桀辅桀”之喻。 借桀言暴君，非必指桀。
  4. 本章与上章之关系。 皆论”事君”。
  5. “不能一朝居”之解。 朱熹曰”必争夺而至于危亡”。
