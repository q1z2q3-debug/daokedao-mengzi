第二百五十二章　盆成括

一　本章导读

“死矣盆成括！”

——盆成括要死了！

“其为人也小有才，未闻君子之大道也，则足以杀其躯而已矣。”

——他这人小有点才能，没听过君子的大道，那就够杀他自己了。

二十四个字，一句预言，一句解释。 这是《孟子》里唯一一次”预先断定一个人的死”。

朱熹说： “恃才妄作，所以取祸。”

徐氏曰： “君子道其常而已。括有死之道焉，设使幸而获免，孟子之言犹信也。”

此章驳谁：驳”才即是资”——把能力当护身。立什么：立”才小而不闻大道，才反杀身”。留给后人什么：一人手持一柄小刃；旁边一条大路远去，他不看；路尽头一点赭。

二　经文

【经】盆成括仕于齐。孟子曰：“死矣盆成括！”盆成括见杀。门人问曰：“夫子何以知其将见杀？”曰：“其为人也小有才，未闻君子之大道也，则足以杀其躯而已矣。”

三　字义与句读

盆成括　人名。朱熹曰”盆成，姓；括，名也”。

仕于齐　在齐做官。

见杀　被杀。

小有才　稍有才能。

未闻　未曾听闻。

大道　君子之道。

足以　足够。

句读一处：“小有才，未闻君子之大道也，则足以杀其躯而已矣” 三截。第一截是”有”，第二截是”无”，第三截是”则”. 若把”小有才”与”足以杀躯”直接连读，中间的”未闻大道”就成了陪衬；其实是这一句在起杀机——才不足恃，道不足知。

四　今译

盆成括在齐国做官。孟子说：“盆成括要死了！”盆成括果然被杀。门人问：“夫子怎么知道他将被杀？”孟子说：“他这人小有点才能，没听过君子的大道，那就足够杀他自己了。”

五　章旨

“小有才”三字，是全章的判根。

五条支撑：

  1. “仕于齐”是起点：他有了位置。
  2. “死矣”是断语，不是感叹。
  3. “见杀”是应验，不是巧合。
  4. “小有才”——才小，故不能自保。
  5. “未闻大道”——无道，故不知自止。

六　注家

【朱熹曰】“盆成，姓；括，名也。”（《孟子集注·尽心下》）

【朱熹曰】“恃才妄作，所以取祸。”（同上）

【徐氏曰】“君子道其常而已。括有死之道焉，设使幸而获免，孟子之言犹信也。”（朱熹引）

【赵岐注】盆成括有小才而无大道，恃才妄作，故知其将见杀。（按：此为赵注大意，非原文。）

对照：赵岐只说”恃才妄作”，朱熹加”所以取祸”一句断其因果，徐氏再补”幸免亦信”一层。赵指其行，朱断其因，徐固其言。

七　分寸与边界

  1. 不可把”小有才”读成”无才”.** 是”稍有”.
  2. 不可把”未闻大道”读成”不肯学”.** 是”未闻”.
  3. 不可把”足以杀其躯”读成”才多害人”.** 是”才小而无道”这一组合。
  4. 不可把本章读成”反对才能”.** 反对的是”才而无道”.
  5. 不可把”死矣”读成咒语。** 是据理而断。

八　义理

这一章有一个很硬的预言。

“盆成括仕于齐。孟子曰：‘死矣盆成括！’”

一个人刚做官，孟子就说他要死。 这话在当时听来，近乎刻毒。

“盆成括见杀。”

——他果然被杀。

门人于是问：您怎么知道的？

孟子的回答只有两层：

“其为人也小有才。”

——他有点才能。

“未闻君子之大道也。”

——可他没听过君子的大道。

然后一句收：

“则足以杀其躯而已矣。”

——这两样合起来，就够杀他了。

为什么”小才”反而危险？

因为才小，人就会高估自己。 他能办一两件事，便以为天下的事都能办。

因为无道，人就不识边界。 他不知道什么事不能碰，什么话不能说，什么位置不能坐。

才使他敢动，无道使他不知何时停。 两者相加，就是”足以杀其躯”.

朱熹四个字最准： “恃才妄作。”

——恃，是靠；妄，是不知。 靠着自己那点才，去做不知道的事。

徐氏又补一层，极有分寸： “设使幸而获免，孟子之言犹信也。”

——就算他侥幸没死，孟子的话仍然是对的。

这一句把”预言”从”命中”改成了”理中”. 孟子断的是”这条路通向死”，不是”他必死于某日”。

图上一个人，右手持一柄小刃。

刃很短，只到肘下。

右侧一条大道：两道平行长线，自人身边向远处延伸，尽头一点赭。

人不看那条路，只看手里的刃。

下方：“小有才，未闻君子之大道。”

——手里那把小刃很亮，旁边那条大路他没看见。

九　时代之问

  • 我手里的”才”，有多大？
  • 我看见旁边那条大道了吗？
  • 我”恃”的是什么？“妄”在哪儿？
  • 我的才，是在护我，还是在推我？
  • 我知道什么事不能碰吗？

十　跨典

  • 《孟子·尽心下》“以其昭昭”——上章，“明”与”才”相接。
  • 《孟子·告子上》“舍其路而弗由”——大道之弃。
  • 《论语·泰伯》“才难”——才之难得。
  • 《论语·子路》“刚毅木讷近仁”——才外之德。
  • 《老子》第五十二章”用其光，复归其明”——光与明。
  • 《荀子·宥坐》“有才而无道”之戒。

十一　存疑

  1. 盆成括其人。 朱熹曰”盆成，姓；括，名”,他书无详。
  2. “见杀”之由。 史无明文。
  3. “小有才”是否指”辩给”. 注家只作”稍有才能”.
  4. 本章是否在盆成括仕齐之初。 文曰”仕于齐”，当是初。
  5. 徐氏”犹信”之说是否为孟子本意。 朱熹引之，以为的解。
