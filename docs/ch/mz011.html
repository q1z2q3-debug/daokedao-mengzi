第十一章　雪宫之乐

一　本章导读

齐宣王在自己的离宫雪宫里见孟子，问：“贤者也有这种快乐吗？”意思很直：这样的享乐，贤人怎么说得过去？

孟子答：有。人若得不到，就会怨他的上位；得不到而怨上，是不对的；但身为上位而不与民同乐，也是不对的。然后给出全书最著名的一联：乐民之乐者，民亦乐其乐；忧民之忧者，民亦忧其忧。乐以天下，忧以天下，然而不王者，未之有也。

接着讲齐景公与晏子一段极长的对话：景公想出去游玩，问怎么才能比得上先王的”观”。晏子说：天子到诸侯叫巡狩，诸侯朝天子叫述职——没有一件是白走的。春天察看耕种、补助不足，秋天察看收获、救济不够。夏谚说”吾王不游，吾何以休；吾王不豫，吾何以助”——先王出游，民得以休息得补助。如今却不然：队伍一动就要粮，饥者不得食，劳者不得息，人人侧目怨谤。这叫”流连荒亡”。

景公听了，大戒于国，出舍于郊，兴发仓廪补不足；又召乐官作君臣相说之乐，就是《徵招》《角招》，诗里说”畜君何尤”——畜君，就是爱君。

此章驳谁：驳”享乐必私”的默认，也驳”贤者不该乐”的假道学。立什么：立”游也有两种”——一种带政事，一种只带自己。留给后人什么：一个判法：一场巡游是福利还是负担，看它走的时候留下了什么。

二　经文

【经】齐宣王见孟子于雪宫。王曰：“贤者亦有此乐乎？”孟子对曰：“有。人不得，则非其上矣。不得而非其上者，非也；为民上而不与民同乐者，亦非也。

【经】乐民之乐者，民亦乐其乐；忧民之忧者，民亦忧其忧。乐以天下，忧以天下，然而不王者，未之有也。

【经】昔者齐景公问于晏子曰：‘吾欲观于转附、朝儛，遵海而南，放于琅邪，吾何修而可以比于先王观也？’晏子对曰：’善哉问也！天子适诸侯曰巡狩——巡狩者，巡所守也；诸侯朝于天子曰述职——述职者，述所职也。无非事者。春省耕而补不足，秋省敛而助不给。夏谚曰：吾王不游，吾何以休？吾王不豫，吾何以助？一游一豫，为诸侯度。’

【经】‘今也不然：师行而粮食，饥者弗食，劳者弗息。睊睊胥谗，民乃作慝。方命虐民，饮食若流。流连荒亡，为诸侯忧。……先王无流连之乐、荒亡之行。惟君所行也。’

【经】景公说，大戒于国，出舍于郊。于是始兴发补不足。召大师曰：’为我作君臣相说之乐！’盖《徵招》《角招》是也。其诗曰：’畜君何尤？’畜君者，好君也。”

三　字义与句读

雪宫　离宫名。

非其上　非，怨非、责怪。

巡狩　巡所守。述职　述所职。

无非事者　没有一件是白走的。朱熹：“皆无有无事而空行者。”

省耕　察看耕种。省敛　察看收获。

豫　乐。为诸侯度　成为诸侯的法度。

师行而粮食　队伍一动就要运粮。睊睊　侧目相看。胥谗　互相怨谤。慝　怨恶。

方命　逆命。饮食若流　吃喝如水之流，无有穷极。

流连荒亡　朱熹：“从流下而忘反谓之流，从流上而忘反谓之连，从兽无厌谓之荒，乐酒无厌谓之亡。”

畜君　畜，止也；止君之欲。何尤　有什么过错。

句读两处：

  1. “人不得，则非其上矣”——“不得”是”得不到这种乐”，不是”不得志”。
  2. “无非事者”——“事”是政事；此句是全段的枢纽：先王出游，每一趟都有事由。

四　今译

齐宣王在雪宫见孟子。王问：“贤者也有这种快乐吗？”孟子答：“有。人若得不到，就会怨他的上位；得不到而怨上，不对；身为上位而不与民同乐，也不对。

以民的乐为乐，民也以你的乐为乐；以民的忧为忧，民也以你的忧为忧。乐以天下，忧以天下，这样还不能王天下的，没有过。

从前齐景公问晏子：‘我想去转附、朝儛游观，沿海往南，直到琅邪，我怎样做才能比得上先王的游观？’晏子说：’问得好！天子到诸侯叫巡狩——就是巡视所守之地；诸侯朝天子叫述职——就是陈说自己所职之事。没有一件是白走的。春天察看耕种、补助不足，秋天察看收获、救济不够。夏谚说：我们的王不出游，我们靠谁休息？我们的王不游乐，我们靠谁补助？一游一乐，都是诸侯的法度。’

‘如今却不然：队伍一动就要运粮，饥者不得食，劳者不得息，人人侧目、互相怨谤，民就生出怨恶。逆命虐民，饮食如水。流连荒亡，成为诸侯的忧患。……先王没有流连之乐、荒亡之行。只看君怎么做了。’

景公听了很高兴，在国内大发告令，出居郊外以自省。于是开始开仓补不足，召乐官说：‘给我作一支君臣相悦的乐！’就是《徵招》《角招》。诗里说’畜君何尤’——畜君，就是爱君。”

五　章旨

游有两种：一种带着政事，一种只带着自己。前一种，民盼你来；后一种，民怕你来。

五条支撑：

  1. 孟子先答”有”——不否认贤者可以享乐。这一答就把”贤者不该乐”的道学挡回去了。
  2. 但他立刻加一侧：上不与民同乐，也是不对的。 上下两头都非，这才是全句。
  3. “乐以天下，忧以天下”——“以”字是关键：把你的乐与忧，做天下的尺度，不是把天下做你的乐与忧的原料。
  4. 晏子那段是判例：巡狩述职”无非事者”，即每趟公差都有事由。若无事而游，就是”流连荒亡”。
  5. 景公的反应是最实的落地：出舍于郊（自责）、兴发补不足（开仓）。改的不是心情，是动作。

六　注家

【朱熹曰】“雪宫，离宫名。言人君能与民同乐，则人皆有此乐；不然，则下之不得此乐者，必有非其君上之心。明人君当与民同乐，不可使人有不得者，非但当与贤者共之而已也。”（《孟子集注·梁惠王下》）

【朱熹曰】“下不安分，上不恤民，皆非理也。”（同上）

【朱熹曰】“乐民之乐而民乐其乐，则乐以天下矣；忧民之忧而民忧其忧，则忧以天下矣。”（同上）

【朱熹曰】“巡所守，巡行诸侯所守之土也。述所职，陈其所受之职也。皆无有无事而空行者，而又春秋循行郊野，察民之所不足而补助之。故夏谚以为王者一游一豫，皆有恩惠以及民，而诸侯皆取法焉，不敢无事慢游以病其民也。”（同上）

【朱熹曰】“从流下，谓放舟随水而下。从流上，谓挽舟逆水而上。从兽，田猎也。荒，废也。乐酒，以饮酒为乐也。亡，犹失也，言废时失事也。”（同上）

【朱熹引尹氏曰】“君之与民，贵贱虽不同，然其心未始有异也。孟子之言，可谓深切矣。齐王不能推而用之，惜哉！”（同上）

对照：赵岐注此章偏于地理（转附、朝儛、琅邪所在）；朱熹偏于”无非事者”四字，把巡狩述职解成”有事的出差”。这一解最实用：先王的游，是有事由的公差；后世君的游，是无事由的私行。 差别不在走多远，在有没有事。

七　分寸与边界

  1. 不可把”乐以天下”读成”要与民同甘”的情感口号。它是尺度问题：拿天下量你的乐。
  2. 不能把”人不得则非其上”当作斥民。孟子明说”不得而非其上者，非也”——怨上不对，但不与民同乐更不对。两非并立。
  3. 不可把”无非事者”当作给巡游找借口的模板。事由要真，补助要落到人。
  4. 不能把景公”出舍于郊”当表演。他接着是”兴发补不足”——自责之后有动作，才算数。

八　义理

此章的分量，在”以”这个字。

“乐以天下，忧以天下”——不是”与天下同乐”，是”以天下为尺度”。前者讲感情，后者讲度量。你的快乐有多大，不由你的感受定，由它能覆盖多少人定。一个人独享的乐，再盛也只是一个人的尺寸。

第二层是”无非事者”。这四个字把”游”分成了两类：有事由的与无事由的。有事由，走千里也是公；无事由，走十里也是私。所以判断一场巡游，不看排场大小，看它有没有”事”。

第三层是”畜君”。景公听了晏子的话，不但没恼，反而作乐纪念，说”畜君何尤”——拦住我的欲望的人，有什么错？这一句极难得：一个君，能承认拦他的人是爱他。 孟子把它写进来，是给齐宣王看：这才是听得进话的样子。

合起来：此章不只是讲享乐，它讲的是权力的自我节制如何可能。答案有三：一是把乐放到天下的尺度上量；二是给每次出行配上事由；三是身边有一个能”畜”你的人，而你肯认他是爱你。

九　时代之问

今天每一次”巡游”都还在：考察、调研、团建、出差、视察、年会。

  • 有没有”事”？ 这趟走，补助了谁、解决了什么、留下了什么。若答不出，就是流连。
  • 民（员工、客户、被视察者）盼你来还是怕你来？ 盼，则你来是休与助；怕，则你来是粮与扰。
  • 我身边有没有”畜君”的人？ 有没有一个能拦住你、而你不恼的人。若没有，你的乐就无人量。
  • 我自责之后有没有动作？ “出舍于郊”只是姿态，“兴发补不足”才是改。

十　跨典

  • 《老子》第六十四章：“民之从事，常于几成而败之。”——乐极则败，正在几成之处。
  • 《论语·学而》：“道千乘之国，敬事而信，节用而爱人，使民以时。”——“使民以时”，即”无非事者”。
  • 《易·豫·彖》：“豫，顺以动。”——豫而顺，则动不扰。
  • 《诗经·小雅·天保》：“如月之恒，如日之升。”——民之祝君，出于自愿。
  • 《书·无逸》：“不知稼穑之艰难，乃逸。”——逸而不知艰难，则乐成害。

十一　存疑

  1. “转附、朝儛”之地。 旧说皆齐之山名，所在已不可确考。
  2. “放于琅邪”之”放”。 朱熹训”至”；一说”放”为”仿”，谓效法。从朱读。
  3. 《徵招》《角招》之诗。 朱熹谓”其诗，徵招角招之诗也”，今已不传；“畜君何尤”一句仅存。
  4. 本章是否一时之语。 景公晏子一段甚长，或为孟子引旧闻以讽，非与宣王一时对答。不影响章旨。
