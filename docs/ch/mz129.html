第一百二十九章　天与贤

一　本章导读

万章接着问：“人有言：’至于禹而德衰，不传于贤而传于子。’有诸？”

——有人说，到禹的时候德就衰了，不传给贤人而传给儿子，有这回事吗？

孟子答：“否，不然也。天与贤，则与贤；天与子，则与子。”——不是这样。天要给贤人，就给贤人；天要给儿子，就给儿子。

接着是一串史事：舜荐禹于天，十有七年，舜崩；三年之丧毕，禹避舜之子于阳城，天下之民从之，若尧崩之后不从尧之子而从舜也。 禹荐益于天，七年，禹崩；三年之丧毕，益避禹之子于箕山之阴。朝觐讼狱者不之益而之启，说：“这是我君的儿子。”讴歌者不讴歌益而讴歌启，说：“这是我君的儿子。”

孟子说：“启贤，能敬承继禹之道。”

然后是一段极冷静的话：

“丹朱之不肖，舜之子亦不肖。舜之相尧、禹之相舜也，历年多，施泽于民久。启贤，能敬承继禹之道。益之相禹也，历年少，施泽于民未久。”

“舜、禹、益之间，相去久远，其子之贤不肖，皆天也，非人之所能为也。莫之为而为者，天也；莫之致而至者，命也。”

最后一句最要紧：“若孔子，则闻命矣。”——孔子没有天子之位。

此章驳谁：驳”禹德衰而传子”。立什么：立”天与贤／天与子”、“莫之为而为者天”。留给后人什么：一架权衡，两端是”贤”与”子”。

二　经文

【经】万章问曰：“人有言：‘至于禹而德衰，不传于贤而传于子。’有诸？“孟子曰：”否，不然也。天与贤，则与贤；天与子，则与子。昔者，舜荐禹于天，十有七年，舜崩。三年之丧毕，禹避舜之子于阳城。天下之民从之，若尧崩之后，不从尧之子而从舜也。禹荐益于天，七年，禹崩。三年之丧毕，益避禹之子于箕山之阴。朝觐讼狱者不之益而之启，曰：’吾君之子也。’讴歌者不讴歌益而讴歌启，曰：’吾君之子也。’丹朱之不肖，舜之子亦不肖。舜之相尧、禹之相舜也，历年多，施泽于民久。启贤，能敬承继禹之道。益之相禹也，历年少，施泽于民未久。舜、禹、益之间，相去久远，其子之贤不肖，皆天也，非人之所能为也。莫之为而为者，天也；莫之致而至者，命也。匹夫而有天下者，德必若舜、禹，而又有天子荐之者，故仲尼不有天下。继世以有天下，天之所废，必若桀、纣者也，故益、伊尹、周公不有天下。伊尹相汤以王于天下。汤崩，太丁未立，外丙二年，仲壬四年。太甲颠覆汤之典刑，伊尹放之于桐。三年，太甲悔过，自怨自艾，于桐处仁迁义；三年，以听伊尹之训己也，复归于亳。周公之不有天下，犹益之于夏、伊尹之于殷也。孔子曰：’唐、虞禅，夏后、殷、周继，其义一也。’”

亳　殷都。

句读一处：“匹夫而有天下者，德必若舜、禹，而又有天子荐之者”——两个条件并列：德如舜禹，又有荐者。 孔子德够而荐者无，故不有天下。 这一句是全章的算术。

四　今译

万章问：“有人说：‘到禹时德衰了，不传贤而传子。’有这回事吗？“孟子说：”不，不是这样。天要给贤人，就给贤人；天要给儿子，就给儿子。从前舜荐禹于天，十七年，舜崩。三年丧毕，禹避舜之子于阳城。天下百姓跟从他，就像尧崩之后不跟尧的儿子而跟舜一样。禹荐益于天，七年，禹崩。三年丧毕，益避禹之子于箕山之阴。朝觐、打官司的不去益那里而到启那里，说：’这是我们君主的儿子。’唱歌颂的不歌颂益而歌颂启，说：’这是我们君主的儿子。’丹朱不贤，舜的儿子也不贤。舜辅佐尧、禹辅佐舜，历年多，施恩于民久。启贤，能敬慎承继禹的道。益辅佐禹，历年少，施恩于民未久。舜、禹、益之间，相隔久远，其子的贤与不贤，都是天，不是人力所能为。没有谁去做却做成了，是天；没有谁去招却来了，是命。一个平民而得到天下，德必须像舜、禹，又要有天子荐他，所以仲尼不得有天下。承继世位而有天下，天所要废的，必定像桀、纣那样，所以益、伊尹、周公不有天下。伊尹辅佐汤王于天下。汤崩，太丁未立而死，外丙在位二年，仲壬在位四年。太甲败坏汤的常法，伊尹把他放逐到桐。三年，太甲悔过，自责自改，在桐处仁迁义；三年，听伊尹训导自己，回到亳。周公不有天下，同益在夏、伊尹在殷一样。孔子说：’唐、虞禅让，夏、殷、周继世，其义一也。’”

五　章旨

天与贤则与贤，天与子则与子；莫之为而为者天，莫之致而至者命。

五条支撑：

  1. “天与贤／天与子”两句并列。 传贤传子，不是德之升降。
  2. “避”是三次重现的动作。 禹避阳城，益避箕山，舜避南河。
  3. “历年多／施泽久”是可见的量。 天意落在时间上。
  4. “二条件”解释了孔子。 德如舜禹，又有荐者——孔子缺后一条。
  5. “其义一也”是孔子的判。 禅与继，义同。

六　注家

【朱熹曰】“外丙、仲壬之年，皆未可详。”（《孟子集注·万章上》，释”外丙二年，仲壬四年”）

【朱熹曰】“莫之为而为者，天也；莫之致而至者，命也。”（《孟子集注·万章上》）朱熹曰：“盖以理言之谓之天，自人言之谓之命，其实则一而已。”

【朱熹曰】“匹夫而有天下者，德必若舜、禹，而又有天子荐之者。”（同上）朱熹曰：“故仲尼不有天下。”

【杨氏曰】“尧、舜、禹之心，皆无一毫私意也。……此天与之，非人力也。”（同上，引杨时说）

【尹氏曰】“知前圣之心者，无如孔子，继孔子者，孟子而已矣。”（同上，引尹焞说）

【赵岐注】传贤传子，皆天与之；益、伊尹、周公不有天下，以继世之君未大恶。（按：此为赵注大意，非原文。）

对照：赵岐顺释史事；朱熹以”理言之谓天，人言之谓命”一句统住全章，又以”二条件”算出孔子之不得。赵明其事，朱立其算。

七　分寸与边界

  1. 不可把”天与子”读成”家天下合理”。**孟子是在说”哪一种都是天与”，不是”应该传子”。
  2. 不可把”莫之为而为”读成”宿命”。**它是”非人力所能为”的另一个说法。
  3. 不可把”其义一也”读成”禅与继无别”。**义同而事异。
  4. 不可忽略”施泽于民久”这一条。**天意是可量的：时间与恩泽。
  5. 不可把”孔子不有天下”读成”孔子失败”。**他缺的是”荐”，不是”德”。

八　义理

这一章要回答一个很尖锐的指控：禹把天下传给儿子，是不是德衰了？

孟子的答法，是把”传贤/传子”的问题从道德里拿出来，放进”天”里。 “天与贤则与贤，天与子则与子”——哪一种都是天给，不是人选。

但他没有停在”天意难测”上。 他给了三件可看的事：

第一，避。 禹避阳城，益避箕山，舜避南河。三个人都先躲开，然后看天下的脚往哪边走。

第二，历年。 舜相尧、禹相舜，历年多；益相禹，历年少。时间长短，直接决定”施泽于民”的深浅。

第三，其子之贤不肖。 丹朱不肖，舜子亦不肖，启贤。这三件事，孟子说”皆天也，非人之所能为”。

于是”天”这个字，在孟子这里不是一个人格神，是一个”不由人做主的总账”。 朱熹说得最准：“以理言之谓之天，自人言之谓之命，其实则一而已。”

然后是最漂亮的一段算账：匹夫而有天下，要两个条件——德如舜禹，又有天子荐之。 孔子两样只占一样。所以”仲尼不有天下”，不是他不够，是荐者无。

再一段是反面的算账：继世而有天下，天所要废的，必定像桀纣那样。 益、伊尹、周公不有天下，是因为他们要取代的君主，还没坏到那个份上。

这一章的分量，在于它把”成败”和”德”解开了。 有德而不成，是常事；成了而无德，也是常事。孟子不拿成败论人，他拿条件论事。

九　时代之问

  • 我这一件事没做成，是德不够，还是条件不够？
  • 我的”施泽”做了多久？
  • 我有没有先”避”一下，再决定要不要？
  • 我评论一个人的成败，用的是结果，还是条件？
  • 我的”命”，是不是只是我不肯承认的那个”条件”？

十　跨典

十一　存疑

  1. 外丙、仲壬之年。 朱熹曰”未可详”，今文《尚书》有异。
  2. “桐”之地望。 旧说在今河南偃师。
  3. “其义一也”是否孔子语。 朱熹曰”孔子之言，见于《书》传”。
  4. 益、伊尹、周公”不有天下”的读法。 一说谓”不终有”，一说谓”本可有而不取”。
  5. “天与子”是否即”家天下”。 孟子未作此断，后世多引申。
