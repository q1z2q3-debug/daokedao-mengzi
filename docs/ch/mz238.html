第二百三十八章　百世之师

一　本章导读

“圣人，百世之师也，伯夷、柳下惠是也。”

——圣人，是百世之后的老师；伯夷、柳下惠就是。

“故闻伯夷之风者，顽夫廉，懦夫有立志；闻柳下惠之风者，薄夫敦，鄙夫宽。”

——所以听到伯夷风范的人，贪的会变廉洁，懦的会立志；听到柳下惠风范的人，刻薄的会变厚道，器量小的会变宽。

“奋乎百世之上，百世之下，闻者莫不兴起也。”

——在百世之前奋起，百世之后听见的人，没有不感奋振作的。

“非圣人而能若是乎？而况于亲炙之者乎？”

——不是圣人能做到这样吗？何况那些亲身受他熏炙的人呢？

这一章是《孟子》里对”风化”写得最具体的一段。 八个字一组，四种人各有其变。

朱熹说： “兴起，感动奋发也。亲炙，亲近而熏炙之也。”

此章驳谁：驳”圣人只利一时”——以当世效用论圣。立什么：立”风可及百世”。留给后人什么：上方两像，各一道向下的风弧；下四人，虚影在后，现形在前。

二　经文

【经】孟子曰：“圣人，百世之师也，伯夷、柳下惠是也。故闻伯夷之风者，顽夫廉，懦夫有立志；闻柳下惠之风者，薄夫敦，鄙夫宽。奋乎百世之上，百世之下，闻者莫不兴起也。非圣人而能若是乎？而况于亲炙之者乎？”

三　字义与句读

百世　百代。

风　风范、余风。

顽夫　贪顽之人。朱熹曰”顽夫，贪顽之人”（按语义）。

敦　厚。

鄙夫　器量狭小之人。

兴起　朱熹曰”感动奋发也”。

亲炙　朱熹曰”亲近而熏炙之也”。

句读一处：“非圣人而能若是乎？而况于亲炙之者乎？” 是两个反问连用。第一个反问收”闻风者”,第二个反问推”亲炙者”. 若把两句合成一句读，第二层的递进就没有了——耳闻尚且如此，亲受当然更甚。

四　今译

孟子说：“圣人，是百世之后的老师，伯夷、柳下惠就是。所以听到伯夷的风范，贪的会廉洁，懦的会立志；听到柳下惠的风范，刻薄的会厚道，器量小的会宽。在百世之上奋起，百世之后听见的人，没有不感奋振作。不是圣人能这样吗？何况亲身受其熏炙的人呢？”

五　章旨

“风”字是这一章的枢：不靠教，靠吹。

五条支撑：

  1. “百世之师”不是”百世之君”，师无位而有力。
  2. 四组对治：顽→廉、懦→立志、薄→敦、鄙→宽。
  3. 两组配对，一严一宽，正伯夷、柳下惠之异。
  4. “奋乎百世之上”——风有起点。
  5. “亲炙”二字把”闻”与”受”分开，见其递进。

六　注家

【朱熹曰】“兴起，感动奋发也。亲炙，亲近而熏炙之也。”（《孟子集注·尽心下》）

【朱熹曰】“余见前篇。”（同上，指《万章下》论伯夷、柳下惠诸章）

【赵岐注】伯夷之风，能使顽贪者廉，懦弱者立志；柳下惠之风，能使薄者敦，鄙者宽。（按：此为赵注大意，非原文。）

对照：赵岐只作平解四组，朱熹点出”感动奋发”“亲近熏炙”两词，把”风”的机制说成”熏”.赵列其效，朱言其法。

七　分寸与边界

  1. 不可把”百世之师”读成”百世之王”.** 师无位。
  2. 不可把”风”读成”教”.** 风是熏，教是授。
  3. 不可把”顽夫廉”读成”顽夫变廉”.** 是”闻风而廉”，非教而后廉。
  4. 不可把伯夷、柳下惠读成同一型。** 一严一宽，四组正分属之。
  5. 不可把”亲炙”读成”亲受业”.** 是亲近而熏炙。

八　义理

这一章写的不是圣人，是”风”。

“圣人，百世之师也。”

注意”师”这个字。 不是说”圣人是百世的君主”,是说”老师”.

师与君之别在一处：君靠位，师靠风。

“伯夷、柳下惠是也。”

两个人，两种风。

“闻伯夷之风者，顽夫廉，懦夫有立志。”

伯夷是”严”的一路。 他饿死首阳山，不食周粟。这股风是”不肯”.

不肯的人，会让贪的人羞，让懦的人立。

“闻柳下惠之风者，薄夫敦，鄙夫宽。”

柳下惠是”宽”的一路。 他”不羞污君，不辞小官”，三次被黜而不去。这股风是”能容”.

能容的人，会让刻薄的人厚，让器量小的人宽。

四组对治，两两分属：

顽→廉（贪变洁）、懦→立志（弱变强）——伯夷之风。 薄→敦（刻变厚）、鄙→宽（窄变宽）——柳下惠之风。

“奋乎百世之上，百世之下，闻者莫不兴起也。”

“奋”是这股风的起点。 一个人在百世之前奋起，百世之后还有人被吹动。

“非圣人而能若是乎？”

第一反问：这还不是圣人？

“而况于亲炙之者乎？”

第二反问：何况亲身在他身边的人？

“亲炙”两个字，朱熹说”亲近而熏炙之也”。

炙，是火烤。 靠近火的人，不必学，也会暖。

图上上方两像：左一人冠而瘦，右一人宽袍。

各有一道长弧自上垂下，落在下方四个人身上。

下方四人：左二人身后各有一道虚线旧形（一弯背、一垂手），现形直立。

右二人身后各有一道虚线旧形（一窄身、一并臂），现形展臂。

下方：“百世之下，闻者莫不兴起。”

——两个人在上，四道风在下，四个人变了形。

九　时代之问

  • 我受的是谁的风？
  • 我的风，吹得动谁？
  • 我是”严”的一路，还是”宽”的一路？
  • 我离得近的人，被我熏成了什么样？
  • 我有没有把”教”当成”风”？

十　跨典

  • 《孟子·万章下》“伯夷，圣之清者也”——伯夷之品。
  • 《孟子·万章下》“柳下惠，圣之和者也”——柳下惠之品。
  • 《孟子·公孙丑上》“伯夷、柳下惠之风”——同语。
  • 《论语·微子》“不降其志，不辱其身，伯夷、叔齐与”——严之极。
  • 《论语·微子》“柳下惠、少连，降志辱身矣”——宽之极。
  • 《礼记·学记》“师严然后道尊”——师之道。

十一　存疑

  1. “百世”是否确数。 是极言其远。
  2. “顽夫”之”顽”是否作”贪”. 赵岐、朱熹均以”贪顽”释。
  3. 四组是否确分属二人。 前二属伯夷，后二属柳下惠，注家无异。
  4. “风”是否为”风化”之简称。 是风范、余风。
  5. 本章与《万章下》诸章关系。 义相足，文不相属。

读图三处：

  1. 两弧自上而下，不断。 风是隔世仍吹的。
  2. 旧形用虚线，新形用实线。 变的是形，不是人。
