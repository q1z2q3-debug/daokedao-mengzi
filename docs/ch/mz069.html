第六十九章　沧浪之水

一　本章导读

开头是一句反问：不仁者可与言哉？ ——不仁的人，还能跟他讲道理吗？

孟子先说他的样子：安其危而利其菑，乐其所以亡者。 ——把危险当安稳，把灾祸当好处，爱干那些会让自己亡掉的事。

然后是那句最伤人的话：不仁而可与言，则何亡国败家之有？ ——这种人要是还能听得进话，世上哪来亡国败家的事。

接着是一首童谣：沧浪之水清兮，可以濯我缨；沧浪之水浊兮，可以濯我足。

孔子听见了，让弟子们听：清斯濯缨，浊斯濯足矣，自取之也。 ——水清就洗帽缨，水浊就洗脚，是水自己招来的。

再往下，孟子把”自取”推成三级：夫人必自侮，然后人侮之；家必自毁，而后人毁之；国必自伐，而后人伐之。

收在《太甲》一句：天作孽，犹可违；自作孽，不可活。

此章驳谁：驳”我的处境是别人给的”。立什么：立”自取”的三级：人自侮、家自毁、国自伐。留给后人什么：一首童谣与一个动作——水清洗缨，水浊洗脚。

二　经文

【经】孟子曰：“不仁者可与言哉？安其危而利其菑，乐其所以亡者。不仁而可与言，则何亡国败家之有？

【经】“有孺子歌曰：‘沧浪之水清兮，可以濯我缨；沧浪之水浊兮，可以濯我足。’孔子曰：’小子听之！清斯濯缨，浊斯濯足矣，自取之也。’

【经】“夫人必自侮，然后人侮之；家必自毁，而后人毁之；国必自伐，而后人伐之。《太甲》曰：’天作孽，犹可违；自作孽，不可活。’此之谓也。”

三　字义与句读

菑　朱熹：“菑，与灾同。”

安其危／利其菑　朱熹：“安其危利其菑者，不知其为危菑而反以为安利也。”——不是明知故犯，是把危险看成了安稳。这一条注释很重要：它把”不仁”从”坏”改成了”看错”。

乐其所以亡者　朱熹：“所以亡者，谓荒淫暴虐，所以致亡之道也。”

沧浪　朱熹：“沧浪，水名。”缨：“冠系也。”

清斯濯缨，浊斯濯足　朱熹：“言水之清浊有以自取之也。”——“自取”的主语是水，不是人。这一层最容易被读反。

自侮／自毁／自伐　朱熹：“所谓自取之者。”

太甲　《尚书》篇名。朱熹：“解见前篇。”

句读一处：“清斯濯缨，浊斯濯足矣，自取之也。”——“斯”是”就”。清就洗缨，浊就洗脚：这是水与人的一种自动配对。 “自取”落在水身上：水的清浊，是它自己弄成的；人的用与不用，是顺着它的清浊来的。

四　今译

孟子说：“不仁的人，还能跟他讲道理吗？把危险当安稳，把灾祸当好处，专爱干那些让自己亡掉的事。这种人要是还听得进话，世上哪来亡国败家的事？

“有个孩子唱歌：‘沧浪的水清啊，可以洗我的帽缨；沧浪的水浊啊，可以洗我的脚。’孔子说：’弟子们听！水清就洗帽缨，水浊就洗脚，是它自己招来的。’

“人一定是自己先侮辱自己，别人才侮辱他；家一定是自己先毁，别人才毁它；国一定是自己先攻伐自己，别人才攻伐它。《太甲》说：’天降的灾，还可以躲；自己作的孽，逃不掉。’说的就是这个。”

五　章旨

“别人怎么对我”，多半是我先把自己弄成了那个样子。

五条支撑：

  1. “安其危而利其菑”是一种看错，不是一种坏。 朱熹：“不知其为危菑而反以为安利也。”——不仁的第一症状是判断失灵，第二症状才是行为失当。
  2. 童谣里没有道德，只有配对。 清配缨，浊配足。水不挑人，人挑水；而水清还是水浊，是水自己的事。
  3. “自取”的主语是水。 这一层读反，全章就成了”人活该”。朱熹说得清楚：水的清浊是它自己取来的，于是人拿它做什么，也就定了。
  4. 三级”自”：人、家、国。 自侮→人侮，自毁→人毁，自伐→人伐。同一句法三遍，把”外来的”一律改成”先来的”。
  5. “天作孽，犹可违”给了一条退路。 天灾可以躲，人祸躲不掉。孟子把”不可活”四个字留给”自作孽”，是本章最重的一笔。

六　注家

【朱熹曰】“安其危利其菑者，不知其为危菑而反以为安利也。”（《孟子集注·离娄上》）

【朱熹曰】“不仁之人，私欲固蔽，失其本心，故其颠倒错乱至于如此，所以不可告以忠言，而卒至于败亡也。”（同上）

【朱熹曰】“言水之清浊有以自取之也。圣人声入心通，无非至理，此类可见。”（同上）

【朱熹曰】“此章言心存则有以审夫得失之几，不存则无以辨于存亡之着。祸福之来，皆其自取。”（同上）

对照：赵岐注此章，释”沧浪”为水名，释”缨”为冠系，重在名物；朱熹则抓住”自取”二字，先解作”水之清浊有以自取”，再推及人、家、国三级，末以”心存／不存”收束。赵明其物，朱推其自。

七　分寸与边界

  1. 不可把”自取”读成”受害者活该”。孟子说的是”先有自侮，然后人侮”这一种次序，不是给一切欺凌找理由。
  2. 不可把”清斯濯缨，浊斯濯足”读成”人随水变”。它讲的是水自己取来的清浊，决定了它被怎么用。
  3. 不可把”不仁者可与言哉”读成”不必再劝”。它是”话进不去”的判断，不是”不必救”的命令。
  4. 不可把”天作孽犹可违”读成”天灾无所谓”。它是在做对比：可躲的与不可躲的，哪个更重。
  5. 不可把此章读成”因果报应”。孟子讲的是可推演的次序（自侮→人侮），不是天道的记账。

八　义理

这一章在中国流传极广，多半因为那首童谣。但它真正的骨架，是”自取”这两个字。

第一层，判断失灵。 “安其危而利其菑”——把危险当安稳，把灾祸当好处。 朱熹点出”不知其为危菑”，这一条极准：不仁的人不是先坏，是先看不准。 看不准之后，一切劝告都成了噪音——所以”不可与言”。

第二层，水与人的配对。 童谣里没有一个道德字。清配缨，浊配足。孔子那一句是点睛：不是人选了水，是水的清浊先把自己放在了某个位置上。 朱熹说”水之清浊有以自取之也”——“自取”的主语是水。 这一层如果不看清，整章就会被读成”人分三六九等”。

第三层，三级推演。 人自侮→人侮；家自毁→人毁；国自伐→人伐。孟子用的是同一个句式三次。 这个句式的力量在于：它把”外来的”一律改写成”先来的”。 别人为什么敢侮你？因为你先把自己放在那个位置上了。

第四层，天命与人孽的分界。 “天作孽，犹可违；自作孽，不可活。”——这一句把世上的祸分了两类：一类可以躲，一类躲不掉。 前者是天给的，后者是自己做的。孟子把最重的四个字”不可活”，留给了后者。

所以这一章的主题不是”报应”，是”位置”。 水的清浊决定它被用来洗什么；人的自处决定他被怎样对待。而这两件事，都发生在别人动手之前。

九　时代之问

  • 我现在的处境，有多少是我先把自己放到那个位置上的？
  • 我把什么危险当成了安稳？
  • 我这一摊事，是”天作孽”，还是”自作孽”？
  • 我的水，是清的，还是浊的？我在拿它洗什么？
  • 我说”别人都这样对我”，那句”都”里，有没有我自己的手？

十　跨典

  • 《尚书·太甲》：“天作孽，犹可违；自作孽，不可活。”——本章所引，全章的收束。
  • 《论语·子张》：“君子之过也，如日月之食焉。”——“自取”的另一面：过错可见。
  • 《孟子·公孙丑上》：“仁则荣，不仁则辱。”——同一条自取之理。
  • 《孟子·离娄上》上一章：“顺天者存，逆天者亡。”——“天”与”自”的分界。
  • 《荀子·荣辱》：“先义而后利者荣，先利而后义者辱。”——荣辱自取。
  • 《左传·隐公元年》：“多行不义，必自毙。”——“自伐”的史例。

十一　存疑

  1. “沧浪”的地望。 朱熹谓水名，一说在汉水之支流，一说为水色之形容，注家不一。
  2. “缨”的形制。 朱熹训”冠系”，即系帽之带；一说指帽缨之饰。
  3. “自取”的主语。 朱熹解为水自取，今人多解为人自取，此为本卷与他本分歧最大处。
  4. “安其危”的读法。 一说”安”为”安处”，谓安处于危而不自知；与朱熹”反以为安利”义近。
  5. 童谣的来源。 朱熹未注出处，后世多以为楚地民歌，《楚辞·渔父》有”沧浪之水清兮”一段。

读图三处：

  1. 上游那段清水与那双濯缨的手——水清，所以被用来洗最上的东西。缨在头上。
  2. 下游那段浊水与那双脚——水浊，所以只能洗最下的东西。脚在底下。同样的水，位置变了，用法就变了。
