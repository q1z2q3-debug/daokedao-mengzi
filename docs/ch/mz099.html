第九十九章　后患

一　本章导读

一句反问，孟子把”说话”这件事的后半段亮出来：

言人之不善，当如后患何？

说人的不好，那后患怎么办？

此章驳谁：驳”我是直人，我说的是实话”——实话也有重量，话说出去，是要飞的。立什么：立”言有后患”：不是不许说，是不许不计后果地说。 留给后人什么：一张弓，一支已出的箭，一个追不上的”患”。

二　经文

【经】孟子曰：“言人之不善，当如后患何？”

三　字义与句读

言人之不善　“言”是说；“不善”是人的短处。**这五个字里有一个很轻的分寸：说的是”不善”，不是”罪”。

当如……何　“当”是”将”；“如何”是”怎么办”。**合起来是反问：你将拿那后患怎么办？

后患　后来的祸患。**“后”字是时间：不是当下的痛快，是之后的事。

句读一处：“言人之不善，当如后患何？”——“当”字若读为”应当”，则句意变成”说人不好，应当想到后患”，义亦可通；但孟子此句的语气是反问，“当”作”将”读更合文气：你将如何对付那个后患？

四　今译

孟子说：“说别人的不好，那后头的祸患可怎么办？”

五　章旨

言人之恶，须计其后；非禁直言，是禁不计后果之言。

五条支撑：

  1. 这是一个反问，不是一条禁令。 孟子问”怎么办”，不答。
  2. “后患”有两头。 被说的人有患，说的人也有患。
  3. “不善”而非”罪”。 说的是短处，不是刑名——**轻重之间，正见分寸。
  4. 朱熹曰”此亦有为而言”。 这句话是有指的，不是空论。
  5. 话说出口，就收不回。 全章的力，在”后”这个字上。

六　注家

【朱熹曰】“此亦有为而言。”（《孟子集注·离娄下》）

【赵岐注】言人之不善，当念其后患。（按：此为赵注大意，非原文。）

对照：赵岐把”当”读为”当念”，落在”念”字上，是劝；朱熹只留一句”此亦有为而言”，把话头交回给读者：这句话是对着某件事说的，你自己去想是哪件事。 赵存其戒，朱著其失。

七　分寸与边界

  1. 不可读成”不许批评人”。**孟子不封人的口，只问”后患”。
  2. 不可读成”和稀泥”。**不计后果的直言与不敢言的沉默，都不是孟子要的。
  3. 不可把”后患”只想成说者的安危。**被说者的处境，也是”后”的一部分。
  4. 不可用此章作”封口”的凭据。**反问不是禁令；它要人自己算账。
  5. 不可忽略”不善”二字的轻。**说人短处与告人罪状，分量不同。

八　义理

这一章只有一句问话，却比许多长篇更重。

孟子不回答。 这正是他的手法：有些道理，一问就明，一答就死。

先说”后”这个字。 说话最痛快的一刻，是”说出口”的那一刻；而所有后果，都在那一刻之后。 孟子把注意力从”当下”挪到”之后”，这一挪，就把整件事翻过来了。

“患”有两头。 一头在被说的人：他的名声、他的处境、他一家人的日子。 一头在说的人：他的信用、他的处境、他以后还能不能说话。 孟子没有分说，一个”后患”把两头都罩进去了。

“不善”二字也很讲究。 若说”言人之罪”，那是另一件事：罪要告，要审，要明。但”不善”是短处：短处多半不是拿来告的，是拿来容的。 孟子在这里用的，是最轻的一个词；越轻的词，越见分寸。

朱熹一句”此亦有为而言”，最见注家的分寸。 他不说破，只点一句”有指”。因为这句话一旦被当成普遍禁令，就会变成封口的工具；一旦被当成空论，就会变成耳旁风。 朱熹留了一个空，让读者自己填。

这一章其实在教一种”慢”。 话到嘴边，先停一停：这话飞出去，会落在哪里？ 落在人身上，是一个洞；落在自己身上，是一个印。都不是一时能补的。

图里是一张弓，弦已松，箭已出，箭后一道虚线一直向远处去，尽头一个圆圈，圈里一个”患”。 弓还在手里，箭已经追不回来了。

九　时代之问

  • 我上一次说人不好，那句话后来落在哪里？
  • 我说的时候，算过”后”吗？
  • 我是不是把”我这是实话”当成了一张免票？
  • 我不说，是宽容，还是怕？
  • 若我非说不可，我能不能把”不善”说得更准、更轻？

十　跨典

  • 《论语·颜渊》“非礼勿言”——言之节。
  • 《论语·阳货》“道听而涂说，德之弃也”——言之轻。
  • 《孟子·尽心下》“言近而指远者，善言也”——言之善。
  • 《诗经·大雅·抑》“白圭之玷，尚可磨也；斯言之玷，不可为也”——言之不可磨。
  • 《礼记·缁衣》“言必虑其所终”——虑后。
  • 《荀子·非相》“凡言不合先王”——言之准。

十一　存疑

  1. “当”字的读法。 作”将”（反问）或作”应当”（劝戒），两读皆通。
  2. “此亦有为而言”所指。 朱熹未明言，或指当时某位好讦人短者。
  3. “后患”的主体。 指言者之患，或被言者之患，或兼指。
  4. 此章是否与上章”不为”相连。 文不相属，当别为一章。
  5. “不善”是否包括”实有其事者”。 经文未分，注家亦未细辨。
