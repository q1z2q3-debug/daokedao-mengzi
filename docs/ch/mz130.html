第一百三十章　割烹要汤

一　本章导读

万章问：“人有言：‘伊尹以割烹要汤’，有诸？”——有人说伊尹靠一手好厨艺求见汤，有这回事吗？

孟子答：“否，不然。”——不是。

“伊尹耕于有莘之野，而乐尧、舜之道焉。非其义也，非其道也，禄之以天下，弗顾也；系马千驷，弗视也。非其义也，非其道也，一介不以与人，一介不以取诸人。”

——不合义、不合道，拿整个天下来给他，他不看一眼；系一千乘马在门前，他不看一眼。 不合义不合道，一根草不给人，一根草不取于人。

然后是一段极有名的话：

“汤使人以币聘之，嚣嚣然曰：‘我何以汤之聘币为哉？我岂若处畎亩之中，由是以乐尧、舜之道哉？’”

汤三次使人请，他才改变态度，说：“与其……，我岂若使是君为尧、舜之君哉？……”于是他出来。

后面几句是全章的骨：

“天之生此民也，使先知觉后知，使先觉觉后觉也。予，天民之先觉者也；予将以斯道觉斯民也。非予觉之，而谁也？”

“思天下之民匹夫匹妇有不被尧、舜之泽者，若己推而内之沟中——其自任以天下之重也如此。”

所以：“吾未闻枉己而正人者也，况辱己以正天下者乎？”

——我没听说歪了自己去正别人的，何况污辱自己去正天下？

此章驳谁：驳”伊尹以割烹要汤”。立什么：立”非其义则一介不取不与”、“先知觉后知”、“自任以天下之重”。留给后人什么：一鼎，一跪着的人，三束币。

二　经文

【经】万章问曰：“人有言：‘伊尹以割烹要汤’，有诸？”孟子曰：“否，不然。伊尹耕于有莘之野，而乐尧、舜之道焉。非其义也，非其道也，禄之以天下，弗顾也；系马千驷，弗视也。非其义也，非其道也，一介不以与人，一介不以取诸人。汤使人以币聘之，嚣嚣然曰：’我何以汤之聘币为哉？我岂若处畎亩之中，由是以乐尧、舜之道哉？’汤三使往聘之，既而幡然改曰：’与我处畎亩之中，由是以乐尧、舜之道，吾岂若使是君为尧、舜之君哉？吾岂若使是民为尧、舜之民哉？吾岂若于吾身亲见之哉？天之生此民也，使先知觉后知，使先觉觉后觉也。予，天民之先觉者也；予将以斯道觉斯民也。非予觉之，而谁也？’思天下之民匹夫匹妇有不被尧、舜之泽者，若己推而内之沟中，其自任以天下之重如此，故就汤而说之以伐夏救民。吾未闻枉己而正人者也，况辱己以正天下者乎？圣人之行不同也，或远，或近；或去，或不去；归洁其身而已矣。”

三　字义与句读

要　干求，求见。

割烹　割肉、烹调。**指以庖厨之技干进。

有莘　古国名。

千驷　四千匹（一驷四马）。

一介　一个，极言其微。朱熹曰”一介，犹一草芥之芥，言其微也”。

币聘　以币帛聘请。

嚣嚣　朱熹曰”嚣嚣，无欲自得之貌”。

幡然　朱熹曰”幡然，变动之貌”。

觉　使觉悟。

推而内之沟中　“内”同”纳”。把他推进沟里。

自任　自己承担。

枉己　使自己不正。

归洁其身　归结于使自身洁净。

句读一处：“非其义也，非其道也，一介不以与人，一介不以取诸人”——“以”是”拿”；“一介不以与人”，是一个微物也不拿给人。 这小句极重：取与两边的门槛一样高。

四　今译

万章问：“有人说：’伊尹靠割肉烹调求见汤。’有这回事吗？”孟子说：“不，不是。伊尹在有莘之野耕田，以尧舜之道为乐。不合义、不合道，拿整个天下来给他，他不回头看一眼；系一千乘马在他门前，他不看一眼。不合义不合道，一草一芥不给人，一草一芥不取于人。汤派人以币帛聘他，他自得地说：’我要汤的币帛做什么？我何不就在田亩之中，这样以尧舜之道为乐？’汤三次派人去聘，他才改变，说：’我与其在田亩之中以尧舜之道为乐，何不使这个君主成为尧舜那样的君主？何不使这些百姓成为尧舜之民？何不让我亲眼见到？天降生这些百姓，是要让先知觉后知、先觉觉后觉。我就是百姓中先觉的人；我要以这道使百姓觉悟。若不是我使他们觉悟，是谁呢？’想到天下百姓中有匹夫匹妇未受尧舜之泽，就像自己把他们推到沟里——他这样把天下的重担担在自己身上，所以到汤那里，说以伐夏救民。我没听说使自己不正而去正别人的，何况污辱自己去正天下？圣人的行事不同，或远或近，或去或不去，归结于使自身洁净罢了。”

五　章旨

非其义则一介不取不与；先知觉后知；归洁其身。

五条支撑：

  1. “弗顾”“弗视”是两次极硬的不看。 天下与千驷，一概不看。
  2. “一介”是门槛的刻度。 取与两端，同一条线。
  3. “嚣嚣然”是初志。 不是待价，是自足。
  4. “幡然改”是转向的理由。 不是为官，是为”觉斯民”。
  5. “归洁其身”是全章的收。 圣人之行不同，落脚只有一处。

六　注家

【朱熹曰】“伊尹耕于有莘之野，而乐尧、舜之道焉。”（《孟子集注·万章上》）朱熹曰：“有莘，国名。……莘，音申。”

【朱熹曰】“一介，犹一草芥之芥，言其微也。”（同上）

【朱熹曰】“嚣嚣，无欲自得之貌。幡然，变动之貌。”（同上）

【朱熹曰】“使先知觉后知，使先觉觉后觉，是又天之所以生此民之意也。”（同上，意引）

【徐氏曰】“伊尹乐尧、舜之道。尧、舜揖逊，而伊尹说汤以伐夏者，时之不同，义则一也。”（同上，引徐氏说）

【朱熹曰】“归洁其身而已矣。”（同上）朱熹曰：“或远或近，或去或不去，其立心则一。”

【赵岐注】伊尹耕莘，乐尧舜之道，非义不取，汤三聘而后起。（按：此为赵注大意，非原文。）

对照：赵岐顺释本事；朱熹以”一介”标其微，以”嚣嚣”“幡然”标其志之变；徐氏补”时之不同，义则一”解”伐夏”之疑。赵明其事，朱标其节，徐解其变。

七　分寸与边界

  1. 不可把”割烹要汤”当作史实。**孟子明断”否，不然”。
  2. 不可把”幡然改”读成”待价而沽”。**他改的是”觉民”之责，不是价钱。
  3. 不可把”一介不取”读成”清高”。**这是”取”与”与”的双向律。
  4. 不可把”伐夏救民”读成”以下犯上”。**徐氏”时之不同，义则一也”是解。
  5. 不可把”归洁其身”读成”独善”。**洁身是他一切行的底线，不是终点。

八　义理

这一章表面在辩一件事，实在在立一副人的样子。

先看孟子怎么辩。 他不去考证”伊尹是否真会做菜”，他直接画一幅像：耕于有莘之野，乐尧舜之道。 然后两个”弗顾”“弗视”——天下给他，不看；千驷系门，不看。 一个人若真是这样，他连”以割烹要汤”的念头都不会有。这是以人废事。

然后是最细的一句：“一介不以与人，一介不以取诸人。” 这句妙在双向。清廉的人常常只守”不取”，忘了”不与”也是同一把尺。 孟子说：取与两端，都是”一介”。

“嚣嚣然”三个字，写足了初志。 汤来聘，他说：我要你的币做什么？我就在田里乐尧舜之道，不好吗？ 这是自足，不是作态。

“幡然改”改的是什么？ 不是价钱，是责任。他说：天降生这些百姓，是要先觉的人去觉后觉的人。我是先觉者；我不去觉他们，谁去？

接着一句极重： “匹夫匹妇有不被尧舜之泽者，若己推而内之沟中。”——别人没受到好处，就像自己把他推进沟里。 这就是”自任以天下之重”。

最后落到辨诬： “吾未闻枉己而正人者也，况辱己以正天下者乎？”歪了自己去正人，不可能；辱了自己去正天下，更不可能。 所以”割烹要汤”这种事，从道理上就不成立。

“圣人之行不同也，或远或近，或去或不去；归洁其身而已矣。” 这一句把门开得很宽：圣人的做法可以不同——远、近、去、留，都可以。但落脚只有一处：洁其身。

九　时代之问

  • 我有没有为了”见一个人”，先弯一下自己？
  • 我守”不取”，守不守”不与”？
  • 我给自己的位置，是”待价”，还是”待事”？
  • 别人的苦，我觉不觉得像自己推他下沟？
  • 我的做法可以变，我的”洁”变了没有？

十　跨典

  • 《尚书·说命》“若作和羹，尔惟盐梅”——割烹之喻。
  • 《论语·述而》“不义而富且贵，于我如浮云”——不取。
  • 《孟子·尽心上》“穷则独善其身”——洁身。
  • 《墨子·尚贤》“伊尹，有莘氏之媵臣”——异说。
  • 《史记·殷本纪》“伊尹名阿衡”——史证。
  • 《荀子·非相》“伊尹之状”——形貌之说。

十一　存疑

  1. “割烹要汤”的来源。 战国游士之说，孟子所驳。
  2. 伊尹是否”媵臣”。 《墨子》《吕氏春秋》有异说。
  3. “有莘”地望。 旧说在今河南开封一带，一说在山东曹县。
  4. “三使往聘”之数。 诸书或作”三反”。
  5. “伐夏救民”的评价。 徐氏”时之不同”为一解，后世另有争论。
