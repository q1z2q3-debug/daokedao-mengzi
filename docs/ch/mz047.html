第四十七章　道性善

一　本章导读

滕国的太子要去楚国，路过宋国，见了孟子一面。

孟子跟他讲了一句话：性善。 举例子，一律举尧舜。

太子从楚国回来，又见孟子。这一次他带着疑问来的——朱熹说得很清楚：“世子于孟子之言不能无疑，而复来求见，盖恐别有卑近易行之说也。”他怕孟子讲的是空话，想找一个便宜点的说法。

孟子没有给新说法。他只说了三句别人的话：

成覸谓齐景公曰：“彼丈夫也，我丈夫也，吾何畏彼哉？”

颜渊曰：“舜何人也？予何人也？有为者亦若是。”

公明仪曰：“文王我师也，周公岂欺我哉？”

然后把滕国摆上来量了一量：今滕，绝长补短，将五十里也，犹可以为善国。

最后是一味药：若药不瞑眩，厥疾不瘳。 药要是不把人搅得头昏眼花，病就治不好。

此章驳谁：驳”圣贤是天生的另一类人，我这样的人、我这样的国，学不来、做不成”。立什么：立”道一而已”——圣与凡只有一条道，不是两条；滕虽五十里，也可以为善国。留给后人什么：一句极硬的话：药不瞑眩，疾不瘳。 想不痛不痒地把病养好，是没有的。

二　经文

【经】滕文公为世子，将之楚，过宋而见孟子。孟子道性善，言必称尧舜。

【经】世子自楚反，复见孟子。孟子曰：“世子疑吾言乎？夫道一而已矣。成覸谓齐景公曰：‘彼丈夫也，我丈夫也，吾何畏彼哉？’颜渊曰：’舜何人也？予何人也？有为者亦若是。’公明仪曰：’文王我师也，周公岂欺我哉？’今滕，绝长补短，将五十里也，犹可以为善国。书曰：’若药不瞑眩，厥疾不瘳。’”

三　字义与句读

世子　朱熹：“世子，太子也。”

道性善　朱熹：“道，言也。性者，人所禀于天以生之理也，浑然至善，未尝有恶。人与尧舜初无少异，但众人汨于私欲而失之，尧舜则无私欲之蔽，而能充其性尔。”——“道”是言说，不是创制。孟子在讲一件已经存在的事。

言必称尧舜　朱熹：“欲其知仁义不假外求，圣人可学而至，而不懈于用力也。”——称尧舜不是抬出两个偶像，是给出两个可以到达的实证。

道一而已矣　朱熹：“以明古今圣愚本同一性，前言已尽，无复有他说也。”——“一”字是全章的锁。 世子来找第二种说法，孟子说没有第二种。

成覸　朱熹：“成覸，人姓名。”齐景公时人。

彼丈夫也，我丈夫也　朱熹：“彼，谓圣贤也。”——“丈夫”是成年男子的通称，不是道德称号。 他也是个人，我也是个人。

有为者亦若是　朱熹：“言人能有为，则皆如舜也。”——“若是”指像舜那样，前提是”有为”。

公明仪　朱熹：“公明，姓；仪，名；鲁贤人也。文王我师也，盖周公之言。”公明仪诵周公的话，说周公没有骗我。

绝长补短　朱熹：“绝，犹截也。”——把长的截下来补到短处。 这是量地之法，也是立国之法。

将五十里　朱熹：“言滕国虽小，犹足为治。”

瞑眩　朱熹：“瞑眩，愦乱。”——吃药后头晕目乱，是药在起作用的样子。

厥疾不瘳　朱熹：“瘳，愈也。”引自《尚书·说命》。

句读一处：“夫道一而已矣”——“夫”是发语词，一句一顿。不是”道，一而已矣”的断言句式，是”道，就一条，完了”的收束语。

四　今译

滕文公做太子的时候，要到楚国去，路过宋国，见了孟子。孟子讲性善，讲什么都要举尧舜为例。

太子从楚国回来，又见孟子。孟子说：“太子是怀疑我的话吗？道只有一条，罢了。成覸对齐景公说：‘他是丈夫，我也是丈夫，我怕他什么？’颜渊说：’舜是什么人？我是什么人？有作为的人也就这样。’公明仪说：’文王是我的老师，周公难道骗过我吗？’如今滕国，截长补短，方圆将近五十里，仍然可以成为一个好国。《书》上说：’药若不把人搅得头昏眼花，那病就不会好。’”

五　章旨

圣与凡是一条道，不是两条；小国也能为善国，但得吃猛药。

五条支撑：

  1. “道性善”是把起点统一。 朱熹说”浑然至善，未尝有恶”，又说众人只是”汨于私欲而失之”——失掉不等于没有。 这是本章全部推论的地基。
  2. “言必称尧舜”是把终点也统一。 起点相同还不够，得有一个走通过的人作证。尧舜不是神，是”能充其性”的人。
  3. 三句引语各攻一处疑。 成覸攻”他比我高”（彼丈夫我丈夫）；颜渊攻”舜不可及”（有为者亦若是）；公明仪攻”这是空话”（周公岂欺我哉）。三句合起来，正好拆掉世子复见时的那个疑。
  4. “绝长补短，将五十里”把问题从人转到国。 国小是事实，孟子不改这个事实，只改它的用法：小可以治，不能大而治者，小而治之亦足。
  5. “药不瞑眩”是全章的代价条款。 前面许诺”可以为善国”，这一句说出价钱：改，是要痛的。 朱熹说”但恐安于卑近，不能自克，则不足以去恶而为善也”。

六　注家

【朱熹曰】“性者，人所禀于天以生之理也，浑然至善，未尝有恶。人与尧舜初无少异，但众人汨于私欲而失之，尧舜则无私欲之蔽，而能充其性尔。”（《孟子集注·滕文公上》）

【朱熹曰】“时人不知性之本善，而以圣贤为不可企及；故世子于孟子之言不能无疑，而复来求见，盖恐别有卑近易行之说也。”（同上）

【朱熹曰】“瞑眩，愦乱。言滕国虽小，犹足为治，但恐安于卑近，不能自克，则不足以去恶而为善也。”（同上）

【朱熹引程子曰】“性即理也。天下之理，原其所自，未有不善。”（同上）

对照：赵岐注此章，于”世子”“成覸”“公明仪”诸名物一一指实，是训诂家的本分；朱熹则在名物之上补一句”性者，人所禀于天以生之理”，把”性善”从一句论断提成一个结构。赵立其名，朱立其理——读此章，两名物可略，一理不可略。

七　分寸与边界

  1. 不可把”性善”读成”人不会做坏事”。朱熹明说”汨于私欲而失之”，失是常态。
  2. 不可把”言必称尧舜”读成偶像崇拜。尧舜在此是证据，不是权威。
  3. 不可把”道一而已”读成”只有一种做法”。孟子说的是一条道，不是一套办法；下文”润泽之则在君与子”，做法是活的。
  4. 不可把”五十里可以为善国”读成”小国必然能成”。原文是”犹可以”，可以是许可，不是保证。
  5. 不可跳过”瞑眩”只取”可以为善国”。许诺在前，代价在后，两句是一副药。

八　义理

这一章给的是一件极难的事：怎么让人相信自己够得着。

世子的问题不是不知道性善，是不信。朱熹点得准：“恐别有卑近易行之说”——他想找一个便宜版本。凡是想找便宜版本的人，都是先在心里把自己判低了。

孟子的处理办法很硬：不给便宜版本，只给三个证人。三个证人有一个共同的句式——“他也是一样的人”。

  • 成覸对齐景公说：他是丈夫，我也是丈夫。
  • 颜渊说：舜是什么人，我是什么人。
  • 公明仪说：文王是我老师，周公没骗我。

三个证人来自三个方向：一个是劝国君的臣子，一个是孔门高弟，一个是鲁国贤人。证人齐了，剩下的不是道理问题，是肯不肯用力的问题。

然后孟子把滕国放到天平上：绝长补短，五十里。他没有说”滕虽小，其道甚大”这种空话，他先算了一遍地。 算完才说”犹可以为善国”。这是孟子的习惯：先量尺寸，再下判断。

最后一味药，是全章最狠的地方。“药不瞑眩，厥疾不瘳”——出自《尚书·说命》，本是商王武丁对傅说说的：你的话要像药一样，把我搅得难受，我的病才好。孟子拿它来说滕国：你要治，就得先乱一阵。

这里有一个今天仍然刺人的判断：改革的第一道门槛不是方案，是难受。 凡承诺”无痛”的方案，多半是把病留在原处。凡一听要痛就退回去的人，不是不信性善，是不信自己要付这个价。

九　时代之问

  • 我信”我也够得着”吗？还是暗地里给自己判了一个”我就这样了”？
  • 我在等一个便宜的说法吗？ 那个说法通常不解决病，只解决不安。
  • 我手里的事，量过尺寸吗？ 还是先讲大话，再回头看地有多大。
  • 我愿意为”变好”付一段难受吗？
  • 我的”不能”，是已知的边界，还是没试过的托辞？

十　跨典

  • 《论语·颜渊》：“舜何人哉？予何人哉？”——颜渊语，与此章同。
  • 《孟子·告子上》：“人性之善也，犹水之就下也。”——性善的详说在此。
  • 《孟子·尽心上》：“人之有德慧术知者，恒存乎疢疾。”——病与药，同一逻辑。
  • 《尚书·说命》：“若药弗瞑眩，厥疾弗瘳。”——孟子所引。
  • 《荀子·劝学》：“青，取之于蓝，而青于蓝。”——同一种”可以胜出”的信心，路径不同。
  • 《老子》第六十三章：“天下难事，必作于易。”——可与此章”瞑眩”对看：一者言难事须自易始，一者言治病须先受痛，两说各执一端，合起来才是全.

十一　存疑

  1. 滕文公之世次。 朱熹以定公为文公父；《史记》世系与注家所记略有出入。
  2. “成覸”字形。 一本作”成瞷”，音同；朱熹注”古苋反”，当为一人。
  3. “公明仪”所诵是否周公原语。 朱熹云”盖周公之言”，是推测之辞，非定论。
  4. “绝长补短，将五十里”是实数还是约数。 朱熹云”将，近也”，注家多以为约计。
  5. 瞑眩之喻的指向。 一说指滕国之政，一说指世子之身；朱熹合两者而言，未分。

图位　图一｜绝长补短

读图三处：

  1. 左边一条窄长帛——这是滕国的原样：长而窄，看着不成形。
  2. 中间截成三段——“绝”是截，不是添。手里没有多的，只能把已有的重新摆。
  3. 右边拼成的方——拼出来的方比原来窄条”像样”，但面积一点没多。孟子许诺的不是变大，是成形。

图说一句：不能长，就把长的截下来补短的。
