第七十七章　不侮不夺

一　本章导读

这一章只有三句，是《孟子》里最像”下定义”的一章：

恭者不侮人，俭者不夺人。

——恭敬的人不轻慢人，俭省的人不夺人的东西。

然后翻过来一刀：侮夺人之君，惟恐不顺焉，恶得为恭俭？

——又轻慢人、又夺取人的君主，只怕别人不顺从他，这怎么能叫恭俭？

收一句斩断：恭俭岂可以声音笑貌为哉？

——恭俭难道可以用声音和笑脸做出来吗？

此章驳谁：驳”恭敬是一副姿态”“俭省是一种做派”。立什么：立两条否定式的定义——恭的实义是”不侮”，俭的实义是”不夺”；并立”声音笑貌”的界限。留给后人什么：一双垂下的手，和一张被推回去的礼。

二　经文

【经】孟子曰：“恭者不侮人，俭者不夺人。侮夺人之君，惟恐不顺焉，恶得为恭俭？恭俭岂可以声音笑貌为哉？”

三　字义与句读

恭　朱熹注”恶，平声”（“恶得”之”恶”），未专训”恭”字。依全章看，“恭”的实义由”不侮人”给出——孟子用的是”以行定义”，不以字训定义。

俭　旧注以”俭”为”约”（俭约）。但孟子在这里把”俭”拉到”不夺人”上：不是少花钱，是少取人。

侮　轻慢、欺凌。朱熹：“侮夺人之君，惟恐不顺焉”——“不顺”是对下的要求，“侮夺”是对下的动作。

夺　夺取。“夺人”的对象不只是财物，也包括名分、机会、时间。

惟恐不顺　朱熹：“言恐人之不顺己。”——这一句是全章的转轴：怕人不顺，就必然侮与夺。

声音笑貌　朱熹：“伪为于外也。”——四个字，把”表演”这件事说尽了。

句读一处：“侮夺人之君，惟恐不顺焉，恶得为恭俭？”——“侮夺人之君”是一个整体：既侮又夺的那种君主。 若读成”侮、夺人之君”（两个动词各带宾语），句意就散；孟子的刀，砍的正是”既侮又夺”这一种人。

四　今译

孟子说：“恭敬的人不轻慢别人，俭省的人不夺取别人的东西。那种又轻慢人、又夺取人的君主，只担心别人不顺从自己，这怎么能算恭俭？恭俭难道可以用声音和笑脸做出来吗？”

五　章旨

恭与俭不靠姿态证明，靠”不做什么”证明；而一个怕人不顺从的人，做不出这两件事。

五条支撑：

  1. 定义用的是否定式。 “不侮”“不夺”——孟子不说”恭是敬人”，他说”恭是不侮人”。 否定式的好处，是可核：侮没侮，看得见；敬不敬，说不清。
  2. “俭”被从”省钱”拉到”不夺人”。 一个人可以极省而极贪：对自己抠，对别人夺。 孟子把”俭”的检验放到别人身上，节俭立刻有了伦理重量。
  3. “惟恐不顺”是心理机制。 怕人不顺，就要压；压不住，就要夺。侮与夺，是”怕”的两个出口。
  4. “恶得为恭俭”是逻辑，不是骂。 你既侮又夺，就与”不侮不夺”直接冲突；这不是评价你不好，是你的行为把定义推翻了。
  5. “声音笑貌”划出表演的边界。 朱熹一句”伪为于外也”——外在可以做，内里做不出。 这一句把全章从”修养”拉到”检验”。

六　注家

【朱熹曰】“惟恐不顺，言恐人之不顺己。声音笑貌，伪为于外也。”（《孟子集注·离娄上》）

【朱熹曰】此章”恭俭”二字，须以”不侮”“不夺”为实义——朱注虽未逐字训诂，全章之解即建于这两句上。（按：此为朱注行文之意，非原文）

对照：赵岐注此章，以”俭”为”约”，就字面立说，重在自约；朱熹则把”俭”落到”不夺人”，又用”伪为于外”四字点破姿态。赵守其约，朱充其义。

七　分寸与边界

  1. 不可把”恭”读成唯唯诺诺。恭的反面是”侮”，不是”有主张”；一个人可以有主张而不侮人。
  2. 不可把”俭”读成抠门。抠门是对自己；俭的检验在”有没有夺人”。
  3. 不可用姿态判人恭俭。“声音笑貌”正是孟子要剥掉的那一层。
  4. 不可把”不夺”读成”什么都不取”。该取的取，取之有道；此章反对的是”夺”，不是”取”。
  5. 不可把此章只用于评价君主。“侮夺人之君”是例子，不是范围；凡怕人不顺的人，都在这一句里。

八　义理

这一章短，却给了两个”可核的定义”，和一个”不可核的姿态”。

先说定义为什么用否定式。 说”恭是敬人”，谁都能点头；说”恭是不侮人”，就要查账了：你昨天有没有当众让人下不来台？ 孟子一贯如此：他把德目从”应该怎样”改写成”不做什么”，因为后者有证据。 这一手，比一百句劝善都硬。

“俭者不夺人”这一句，是全章最容易被低估的。 世人说俭，说的是”我少花”；孟子说俭，说的是”我少取”。两者之间隔着一个人：你少花的，是谁的？ 若少花的是自己的，那叫省；若少花的是别人的，那叫夺。孟子一句话，把”俭”从账本拉到人身上。

“惟恐不顺焉”这五个字，是一台心理机器。 一个怕人不顺从的人，会先侮——用轻慢压出顺从；压不出，就夺——把你赖以立身的东西拿走，你就只能顺。侮是软的夺，夺是硬的侮。 孟子把它们并成一句”侮夺人之君”，看得很准：这两件事从来是一起长的。

最后一句”岂可以声音笑貌为哉”，是把整章翻过来的那一刀。 声音可以练，笑貌可以练；不侮不夺，练不出来，只能不做。 这一章的结论因此不是”要恭俭”，而是：恭俭是一件”减去”的事——减到不侮、不夺，剩下的才是。

九　时代之问

  • 我上一次让人下不来台，是什么时候？
  • 我的”省”，省的是自己的，还是别人的？
  • 我怕别人不顺从我吗？怕到什么程度？
  • 我练熟的那副笑貌，遮住了哪一件事？
  • 我这一格，减到”不侮不夺”，还剩什么？

十　跨典

  • 《论语·学而》：“恭近于礼，远耻辱也。”——恭要有礼作界。
  • 《论语·八佾》：“礼，与其奢也，宁俭。”——俭在礼中的位置。
  • 《左传·庄公二十四年》：“俭，德之共也；侈，恶之大也。”——“俭”的古义。
  • 《老子》第六十七章：“我有三宝……三曰不敢为天下先。”——“不夺”的另一路表达。
  • 《礼记·大学》：“生财有大道……仁者以财发身，不仁者以身发财。”——“夺”与”取”的分界。
  • 《孟子·告子下》“今之所谓良臣，古之所谓民贼也”——“夺人”的政治形态。

十一　存疑

  1. “俭”的训释。 旧注多训”约”，孟子此处以”不夺人”为说，二者可并存而侧重不同。
  2. “侮夺人之君”是否专指君主。 文面指君，然理可通于一切在上位者。
  3. “声音笑貌”的范围。 一说专指表情，一说兼指言语；朱熹以”伪为于外”统之。
  4. 此章与《公孙丑上》“恭俭”之说的关系。 彼处言”恭俭可以让国”，此处言其实义，可互参。
  5. “恶得为恭俭”是反问还是判断。 文气为反问，理则是判断。

十二　双卡与图

图位　图一｜垂手与推礼

读图三处：

  1. 两只垂下的手——不抬起，就不打人。恭的画法，是把手放低。
  2. 两人之间那段空——不是疏远，是不侵。“不侮”的距离，是一段看得见的空。
  3. 那只把礼推回去的手——推，是”不夺”；但绳还在对方手里。不夺不等于不要，是不要别人手里的。

图说一句：德目的证据，在”没做什么”里。
