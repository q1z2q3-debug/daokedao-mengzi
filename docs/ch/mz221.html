第二百二十一章　进锐退速

一　本章导读

“于不可已而已者，无所不已。”

——在该做的地方停手的人，没有一处不会停手。

“于所厚者薄，无所不薄也。”

——在该厚的地方薄待的人，没有一处不会薄待。

“其进锐者其退速。”

——进得猛的人，退得也快。

三句，三弊。这一章是全篇最短的之一：四十二字，说了三件事，还给了同一个结论。

朱熹说： “进锐者，用心太过，其气易衰，故退速。三者之弊，理势必然，虽过不及之不同，然卒同归于废弛。”

此章驳谁：驳”用力就是好”——以为猛就是勤。立什么：立”过与不及同归废弛”。留给后人什么：一条断口的路、一座尖峰、一厚一薄两块板。

二　经文

【经】孟子曰：“于不可已而已者，无所不已；于所厚者薄，无所不薄也。其进锐者其退速。”

三　字义与句读

已　朱熹曰”已，止也”。

不可已　朱熹曰”不可止，谓所不得不为者也”。不能停的事。

所厚　朱熹曰”所当厚者也”。该厚待的人与事。

进锐　猛进。锐，疾。

退速　退得快。

句读一处：“于不可已而已者，无所不已”——上一句是”在不可停处停”，下一句”无所不已”是”没有一个地方不停”。合为”在最不能停的地方都敢停，别处就更不用说了”。 若把”无所不已”读成”没有不停的时候”（即”总在停”），语势就散了；它是推演，不是描写。

四　今译

孟子说：“在该做的地方停手的人，没有一处不会停手；在该厚的地方薄待的人，没有一处不会薄待；进得猛的人，退得也快。”

五　章旨

三弊异形而同归：一处放手，处处放手；用力太过，其气必衰。

五条支撑：

  1. 两句”无所不”是推演，不是夸张。
  2. “不可已”与”所厚”两处，都是”不能省”的地方。
  3. 第三句换了维度：前两句说”该不该”，第三句说”久不久”。
  4. “进锐”不是错，错在”锐”之后没有”恒”。
  5. 朱熹”同归于废弛”五字，是三句的合题。

六　注家

【朱熹曰】“已，止也。不可止，谓所不得不为者也。所厚，所当厚者也。此言不及者之弊。”（《孟子集注·尽心上》）

【朱熹曰】“进锐者，用心太过，其气易衰，故退速。”（同上）

【朱熹曰】“三者之弊，理势必然，虽过不及之不同，然卒同归于废弛。”（同上，总释）

【赵岐注】不可止而止，则余事皆止；所当厚而薄，则余皆薄；进太疾者退必速。（按：此为赵注大意，非原文。）

对照：赵岐三句平列，朱熹点出”不及者之弊”与”过”的对举，末以”废弛”合之。赵列其三，朱剖其两，末以一语收之。

七　分寸与边界

  1. 不可把”无所不已”读成”总在停”。** 它是推演：最不能停处都停，别处更不必说。
  2. 不可把”所厚者薄”读成”薄待人”。** “厚”兼指事与亲。
  3. 不可把”进锐”读成”勤奋”。** 锐指疾，不指勤。
  4. 不可把”退速”读成”变心”。** 朱熹说”其气易衰”，是气不是志。
  5. 不可把本章读成”反对进取”。** 它反的是”无恒”，不是”进”。

八　义理

这一章四十二个字，三个断语。

第一个断语： “于不可已而已者，无所不已。”

“不可已”是什么？朱熹说”所不得不为者也”。 就是那些停不得的事。

一个人在最停不得的地方停了手，那别的地方就更不用指望。 这不是逻辑推理，是经验判断——一个人的”停手”，是从最要紧的地方开始的。

第二个断语： “于所厚者薄，无所不薄也。”

“所厚”，朱熹说”所当厚者也”。 该厚待的，是亲人、是恩人、是本职。

在该厚的地方薄了，别处一定更薄。 因为”厚”是有次序的，最先该厚的那一处都省了，后面的次序就散了。

第三个断语换了方向。

“其进锐者其退速。”

前两句说的是”不及”——该做不做。 这一句说的是”过”——做过了头。

“锐”是疾，是猛。 一个人猛冲，看着比谁都用力。朱熹说： “用心太过，其气易衰。”

——“其气易衰”四个字，是生理，也是常理。 人的气是有数的，一次用完，后面就空。

这一句最容易被误读成”不要努力”。 不是。它说的是”锐”没有配套的”恒”。

朱熹最后一句把三样合起来了： “虽过不及之不同，然卒同归于废弛。”

——“过”与”不及”，方向相反，落点相同。 一个是从没开始，一个是从半途垮掉。末了都是”废弛”。

这是本章最斩截的地方：它不给你”中庸”的安慰，它给你”同归”的判断。

图上左边一段路，中间断开。 两条边线，断口两侧各一道竖线——路在这里断了。

“止”字落在断口的正中。

中间一座尖峰：从左下陡起，到顶，再陡落。 峰顶一个赭点，注”锐”。

右边两块板：上一块厚，下一块薄。 左侧各注”厚”“薄”。

上方一句”三者之弊，同归于废弛”。

——断口、尖峰、薄板，三样形状不同，都停在同一层地面上。

九　时代之问

  • 我在哪一处”不可已”的地方停过手？
  • 我把哪一处”所厚”薄了？
  • 我”进锐”过吗？后来呢？
  • 我的”气”是一次用完，还是分着用？
  • 我分得清”猛”与”久”吗？

十　跨典

  • 《论语·子路》“欲速则不达”——进锐之戒。
  • 《论语·雍也》“力不足者，中道而废”——不及之弊。
  • 《孟子·公孙丑上》“其进锐者其退速”——同语另见。
  • 《孟子·告子上》“一日暴之，十日寒之”——气衰之象。
  • 《荀子·劝学》“锲而不舍”——恒之反面。
  • 《礼记·学记》“学不躐等”——进锐之戒。

十一　存疑

  1. 本章是否与《公孙丑上》重出。 彼章有”其进锐者其退速”一句，文同。
  2. “已”之训。 朱熹曰”止也”。
  3. “所厚”所指。 一说亲，一说事。
  4. 三句是否同章。 朱熹合为一章。
  5. “废弛”是否朱熹自造。 是朱语，非经文本字。
