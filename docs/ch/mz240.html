第二百四十章　迟迟吾行

一　本章导读

“孔子之去鲁，曰：’迟迟吾行也。’去父母国之道也。”

——孔子离开鲁国时说：’慢慢走吧。’这是离开父母之国的走法。

“去齐，接淅而行，去他国之道也。”

——离开齐国，把淘好的米捞起来就走；这是离开别国的走法。

三十个字，两种走法。 一个慢，一个快；快慢之间，是”父母国”三个字。

朱熹说： “重出。”

（此章与《万章下》“孔子去齐”章文字相重。旧说相承如此，本书仍依朱熹本编次，不删。）

此章驳谁：驳”去国一律”——以一种去法应万国。立什么：立”去有差等，亲疏定其迟速”。留给后人什么：一条横路，左人回首、足迹密；右人疾行、手持淅箩滴三滴水、足迹稀。

二　经文

【经】孟子曰：“孔子之去鲁，曰：’迟迟吾行也。’去父母国之道也。去齐，接淅而行，去他国之道也。”

三　字义与句读

去　离开。

迟迟　缓慢。朱熹曰”迟迟，缓慢之意”（语义）。

父母国　本国。

接淅　捞起已淘的米。朱熹曰”接，犹承也；淅，渍米也。渍米将炊，而欲去之速，故以手承水取米而行，不及炊也。”

句读一处：“迟迟吾行也” 是孔子原话，须加引号读。“去父母国之道也” 是孟子的判。引与判要分开。 若连读成”迟迟吾行是去父母国之道”，句意不差，但孔子那一句的声口就没了——“迟迟吾行也”五个字里有一个人的留恋。

四　今译

孟子说：“孔子离开鲁国时说：’慢慢走吧。’这是离开父母之国的走法。离开齐国，把淘好的米捞起来就走——这是离开别国的走法。”

五　章旨

“父母国”三个字，是这一章的秤砣。

五条支撑：

  1. 两种走法，一个标准：亲疏。
  2. “迟迟”是心慢，不是脚慢。
  3. “接淅”是手快，米都不等炊。
  4. 鲁是父母国，齐是异国。
  5. 本章与《万章下》重出，而编次仍存。

六　注家

【朱熹曰】“重出。”（《孟子集注·尽心下》）

【朱熹曰】“接，犹承也；淅，渍米也。渍米将炊，而欲去之速，故以手承水取米而行，不及炊也。”（《孟子集注·万章下》，同文）

【赵岐注】去父母之国，迟迟而行；去他国，则接淅而去。（按：此为赵注大意，非原文。）

对照：赵岐平解，朱熹标”重出”并详释”接淅”之状。赵注其义，朱记其重。

七　分寸与边界

  1. 不可把”迟迟”读成”拖延”.** 是留恋。
  2. 不可把”接淅”读成”带米上路”.** 是捞起就走，不及炊。
  3. 不可把本章读成”轻齐重鲁”.** 是”父母国”与非父母国之分。
  4. 不可因”重出”而删此章。** 朱熹本存之，本书亦存。
  5. 不可把”道”读成”办法”.** 是”合于情理的走法”。

八　义理

这一章只有三十个字，却把”走”分成了两种。

“孔子之去鲁，曰：‘迟迟吾行也。’”

五个字，是一个人的脚步。

“迟迟”不是走不动，是不肯走快。 朱熹解作”缓慢”，但这缓慢里有分量。

“去父母国之道也。”

孟子给了一个理由：鲁是父母国。

父母国三个字，不是地理，是关系。 生于此，长于此，祖先的坟在这里。

“去齐，接淅而行。”

“接淅”两个字极具体。

朱熹解： “渍米将炊，而欲去之速，故以手承水取米而行，不及炊也。”

——米已经泡上了，本来要下锅。听说要走，用手把水里的米一捞，提着就走，连饭都不做了。

这个动作里没有一点怨，只有”快”.

“去他国之道也。”

齐不是父母国，所以走得干脆。

两句话，快慢都由”亲疏”定。

这一章的分量在”不一律”上。 后世常把”去国”说成一种姿态：要么恋恋，要么决绝。孟子说不。同一个人，去两个国家，两种走法，都对。

图上一条横路自左贯右。

左段一人回首，身后足迹密而短。

右段一人疾行，手中一只竹箩（淅），箩下三滴水。

身后足迹稀而长。

上方两行：“去父母国，迟迟吾行”“去他国，接淅而行”。

——同一双脚，两种走法；差别只在脚下这片土是不是父母之土。

九　时代之问

  • 我离开一个地方，是”迟迟”，还是”接淅”？
  • 我的快慢，由什么定？
  • 我把”父母国”当成地理，还是关系？
  • 我有没有把一种走法当成唯一正解？
  • 我走得快的时候，手里还提着什么？

十　跨典

  • 《孟子·万章下》“孔子去齐”——同文重出。
  • 《孟子·万章下》“去鲁，曰迟迟吾行也”——另一处。
  • 《论语·述而》“齐，必变食”——去国之敬。
  • 《论语·乡党》“去公门”——行之节。
  • 《礼记·曲礼上》“去国三世”——去国之礼。
  • 《荀子·大略》“去国”之节——同期之说。

十一　存疑

  1. 本章是否确为重出。 朱熹曰”重出”，与《万章下》文字相合。
  2. “接淅”之解是否确。 朱熹曰”以手承水取米而行”。
  3. “淅”是否为”淘米”. 朱熹曰”渍米也”.
  4. 孔子去鲁之年。 史有定说，本章不载。
  5. 重出之章是否当删。 朱熹存之，本书从之。（按：旧说相承如此，非本书自定。）
