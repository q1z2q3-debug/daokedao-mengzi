第一百三十九章　义路礼门

一　本章导读

万章问：“敢问不见诸侯，何义也？”——不去见诸侯，是什么道理？

孟子说：“在国曰市井之臣，在野曰草莽之臣，皆谓庶人。庶人不传质为臣，不敢见于诸侯，礼也。”

——在城里的叫市井之臣，在乡野的叫草莽之臣，都是庶人。庶人没有传递贽见之礼而成为臣，就不敢去见诸侯，这是礼。

万章问得很利：“庶人，召之役，则往役；君欲见之，召之，则不往见之，何也？”

——叫他去服役，他去；君主想见他，召他，他不去。为什么？

孟子答：“往役，义也；往见，不义也。往役者，庶人之职；不往见者，士之礼。”

然后是全章的核心：“且君之欲见之也，何为也哉？”——君主要见他，是为了什么？

万章说：“为其多闻也，为其贤也。”

孟子说：“为其多闻也，则天子不召师，而况诸侯乎？为其贤也，则吾未闻欲见贤而召之也。”

接着引子思：缪公屡次见子思，说”古时千乘之国与士为友，怎么样？“子思不高兴，说：“古之人有言：曰事之云乎，岂曰友之云乎？”——古人的话是”事奉他”，哪里说”与他为友”？

孟子替子思把这句解释出来：

“以位，则子，君也；我，臣也。何敢与君友也？以德，则子事我者也。奚可以与我友？”

“千乘之君求与之友，而不可得也，而况可召与？”

再引齐景公招虞人的事：“招虞人以旌，不至，将杀之。志士不忘在沟壑，勇士不忘丧其元。孔子奚取焉？取非其招不往也。”

然后是那句最要紧的：

“夫义，路也；礼，门也。惟君子能由是路，出入是门也。”

此章驳谁：驳”召即当往”、驳”见贤即可召”。立什么：立”非其招不往”；立”义，路也；礼，门也”。留给后人什么：一条路，一道门。

二　经文

【经】万章曰：“敢问不见诸侯，何义也？”孟子曰：“在国曰市井之臣，在野曰草莽之臣，皆谓庶人。庶人不传质为臣，不敢见于诸侯，礼也。”万章曰：“庶人，召之役，则往役；君欲见之，召之，则不往见之，何也？”曰：“往役，义也；往见，不义也。往役者，庶人之职；不往见者，士之礼。且君之欲见之也，何为也哉？”曰：“为其多闻也，为其贤也。”曰：“为其多闻也，则天子不召师，而况诸侯乎？为其贤也，则吾未闻欲见贤而召之也。缪公亟见于子思，曰：‘古千乘之国以友士，何如？’子思不悦，曰：’古之人有言：曰事之云乎，岂曰友之云乎？’子思之不悦也，岂不曰：’以位，则子，君也；我，臣也。何敢与君友也？以德，则子事我者也。奚可以与我友？’千乘之君求与之友，而不可得也，而况可召与？齐景公田，招虞人以旌，不至，将杀之。志士不忘在沟壑，勇士不忘丧其元。孔子奚取焉？取非其招不往也。“曰：”敢问招虞人何以？“曰：”以皮冠。庶人以旃，士以旗，大夫以旌。以大夫之招招虞人，虞人死不敢往；以士之招招庶人，庶人岂敢往哉？况乎以不贤人之招招贤人乎？欲见而召之，是不贤人之招也。以士之招招庶人，则不敢往；以不贤人之招招贤人，则不可往矣。欲见贤人而不以其道，犹欲其入而闭之门也。夫义，路也；礼，门也。惟君子能由是路，出入是门也。《诗》云：’周道如底，其直如矢；君子所履，小人所视。’”万章曰：“孔子，君命召，不俟驾而行。然则孔子非与？”曰：“孔子当仕有官职，而以其官召之也。”

三　字义与句读

质　同”贽”，见面礼。士执雉，庶人执鹜。

传质为臣　通贽而成为臣。

市井之臣／草莽之臣　居城者／居野者。

旌／旗／旃　招大夫用旌，招士用旗，招庶人用旃。

皮冠　田猎之冠，虞人所有事，故以之招虞人。

元　首。

如底　底同”砥”，砺石，言其平。

俟驾　等车驾好。

句读一处：“以位，则子，君也；我，臣也”——“以位”与”以德”两句对举。 按位，你是君我是臣；按德，你该事奉我。两句一摆，召与不召的道理就全出来了。

四　今译

万章说：“请问不见诸侯，是什么义？”孟子说：“在城里叫市井之臣，在乡野叫草莽之臣，都是庶人。庶人没有通贽为臣，就不敢去见诸侯，这是礼。”万章说：“庶人，叫去服役就去；君主想见他，召他，却不去，为什么？”孟子说：“去服役，是义；去见，是不义。服役是庶人的职，不见是士的礼。况且君主要见他，是为了什么？”万章说：“为他多闻，为他贤。”孟子说：“若为他多闻，那天子尚且不召师，何况诸侯？若为他贤，我没听说想见贤人而召他来的。缪公屡见子思，说’古时千乘之国与士为友，怎么样？‘子思不高兴，说’古人的话是事奉他，哪里说与他为友？’子思的不悦，岂不是说：’按位，你是君，我是臣，怎敢与君为友？按德，你该事奉我，怎么可以与我为友？’千乘之君求与他为友尚且不得，何况召他？齐景公田猎，用旌招虞人，虞人不来，要杀他。志士不忘弃尸沟壑，勇士不忘丧失头颅——孔子取他哪一点？取他’非其招不往’。”万章说：“请问招虞人用什么？”孟子说：“用皮冠。庶人用旃，士用旗，大夫用旌。用大夫之招招虞人，虞人死也不敢去；用士之招招庶人，庶人岂敢去？何况用不贤之人的招去招贤人？想见他而召他，就是不贤之人的招。想见贤人而不以其道，就像想他进来却把门关上。义，是路；礼，是门。只有君子能走这条路、出入这道门。《诗》说：‘周道如砥，其直如矢；君子所履，小人所视。’”万章说：“孔子，君命召，不等车驾就走。那孔子不对吗？”孟子说：“孔子当时在做官有官职，君主是以他的官职召他。”

五　章旨

不见诸侯，是士之礼；非其招不往；义是路，礼是门。

五条支撑：

  1. “不敢见”是礼，不是傲。 无贽不为臣。
  2. “往役”与”往见”分两事。 役是职，见是礼。
  3. “何为也哉”一问最狠。 你要见他，为什么？
  4. 子思的分辨：以位／以德。 两条尺子，量出两种关系。
  5. “欲其入而闭之门”是总喻。 召，就是关门。

六　注家

【朱熹曰】“质，与贽同。传，通也。质者，士执雉，庶人执鹜，相见以自通者也。国内莫非君臣，但未仕者与执贽在位之臣不同，故不敢见也。”（《孟子集注·万章下》）

【朱熹曰】“往役者，庶人之职；不往见者，士之礼。”（同上）

【朱熹曰】“皮冠，田猎之冠也。事见春秋传。然则皮冠者，虞人之所有事也，故以是招之。庶人，未仕之臣。通帛曰旃。士，谓已仕者。交龙为旗，析羽而注于旗干之首曰旌。”（同上）

【朱熹曰】“夫义，路也；礼，门也。惟君子能由是路，出入是门也。”（同上）朱熹曰：“欲见贤人而不以其道，犹欲其入而闭之门也。”

【徐氏曰】“孔子、孟子，易地则皆然。”（同上，引徐氏说，答”孔子不俟驾”之疑）

【赵岐注】庶人不见诸侯，士不召不见；招非其物则不往，义路礼门之说以喻之。（按：此为赵注大意，非原文。）

对照：赵岐顺释礼数；朱熹以”贽”字立”不敢见”之实，又以”欲其入而闭之门”一句把全章收成一句喻。赵明其数，朱立其喻。

七　分寸与边界

  1. 不可把”不见诸侯”读成”傲视权贵”。**是”不敢”，不是”不屑”。
  2. 不可把”往役”与”往见”混。**一是职，一是礼。
  3. 不可把”非其招不往”读成”摆架子”。**是”招”本身不合礼。
  4. 不可把”以德则子事我”读成”德高即可傲人”。**子思说的是”不可友”，不是”可召”。
  5. 不可把孔子”不俟驾”当作反例。**他是”以官召”，不是”以贤召”。

八　义理

这一章是全卷最长的一章，讲的是“见与不见”的分寸。

先看那条礼：无贽不为臣，故不敢见。 这一条不是骄傲，是身份的界限：我还没在你手下做事，我就不进你的门。 进去了，我就成了你的臣；没进去，我还是庶人。

万章的反问极准：那服役为什么去？ 孟子答：服役是庶人的职，去见是士的礼。 ——同一个”召”，两件事。 一个是义务，一个是身份。

然后是最要紧的一问：“且君之欲见之也，何为也哉？” ——你不先问”他为什么见我”，就谈”我该不该去”，是本末倒置。

答案给了两个：为他多闻、为他贤。 孟子各破一句：多闻，则天子不召师；贤，则未闻欲见贤而召之。

子思那段，是这一章的骨。 缪公说”古时千乘之国与士为友”，子思不高兴。为什么不高兴？ 因为”友”是把两人放在一条线上，而”事”是有上下的。

孟子替他把话说明白了：按位，你是君我是臣，我不敢与你为友；按德，你该事奉我，你怎么可以与我为友？ ——两把尺子，量出两种关系；而两种关系，都不叫”友”。

“千乘之君求与之友而不可得，而况可召与？” ——连”友”都求不到，还想”召”？

齐景公招虞人那一段，是把”招”这个动作拆开。 招大夫用旌，招士用旗，招庶人用旃，招虞人用皮冠。用错了，虞人死也不去。 孟子说：这就是”非其招不往”。

最后两个字，是这一章留下的东西：义，路也；礼，门也。 ——义是你走的那条路，礼是你进的那道门。 想让人进来，却把门关上；这就是”欲见而召之”的形状。

孔子”不俟驾”不是反例。 孟子说得很清：他当时在做官，君主是以他的官职召他。 以官召，是召臣；以贤召，是召师。召臣可以，召师不可以。

九　时代之问

  • 我这次去见一个人，是为职，还是为礼？
  • 我先问过”他为什么见我”吗？
  • 我用的是哪一把尺子：位，还是德？
  • 我请人帮忙，是”请”，还是”召”？
  • 我有没有一边想人进来，一边把门关上？

十　跨典

  • 《礼记·曲礼》“礼闻来学，不闻往教”——不召师。
  • 《论语·阳货》“孔子不见孺悲”——不见之礼。
  • 《孟子·公孙丑下》“不见诸侯”三章——同事异问。

十一　存疑

  1. “质”是否即”贽”。 朱熹曰同。
  2. “皮冠”招虞人之事。 朱熹曰”事见春秋传”。
  3. “齐景公田”之”田”。 田猎。
  4. “周道如底”的”底”。 诗作”砥”。
  5. 本章是否当与《公孙丑下》诸章合看。 朱熹曰”更合陈代、公孙丑所问者而观之，其说乃尽”。
