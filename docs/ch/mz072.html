第七十二章　道在迩

一　本章导读

孟子这一章只有二十四字，是全书中最近的一章：

道在尔而求诸远，事在易而求之难。

——道就在你脚边，你偏往远处找；事本来容易，你偏往难处做。

然后给出”近”与”易”的具体所指：人人亲其亲、长其长而天下平。 ——各人亲自己的亲人，敬自己的长辈，天下就平了。

此章驳谁：驳”道是高远的、须到远处去求”。立什么：立”道在迩、事在易”，落在两句可指得着的动作上——亲其亲、长其长。留给后人什么：一件近到手边的事，和一条被绕开的近路。

二　经文

【经】孟子曰：“道在尔而求诸远，事在易而求之难。人人亲其亲、长其长而天下平。”

三　字义与句读

尔　朱熹：“尔、迩，古字通用。”——不是”你”，是”近”。

易　朱熹注音”去声”，读如”易”之难易之易。此处的”易”是”不费力”，不是”轻慢”。

长　朱熹注”上声”。前一”长”是名词（长辈），后一”长”是动词（敬重长辈）。两个”长”字，一个读法两样用法。

亲其亲　朱熹：“亲长在人为甚迩，亲之长之在人为甚易，而道初不外是也。”——“亲”作动词，是”亲爱”；“其亲”是”自己的亲人”。

天下平　朱熹：“但人人各亲其亲、各长其长，则天下自平矣。”——“自平”二字要紧：不是谁去摆平，是它自己平。

句读一处：“人人亲其亲、长其长而天下平。”——“而”字连的是前两句与后一句，不是”亲其亲”与”长其长”之间。 若断成”人人亲其亲，长其长而天下平”，就把”长其长”读成了”天下平”的条件，孟子没有这个意思；他给的是两件并列的事，合成一个结果。

四　今译

孟子说：“道就在近处，人却往远处去求；事本来容易，人却往难处去做。人人亲爱自己的亲人、敬重自己的长辈，天下就平了。”

五　章旨

“道”不在远处，在一个人手边的两件事上；“平天下”不是造出来的，是各人把手边这两件事做了之后自己平下来的。

五条支撑：

  1. “尔”字是钥匙。 朱熹一句”尔、迩，古字通用”，把整章的坐标定了下来：不是”道在你那里”，是”道在近处”。 一字之训，全章之势随之。
  2. 两个”求”字点出病根。 “求诸远”“求之难”——病不在”求”，在”求的方向”。 孟子不说人不努力，他说人把力气使反了。
  3. “亲其亲、长其长”是两件可指得着的事。 不是”要有仁心”，是今天去亲一个人、敬一个人。抽象的道，被落成两个动词。
  4. “天下平”的机制是”人人”，不是”一人”。 朱熹说”天下自平”——平不是从上往下发的命令，是从下往上积出来的状态。 孟子把”平天下”从君王手里，交回每一双手里。
  5. 全章没有一个”学”字，却没有一句反对学。 它反对的是”舍近求远”，不是”求”。远求者未必不勤，只是勤在了空处。

六　注家

【朱熹曰】“尔、迩，古字通用。易，去声。长，上声。亲长在人为甚迩，亲之长之在人为甚易，而道初不外是也。”（《孟子集注·离娄上》）

【朱熹曰】“舍此而他求，则远且难而反失之。”（同上）——“反失之”三字最重：远求不只是白费，是把本来有的弄丢了。

【朱熹曰】“但人人各亲其亲、各长其长，则天下自平矣。”（同上）

对照：赵岐注此章，串讲文义，以”道不远人”为说，重在各安其分；朱熹则先把”尔”训成”迩”，再把”自平”点出，把一句格言落成两条动作。赵顺其文，朱定其位。

七　分寸与边界

  1. 不可把此章读成”不必读书、不必问学”。孟子反对的是”舍近”，不是”求远”；该走的远路，仍要走。
  2. 不可把”亲其亲”读成”只管自己家”。原文的重心是”人人”——每一家都做，才有”天下平”；只顾一家，恰恰是这一章要治的病。
  3. 不可把”天下平”读成”什么都不用做”。“自平”是说结果不由一人造，不是说过程不必人做。
  4. 不可把”亲其亲”读成护短。亲是亲爱，长是敬重；亲而至于不问是非，敬而至于不问对错，都不是孟子这里的”亲”“长”。
  5. 不可把”易”读成”轻慢”。“易”是不费力，不是不郑重；恰恰因为不费力，才更容易被跳过。

八　义理

这一章短得像一句谚语，却是《孟子》全书对”人的力气往哪儿使”最干净的一次校正。

先看那个”迩”字。 孟子说”道在尔”，不是说”道很浅”，是说“道的位置在你身边”。位置的判断一错，后面全错：你把道当成远处的山峰，就一辈子在爬山；你把它当成手边的一件事，今天就能做。孟子没有降低道的标准，他只是把道的坐标改了。

再看那两个”求”字背后的心理。 人为什么愿意远求？因为远求显得郑重。 跋山涉水、访师问道、抄万卷书——这些都看得见，都算得清，都能拿出来说。而在家给自己的父亲端一碗饭，没人看见，也说不出口。远求的最大好处，是它可以替代做到。 孟子这一刀，砍的就是这个替代。

“人人亲其亲、长其长而天下平”，这句最容易被读轻。 它不是”只要人人孝顺，天下就好了”这种劝善话。它说的是一个机制：天下的秩序，是从无数个”我对这个人好”里长出来的，不是从一道命令里发出来的。 所以”平”是”自平”——没有一个人能替所有人做这件事，也没有一个人能不做。

最后回到那个”而”字。 亲其亲、长其长，然后天下平；中间没有第三件事。 孟子把”平天下”的工序，删到只剩两道：对人好，对长辈敬。 删到这个地步，是因为他相信：别的都是这两件的延长线。

九　时代之问

  • 我最近在远处找的那个东西，手边是不是已经有一份？
  • 我说”这事太难”的时候，是不是先把容易的那一步跳过了？
  • 我做的事，看得见的多，还是算得清的多？
  • 我上一次认真亲一个人、敬一个人，是哪一天？
  • 我盼着”天下平”，可我这一格，平了吗？

十　跨典

  • 《论语·学而》：“孝弟也者，其为仁之本与！”——“亲其亲、长其长”的根。
  • 《礼记·大学》：“修身而后家齐，家齐而后国治，国治而后天下平。”——同一条由近及远的次序，孟子说得更短。
  • 《礼记·中庸》：“道不远人。人之为道而远人，不可以为道。”——“道在尔”的另一说法。
  • 《荀子·修身》：“道虽迩，不行不至；事虽小，不为不成。”——把”迩”与”行”接上。
  • 《老子》第五十三章：“大道甚夷，而民好径。”——“求诸远”的另一种形态：好走小路。
  • 《孟子·尽心上》：“无为其所不为，无欲其所不欲，如此而已矣。”——把”易”再往下删一层。

十一　存疑

  1. “尔”字。 今本多作”尔”，朱熹谓与”迩”通用；一本径作”迩”，义同。
  2. “亲其亲”的两读。 一说前”亲”为动词、后”亲”为名词；一说两”亲”皆名词而省”爱”字。朱熹从前者。
  3. “天下平”的范围。 一说指”平治”，一说指”公平”。朱熹”自平”近于前者而含后者。
  4. 本章与上章的关系。 朱熹分为二章，文气上与”自暴自弃”相接，然主题另起。
  5. “事在易”之”事”。 或指政事，或泛指人事；朱熹未确指，只以”亲长”当之。

图位　图一｜在迩与求远

读图三处：

  1. 那只牵着的手——就在身前，不用走过去。“亲其亲”的距离，是一伸手。
  2. 脚边那双摆正的鞋——不是行李，是日常。“长其长”的份量，是一双鞋的份量。
  3. 背着行囊的那个人与折线山路——路画得很长，很郑重。他不是不努力，他是把努力用在了”看得见”的地方。

图说一句：最近的那件事，常常是最先被绕开的那件事。
