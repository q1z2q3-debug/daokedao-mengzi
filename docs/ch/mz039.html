第三十九章　俭其亲

一　本章导读

孟子在齐做官时母亲去世，回鲁国安葬，再回齐，停在嬴邑。

弟子充虞来问：先前不知道我不才，让我管过做棺的事。那时事情急，我不敢问；现在想私下问一句——木若以美然。 棺木好像太好了些。

这一问很讲究。它问的不是钱，是”逾制”，是”你在母亲身上是不是过了一点”。

孟子的回答分三层：

第一层，给制度。 古时棺椁没有定尺寸；中古棺七寸，椁与之相称，从天子到庶人一样。不是为好看，是为了”尽于人心”。

第二层，给条件。 制度不许，不能算称心；没有财力，也不能算称心。得之为有财，古之人皆用之，吾何为独不然？

第三层，给理由。 为死者不让土贴近他的皮肤，做人子的心里难道不痛快吗？

末句是全章的定音：吾闻之君子：不以天下俭其亲。

此章驳谁：驳”厚葬就是奢侈”。立什么：立”葬礼的标准不是俭奢，是’能不能尽’——制度允许、财力够，就该尽”。留给后人什么：一句极重的判词：不要拿”天下”当理由，省在自己最亲的人身上。

二　经文

【经】孟子自齐葬于鲁，反于齐，止于嬴。充虞请曰：“前日不知虞之不肖，使虞敦匠事。严，虞不敢请。今愿窃有请也，木若以美然。”

【经】曰：“古者棺椁无度，中古棺七寸，椁称之。自天子达于庶人。非直为观美也，然后尽于人心。”

【经】“不得，不可以为悦；无财，不可以为悦。得之为有财，古之人皆用之，吾何为独不然？”

【经】“且比化者，无使土亲肤，于人心独无恔乎？吾闻之君子：不以天下俭其亲。”

三　字义与句读

敦匠事　朱熹：“尝董治作棺之事者也。”督办做棺。

严　朱熹：“严，急也。”事急，不敢打断。

以美　朱熹：“以、已通。以美，太美也。”已经太好了。

无度　朱熹：“度，厚薄尺寸也。”没有统一尺寸。

中古　朱熹：“中古，周公制礼时也。”

椁称之　朱熹：“椁称之，与棺相称也。欲其坚厚久远，非特为人观视之美而已。”

恔　朱熹：“恔，快也。言为死者不使土近其肌肤，于人子之心，岂不快然无所恨乎？”

不以天下俭其亲　朱熹：“送终之礼，所当得为而不自尽，是为天下爱惜此物，而薄于吾亲也。”

句读一处：“得之为有财”——朱熹：“言得之而又为有财也。或曰：‘为当作而。’”两读皆通，意思都是”制度允许＋财力够”。

四　今译

孟子从齐回鲁安葬母亲，再回齐，停在嬴邑。充虞请教说：“先前不知道我不才，让我督办做棺的事。那时事急，我不敢问；现在想私下请教——棺木好像太好了些。”

孟子说：“古时棺椁没有尺寸之定；中古棺厚七寸，椁与之相称，从天子到庶人都一样。不是为了看着美，是为了尽人心。”

“制度不许，不能称心；没有财力，也不能称心。制度允许又有财力，古人都会这样做，我为什么偏不？”

“况且为了死者不让土贴近他的皮肤，做人子的心里难道不痛快吗？我听说君子：不会为了天下（爱惜财物）而薄待自己的亲人。”

五　章旨

葬礼的尺度不是”俭不俭”，是”尽不尽”；而”尽”有两个前提：制度与财力。

五条支撑：

  1. 充虞问得体面，孟子答得具体。 一问一答都在讲尺寸、财力、皮肤与土的距离，不讲排场。
  2. “非直为观美也”一句，先把”奢侈”这条指控挡掉。 七寸之棺的功能是”坚厚久远”。
  3. “不得”与”无财”是两个闸门。 孟子不主张无条件厚葬，他主张”两门都开时才尽”。
  4. “比化者，无使土亲肤”是本章的实物依据。 棺的第一功能是不让土碰人。
  5. 末句极重：“不以天下俭其亲。”“天下”在这里指”天下之物”——不要拿”为了天下节省”当成薄待亲人的理由。

六　注家

【朱熹曰】“孟子仕于齐，丧母，归葬于鲁。嬴，齐南邑。充虞，孟子弟子，尝董治作棺之事者也。严，急也。木，棺木也。以、已通。以美，太美也。”（《孟子集注·公孙丑下》）

【朱熹曰】“度，厚薄尺寸也。中古，周公制礼时也。椁称之，与棺相称也。欲其坚厚久远，非特为人观视之美而已。”（同上）

【朱熹曰】“不得，谓法制所不当得。得之为有财，言得之而又为有财也。或曰：‘为当作而。’”（同上）

【朱熹曰】“比，犹为也。化者，死者也。恔，快也。……送终之礼，所当得为而不自尽，是为天下爱惜此物，而薄于吾亲也。”（同上）

对照：赵岐注”中古”为”周公时”，与朱同；而赵以”恔”为”快”，朱熹从之而加一句”无所恨”，把”快”解成”没有遗憾”——赵解字面，朱解心境。

七　分寸与边界

  1. 不可读成”厚葬有理”。孟子先摆制度闸门：不得，不可以为悦。
  2. 不可读成”越厚越好”。他说的是”称”——棺椁相称，不称就是过。
  3. 不能把”不以天下俭其亲”当作反对节俭。它反对的是拿”天下”做大帽子，省在自己人身上。
  4. 不可忽略”严”字。事急，弟子不敢问；这一问是隔了很久才问出来的，所以孟子答得郑重。

八　义理

这一章是孟子全书中少有的私人场景，也是他谈”礼”最细的一次。

它处理的是一个普遍困境：当”节俭”变成一种道德姿态，它会不会反过来伤害最亲近的人？

孟子的解法是把”俭”的问题转译成”尽”的问题。俭是量的概念——花得少不少；尽是限的概念——该给的给足了没有。量可以比，限不能比：一个庶人的”尽”和一个天子的”尽”，尺寸不同，性质一样。这就是”自天子达于庶人”的意思：不是同一个标准，是同一个”尽”。

第二层是”两门”：制度与财力。这两门都开，才谈得上”尽”；有一门关着，“不尽”就不算罪。这个结构极重要——它既挡掉了”奢侈”，也挡掉了”以穷为德”。

第三层落在”土亲肤”这三个字上。孟子把一场关于排场的争论，还原成一件极具体的事：土会不会碰到人。 所有的礼，最后都要落在一件能指得着的事上；落不上的，就是观美。

九　时代之问

  • 我的”节俭”，有没有省在最近的人身上？
  • 我说”为了大局”的时候，省掉的是谁？
  • 我给的”尽”，是按别人看的尺寸，还是按这件事本身的尺寸？
  • 我有没有用”制度不许”当省钱的挡箭牌，或用”财力够”当铺张的挡箭牌？

十　跨典

  • 《论语·八佾》：“礼，与其奢也，宁俭。”——孔子主俭，但那是”就礼言礼”。
  • 《孟子·滕文公上》：“生，事之以礼；死，葬之以礼，祭之以礼。”——同一条”尽”。
  • 《礼记·檀弓》：“丧礼，与其哀不足而礼有余也，不若礼不足而哀有余也。”——朱注”无所恨”与此同调。
  • 《荀子·礼论》：“事生，饰始也；送死，饰终也。”——终始一贯。
  • 《老子》第六十七章：“俭，故能广。”——俭是对己，不是对人。

十一　存疑

  1. 棺七寸之制。 朱熹谓”中古棺七寸”，注家多以周尺计；一说为”七寸之椁”。
  2. “得之为有财”之”为”。 朱熹并存两读：“为”或作”而”。
  3. “不以天下俭其亲”之”天下”。 朱熹解为”天下之物”；今人有解为”天下之公”，义更重。
  4. 此事之年。 孟子丧母归葬，注家多系于去齐前后，无确年。
