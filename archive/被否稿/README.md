# 被否稿归档

本库规矩：被作者指出不成立、撤出正式文档的稿子，不销毁，另存此处并标明存疑；正式文档只留改定后的版本。

## 现况

截至 v0.35.0，**尚无被否正文**。二十批正文（MZ001–MZ261）一次落定，作者未退回任何整章；返工只在图件层面发生：

- 图号序列：MZ090 起原按卷内重起（「图一」再起），已后移 89 使全书图号＝章号（仅改图号与署名，正文论述未动）。
- 图件字号与画幅：小注字号统一提到 5.2 下限（仅视觉，不动文义）。

故本目录暂空。日后若有整章撤换，稿子放此处，命名 `MZ###-原题-否决日期.md`，并在文件头写明：何时被否、为何被否、由哪一版取代。
