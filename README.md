# 润泽说 道可道之孟子

> 《孟子》七篇十四卷二百六十章通释读本。底本朱熹《四书章句集注·孟子集注》，参校《孟子注疏》赵岐注、孙奭疏。
> 作者：润泽（润泽博士）· 在线读：<https://q1z2q3-debug.github.io/daokedao-mengzi/> · v0.1.0（骨架）

## 是什么

一章一页，按朱子所分七篇十四卷、二百六十章，章号 `MZ001`–`MZ260` 连排固定。每章十二节（导读、经文、字义与句读、今译、章旨、注家、分寸与边界、义理、时代之问、跨典、存疑、双卡与图）。四层分离：经文【经】、注家【注】、义理【义】、今用【用】，一段只归一层。

两条自立的规矩：

- **孟子三判**：每章导读须答三句——此章驳谁／立什么／留给后人什么。第三句缺席，视为该章未写完。
- **从事入，不从理入**：每章至少落一件可指着说的物或事（一把尺、一条渠、一畦田、一句问话），理从物里长出来。

## 结构

- `book/` 二百六十章源稿（`MZ001`–`MZ260`），一章一文件；`体例.md` 为唯一体例源；`卷表.md`、`chapters.json` 与逐章一致。
- `book/chapters.json` 卷、章、章号、文件、页面、图键的机器可读表（骨架版章题为空，落笔时补定并改文件名）。
- `assets/fig/` 手写 SVG 义理图，一图一文件，纸墨五色。
- `scripts/` `build_book.py`（md→`docs/` 卷首页与首页）、`build_site.py`、`check_book.py`、`daokedao_book.py`（封面/扉页/图件共用件）、`_shell_book.html`（本库页面壳，各库自带副本）。
- `docs/` 站点（GitHub Pages，`main:/docs`）。

## 命令

```bash
python3 scripts/build_book.py     # 构建卷首页 docs/book.html 与首页 docs/index.html
python3 scripts/check_skeleton.py # 骨架自检（卷表／章表／文档一致）；正文落笔后另用 check_book.py
```
